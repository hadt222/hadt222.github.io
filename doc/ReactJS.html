React là gì? Tư duy cốt lõi

React là thư viện JavaScript để xây dựng giao diện người dùng (UI) từ các component — những khối giao diện nhỏ, độc lập và có thể tái sử dụng. Thay vì tự tìm phần tử DOM và cập nhật bằng tay, bạn mô tả giao diện phải trông như thế nào dựa trên dữ liệu; React phụ trách đồng bộ hiển thị khi dữ liệu đổi.

Mô hình tư duy: UI = f(state, props). Cùng một trạng thái và props thì component nên tạo cùng kết quả hiển thị. Hãy nghĩ về React như những hàm mô tả UI.

Khái niệm Hiểu ngắn gọn Ví dụ
Component Khối UI viết thành hàm Header, ProductCard
JSX Cú pháp gần giống HTML trong JavaScript <h1>Xin chào</h1>
Props Dữ liệu cha truyền xuống con <Card title="React" />
State Dữ liệu nội bộ làm UI thay đổi useState(0)
Hook API để dùng khả năng của React useEffect, useRef
Render React gọi component để tính UI tiếp theo state đổi → render

Khi nào nên dùng? Ứng dụng có nhiều phần tương tác, bảng điều khiển, thương mại điện tử, form phức tạp hoặc giao diện cần chia sẻ component. Trang giới thiệu tĩnh rất nhỏ có thể chỉ cần HTML/CSS/JS.

Cần biết trước: HTML cơ bản; CSS, flexbox; JavaScript hiện đại gồm const/let, arrow function, destructuring, array map/filter, module import/export, Promise và async/await.

Cài đặt React bằng Vite

Để học React ở phía trình duyệt, chúng ta dùng Vite làm công cụ phát triển. Đây là cách gọn để có JSX, dev server, hot reload và bản build production. Với ứng dụng sản phẩm cần SSR, routing/data loading tích hợp, tài liệu React cũng khuyên xem xét một framework phù hợp.

Bước 1 — Kiểm tra môi trường

Cài Node.js tương thích với Vite hiện hành (theo tài liệu Vite: 20.19+ hoặc 22.12+, hay phiên bản mới hơn tương thích). Mở Terminal và chạy:

Terminal
node -v
npm -v

Bước 2 — Tạo dự án

Terminal
npm create vite@latest react-tutorial -- --template react
cd react-tutorial
npm install
npm run dev

Mở địa chỉ http://localhost:5173 hoặc URL được Terminal hiển thị. Để triển khai, dùng npm run build; để kiểm tra bản build cục bộ, dùng npm run preview.

Bước 3 — Hiểu cấu trúc file

Cấu trúc thư mục
react-tutorial/
├─ index.html           # chứa <div id="root"></div>
├─ package.json         # scripts và dependencies
├─ public/              # tài nguyên tĩnh không import
└─ src/
   ├─ main.jsx          # điểm khởi động React
   ├─ App.jsx           # component gốc
   └─ index.css         # CSS toàn cục

src/main.jsx thường có dạng:

React · JSX
import React from 'react';
import { createRoot } from 'react-dom/client';
import App from './App.jsx';
import './index.css';

createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);

StrictMode giúp phát hiện một số lỗi tiềm ẩn trong môi trường development. Do đó, bạn có thể thấy một số lần render hoặc chạy Effect bổ sung khi phát triển; không nên “chữa” bằng cách tắt nó ngay.

Ghi nhớ: File HTML tutorial bạn đang đọc là tài liệu một file, mở offline. Các đoạn JSX trong tài liệu là mã React để dán vào dự án Vite, không được trình duyệt thực thi trực tiếp khi mở file hướng dẫn.

JSX: Viết giao diện trong JavaScript

JSX cho phép trộn cấu trúc UI vào biểu thức JavaScript. JSX không phải HTML thuần và được công cụ build chuyển đổi trước khi chạy.

React · JSX
const name = 'Linh';
const isOnline = true;

export default function Greeting() {
  return (
    <section className="welcome">
      <h1>Xin chào, {name} 👋</h1>
      <p>Trạng thái: {isOnline ? 'Đang online' : 'Ngoại tuyến'}</p>
      <img src="/logo.svg" alt="Logo ứng dụng" />
    </section>
  );
}

5 quy tắc phải nhớ

  1. Trả về một phần tử gốc hoặc fragment <>...</>.
  2. Dùng className thay class, htmlFor thay for trên <label>.
  3. Đóng tất cả thẻ: <img />, <input />, <br />.
  4. Dùng {...} để chèn biểu thức JavaScript — không viết lệnh if, for trực tiếp trong JSX.
  5. Style nội tuyến là object: style={{ color: 'tomato', fontSize: 18 }}.
React · JSX
function Profile() {
  const user = { name: 'An', avatar: '/avatar.png' };

  return (
    <>
      <h2>{user.name.toUpperCase()}</h2>
      <img src={user.avatar} alt={`Ảnh của ${user.name}`} />
      <p style={{ color: '#0f766e', marginTop: 12 }}>Học mỗi ngày</p>
    </>
  );
}

Lưu ý: Không đưa HTML thô từ dữ liệu không tin cậy vào dangerouslySetInnerHTML. React tự escape giá trị chuỗi bình thường trong JSX, giúp giảm nguy cơ XSS.

Component, props và children

Component là hàm có tên bắt đầu bằng chữ hoa và trả về JSX. Đặt component trong những file riêng nếu giúp đọc hiểu, rồi export/import để tái sử dụng.

React · JSX
// src/components/Badge.jsx
export default function Badge({ label, color = 'blue' }) {
  return <span className={`badge badge-${color}`}>{label}</span>;
}

// src/App.jsx
import Badge from './components/Badge.jsx';

export default function App() {
  return (
    <main>
      <Badge label="Đang học" />
      <Badge label="Hoàn thành" color="green" />
    </main>
  );
}
  • Props là đầu vào của component, được xem là chỉ đọc. Đừng gán props.title = '...'.
  • children là JSX nằm giữa thẻ mở và đóng của component.
  • Một component cha có thể truyền callback cho component con để con báo sự kiện ngược lên.
React · JSX
function Panel({ title, children }) {
  return (
    <section className="panel">
      <h2>{title}</h2>
      <div>{children}</div>
    </section>
  );
}

function App() {
  return (
    <Panel title="Bài học hôm nay">
      <p>Tìm hiểu cách truyền children.</p>
      <button>Tiếp tục</button>
    </Panel>
  );
}

Phân biệt: Props nhận từ bên ngoài; state là bộ nhớ của component. Cả hai đều ảnh hưởng giao diện khi React render.

Hiển thị có điều kiện và danh sách

Dùng toán tử ba ngôi condition ? A : B, && hoặc if trước câu lệnh return để thay đổi UI theo dữ liệu.

React · JSX
function AccountStatus({ user }) {
  if (!user) return <p>Vui lòng đăng nhập.</p>;

  return (
    <div>
      <h2>Chào {user.name}</h2>
      {user.isAdmin && <strong>Quản trị viên</strong>}
      <p>{user.isOnline ? '🟢 Online' : '⚪ Offline'}</p>
    </div>
  );
}

Với danh sách, dùng .map() để biến từng dữ liệu thành phần tử JSX, và cung cấp key ổn định, duy nhất trong danh sách anh em.

React · JSX
const courses = [
  { id: 'react', title: 'React cơ bản', hours: 12 },
  { id: 'js', title: 'JavaScript', hours: 20 },
  { id: 'css', title: 'CSS hiện đại', hours: 8 },
];

function CourseList() {
  return (
    <ul>
      {courses
        .filter(course => course.hours >= 10)
        .map(course => (
          <li key={course.id}>
            {course.title} — {course.hours} giờ
          </li>
        ))}
    </ul>
  );
}

Vì sao key quan trọng? Nó giúp React nhận biết phần tử nào được thêm, xóa, di chuyển. Tránh key={index} nếu danh sách có thể đổi thứ tự, được thêm/xóa; không tạo key bằng Math.random() mỗi render.

Sự kiện và useState

Sự kiện React viết theo kiểu camelCase: onClick, onChange, onSubmit. Truyền hàm, không gọi hàm ngay khi render: onClick={handleClick} đúng; onClick={handleClick()} thường sai.

React · JSX
import { useState } from 'react';

export default function Counter() {
  const [count, setCount] = useState(0);

  function increase() {
    setCount(previous => previous + 1);
  }

  return (
    <div>
      <p>Đã nhấn: {count} lần</p>
      <button onClick={() => setCount(0)}>Đặt lại</button>
      <button onClick={increase}>Tăng +1</button>
    </div>
  );
}

useState(initialValue) trả về [value, setter]. Khi gọi setter, React xếp lịch cập nhật UI ở lần render sau, không sửa ngay giá trị biến của render hiện tại.

Khi cập nhật dựa trên state trước đó

React · JSX
// Đúng khi cập nhật liên tiếp:
setCount(prev => prev + 1);
setCount(prev => prev + 1);
setCount(prev => prev + 1); // tăng tổng cộng 3

// Dễ sai trong một handler vì cùng đọc giá trị count cũ:
setCount(count + 1);
setCount(count + 1);
setCount(count + 1); // thường chỉ tăng 1

Cập nhật object và array bất biến

React · JSX
const [user, setUser] = useState({ name: 'Mai', city: 'Hà Nội' });
setUser(prev => ({ ...prev, city: 'Đà Nẵng' }));

const [tasks, setTasks] = useState(['Đọc React']);
setTasks(prev => [...prev, 'Làm bài tập']);
setTasks(prev => prev.filter(task => task !== 'Đọc React'));

Không dùng user.city = '...' hoặc tasks.push(...) để cập nhật state trực tiếp vì có thể không tạo được cập nhật đúng như mong muốn.

State, render và luồng dữ liệu

React thường có luồng dữ liệu một chiều: cha truyền props xuống con. Khi nhiều component cần cùng một dữ liệu, hãy đưa state lên tổ tiên chung gần nhất (lifting state up).

React · JSX
import { useState } from 'react';

function SearchBox({ query, onQueryChange }) {
  return (
    <input
      value={query}
      onChange={e => onQueryChange(e.target.value)}
      placeholder="Tìm khóa học..."
    />
  );
}

function App() {
  const [query, setQuery] = useState('');
  const items = ['React', 'JavaScript', 'TypeScript'];
  const visible = items.filter(item =>
    item.toLowerCase().includes(query.toLowerCase())
  );

  return (
    <>
      <SearchBox query={query} onQueryChange={setQuery} />
      <ul>{visible.map(item => <li key={item}>{item}</li>)}</ul>
    </>
  );
}

Tránh state dư thừa

Nếu fullName có thể tính từ firstName và lastName, đừng tạo state thứ ba rồi dùng useEffect để đồng bộ. Chỉ cần const fullName = firstName + ' ' + lastName; trong render. Điều này giảm logic và lỗi đồng bộ.

Quy tắc của Hooks

  • Gọi Hook ở top level của function component hoặc custom Hook.
  • Không gọi Hook trong if, for, callback sự kiện hoặc hàm JavaScript thông thường.
  • Component/Hook nên thuần trong giai đoạn render: không sửa dữ liệu bên ngoài, không gọi API trong thân render.

Form và controlled input

Trong controlled input, React state là nguồn dữ liệu chính. Khi người dùng nhập, onChange cập nhật state, và React truyền lại value vào ô nhập.

React · JSX
import { useState } from 'react';

export default function RegisterForm() {
  const [email, setEmail] = useState('');
  const [error, setError] = useState('');

  function handleSubmit(event) {
    event.preventDefault();
    if (!email.includes('@')) {
      setError('Vui lòng nhập email hợp lệ.');
      return;
    }
    setError('');
    alert(`Đã nhận: ${email}`);
  }

  return (
    <form onSubmit={handleSubmit}>
      <label htmlFor="email">Email</label>
      <input
        id="email"
        type="email"
        value={email}
        onChange={event => setEmail(event.target.value)}
        required
      />
      <button type="submit">Đăng ký</button>
      {error && <p role="alert">{error}</p>}
    </form>
  );
}

Checkbox: dùng checked + onChange={e => setChecked(e.target.checked)}. Select: dùng value + onChange. TextArea: dùng value + onChange. Với form đơn giản trong React 19, bạn cũng có thể dùng action và FormData; phần nâng cao có ví dụ.

UX tốt: Gắn <label>, dùng type đúng, hiển thị trạng thái lỗi rõ ràng, vô hiệu hóa nút khi gửi dữ liệu và không chỉ dựa vào placeholder để mô tả ô nhập.

useEffect: Đồng bộ hệ thống bên ngoài

useEffect phù hợp để đồng bộ với thứ nằm ngoài hệ thống render của React: bộ lắng nghe sự kiện, timer, kết nối mạng, thư viện DOM, hoặc một yêu cầu fetch đơn giản. Nó không phải công cụ mặc định cho mọi phép tính.

Ví dụ: đăng ký sự kiện và cleanup

React · JSX
import { useEffect, useState } from 'react';

function WindowWidth() {
  const [width, setWidth] = useState(window.innerWidth);

  useEffect(() => {
    const onResize = () => setWidth(window.innerWidth);
    window.addEventListener('resize', onResize);
    return () => window.removeEventListener('resize', onResize);
  }, []);

  return <p>Chiều rộng cửa sổ: {width}px</p>;
}

Hàm được return trong Effect là cleanup: chạy trước khi Effect chạy lại với dependency mới và khi component unmount. Ví dụ trên dành cho app chỉ chạy trên client; SSR cần cẩn thận khi truy cập window.

Ví dụ: fetch API có hủy request

React · JSX
import { useEffect, useState } from 'react';

function Users({ endpoint }) {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState('');

  useEffect(() => {
    const controller = new AbortController();

    async function load() {
      setLoading(true);
      setError('');
      try {
        const response = await fetch(endpoint, { signal: controller.signal });
        if (!response.ok) throw new Error(`HTTP ${response.status}`);
        const data = await response.json();
        if (!controller.signal.aborted) setUsers(data);
      } catch (err) {
        if (!controller.signal.aborted) setError(err.message);
      } finally {
        if (!controller.signal.aborted) setLoading(false);
      }
    }

    load();
    return () => controller.abort();
  }, [endpoint]);

  if (loading) return <p>Đang tải...</p>;
  if (error) return <p role="alert">Lỗi: {error}</p>;
  return <ul>{users.map(user => <li key={user.id}>{user.name}</li>)}</ul>;
}

Cách trên thích hợp để học. App thực tế thường hưởng lợi từ loader của router/framework hoặc thư viện cache như TanStack Query / SWR để quản lý cache, retry, tránh request nối đuôi.

Dependency array: bỏ mảng → Effect chạy sau mỗi commit; [] → đồng bộ lúc mount (có chạy bổ sung trong StrictMode ở dev); [endpoint] → chạy lại khi endpoint đổi. Đừng cố tình bỏ dependency để tránh lỗi lint.

useRef và custom Hook

useRef lưu một giá trị qua các lần render nhưng thay đổi ref.current không kích hoạt render. Thường dùng để lấy DOM node hoặc giữ ID của timer.

React · JSX
import { useRef } from 'react';

function FocusInput() {
  const inputRef = useRef(null);
  return (
    <>
      <input ref={inputRef} placeholder="Tên của bạn" />
      <button onClick={() => inputRef.current?.focus()}>
        Focus vào ô nhập
      </button>
    </>
  );
}

Custom Hook là hàm bắt đầu bằng use, giúp tái sử dụng logic có Hook. Mỗi lần gọi có state riêng — không tự động chia sẻ cùng một state cho mọi component.

React · JSX
import { useEffect, useState } from 'react';

function useDocumentTitle(title) {
  useEffect(() => {
    document.title = title;
  }, [title]);
}

function Article({ title }) {
  useDocumentTitle(title);
  return <h1>{title}</h1>;
}

So sánh nhanh: useState lưu dữ liệu ảnh hưởng UI; useRef lưu dữ liệu không cần làm UI cập nhật; useEffect đồng bộ với hệ thống ngoài React.

Context và useReducer

Nếu nhiều cấp component cần theme, người dùng đăng nhập hoặc ngôn ngữ, Context giúp tránh truyền props qua quá nhiều tầng. Không nhất thiết thay mọi props bằng Context; props vẫn rõ ràng và dễ tái sử dụng hơn cho dữ liệu cục bộ.

React · JSX
import { createContext, useContext, useState } from 'react';

const ThemeContext = createContext(null);

function ThemeButton() {
  const { dark, toggle } = useContext(ThemeContext);
  return <button onClick={toggle}>{dark ? 'Chế độ sáng' : 'Chế độ tối'}</button>;
}

export default function App() {
  const [dark, setDark] = useState(false);
  return (
    <ThemeContext.Provider
      value={{ dark, toggle: () => setDark(v => !v) }}
    >
      <ThemeButton />
    </ThemeContext.Provider>
  );
}

Trong React 19, bạn cũng có thể viết <ThemeContext value={...}> thay cho <ThemeContext.Provider>; ví dụ trên dùng cách dễ nhận diện trong nhiều codebase.

useReducer cho logic cập nhật phức tạp

React · JSX
import { useReducer } from 'react';

function reducer(state, action) {
  switch (action.type) {
    case 'increment': return { count: state.count + 1 };
    case 'decrement': return { count: state.count - 1 };
    case 'reset': return { count: 0 };
    default: return state;
  }
}

function Counter() {
  const [state, dispatch] = useReducer(reducer, { count: 0 });
  return (
    <>
      <button onClick={() => dispatch({ type: 'decrement' })}>−</button>
      <span>{state.count}</span>
      <button onClick={() => dispatch({ type: 'increment' })}>+</button>
    </>
  );
}

Reducer là hàm thuần, nhận (state, action) và trả về state mới. Kết hợp Context + useReducer khi nhiều nơi phải đọc và gửi action vào cùng logic cập nhật.

Tối ưu hiệu năng đúng cách

Ưu tiên tính đúng trước, đo rồi mới tối ưu. Đa số component nhỏ không cần memo hóa thủ công. React DevTools Profiler giúp nhận diện phần render tốn kém.

  • useMemo cache kết quả tính toán giữa các render khi dependency không đổi.
  • useCallback cache tham chiếu hàm khi dependency không đổi.
  • memo giúp component có thể bỏ qua render do cha nếu props không đổi; không ngăn render do state/context của chính nó.
  • lazy + Suspense chia nhỏ bundle và tải component khi cần.
React · JSX
import { memo, useMemo, useState } from 'react';

const ResultList = memo(function ResultList({ items }) {
  return <ul>{items.map(item => <li key={item.id}>{item.name}</li>)}</ul>;
});

function SearchPage({ products }) {
  const [query, setQuery] = useState('');
  const filtered = useMemo(() =>
    products.filter(item =>
      item.name.toLowerCase().includes(query.toLowerCase())
    ), [products, query]
  );

  return (
    <>
      <input value={query} onChange={e => setQuery(e.target.value)} />
      <ResultList items={filtered} />
    </>
  );
}

React Compiler có thể tự động hóa nhiều tối ưu memo hóa khi được cấu hình phù hợp; vì vậy hãy theo hướng dẫn hiện hành của dự án trước khi thêm useMemo/useCallback tràn lan.

React · JSX
import { lazy, Suspense } from 'react';

const ReportsPage = lazy(() => import('./ReportsPage.jsx'));

function App() {
  return (
    <Suspense fallback={<p>Đang tải báo cáo...</p>}>
      <ReportsPage />
    </Suspense>
  );
}

Những API mới trong React 19

React 19.3 (09/09/2026) là bản React mới nhất được đối chiếu khi biên soạn trang này. Hãy nắm chắc component, state và Effect trước, sau đó khám phá những API hiện đại dưới đây.

Form Actions và useActionState

React 19 cho phép truyền một hàm vào action của <form>. useActionState giúp theo dõi kết quả và trạng thái pending của form action.

React · JSX
import { useActionState } from 'react';

async function saveName(previousState, formData) {
  const name = String(formData.get('name') || '').trim();
  if (!name) return { message: 'Bạn chưa nhập tên.', ok: false };

  // Thay bằng gọi API ở dự án thật.
  await new Promise(resolve => setTimeout(resolve, 500));
  return { message: `Đã lưu: ${name}`, ok: true };
}

function NameForm() {
  const [state, action, isPending] = useActionState(
    saveName, { message: '', ok: false }
  );

  return (
    <form action={action}>
      <input name="name" aria-label="Tên" />
      <button disabled={isPending}>
        {isPending ? 'Đang lưu...' : 'Lưu'}
      </button>
      <p role="status">{state.message}</p>
    </form>
  );
}

useOptimistic hỗ trợ hiển thị kết quả dự đoán ngay trong lúc chờ tác vụ async; use giúp đọc tài nguyên như Promise/Context trong điều kiện phù hợp với Suspense.

React 19.3 có gì đáng chú ý?

  • <ViewTransition> và Fragment Refs đã trở thành API ổn định trong React 19.3.
  • API View Transition hỗ trợ hiệu ứng khi phần giao diện xuất hiện, biến mất, đổi vị trí hoặc kích thước trong các cập nhật Transition; cần hiểu thêm CSS/khả năng trình duyệt.
  • Đối với app đầu tiên, các API này là kiến thức mở rộng, không phải điều kiện bắt buộc.

Dự án thực hành: Todo App hoàn chỉnh

Bây giờ ghép các kiến thức: component + state + input + list + key + event + derived state + localStorage. Dự án có thêm việc, đánh dấu hoàn thành, xóa, lọc và lưu sau khi tải lại trang.

Bước 1 — Thay nội dung src/App.jsx

React · JSX
import { useEffect, useState } from 'react';
import './App.css';

const STORAGE_KEY = 'react-todo-tutorial-v1';

function loadInitialTasks() {
  try {
    const saved = localStorage.getItem(STORAGE_KEY);
    return saved ? JSON.parse(saved) : [];
  } catch {
    return [];
  }
}

export default function App() {
  const [tasks, setTasks] = useState(loadInitialTasks);
  const [text, setText] = useState('');
  const [filter, setFilter] = useState('all');

  useEffect(() => {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(tasks));
  }, [tasks]);

  function addTask(event) {
    event.preventDefault();
    const title = text.trim();
    if (!title) return;
    setTasks(prev => [
      { id: crypto.randomUUID(), title, done: false },
      ...prev,
    ]);
    setText('');
  }

  function toggleTask(id) {
    setTasks(prev => prev.map(task =>
      task.id === id ? { ...task, done: !task.done } : task
    ));
  }

  function removeTask(id) {
    setTasks(prev => prev.filter(task => task.id !== id));
  }

  const visibleTasks = tasks.filter(task =>
    filter === 'all' ||
    (filter === 'active' && !task.done) ||
    (filter === 'done' && task.done)
  );
  const remaining = tasks.filter(task => !task.done).length;

  return (
    <main className="todo-app">
      <h1>✅ Việc cần làm</h1>
      <p>Còn {remaining} công việc chưa hoàn thành.</p>

      <form className="add-form" onSubmit={addTask}>
        <label htmlFor="new-task">Công việc mới</label>
        <div className="add-row">
          <input
            id="new-task"
            value={text}
            onChange={e => setText(e.target.value)}
            placeholder="Ví dụ: Đọc React 30 phút"
          />
          <button type="submit">Thêm</button>
        </div>
      </form>

      <div className="filters" aria-label="Lọc công việc">
        {[
          ['all', 'Tất cả'],
          ['active', 'Chưa xong'],
          ['done', 'Đã xong'],
        ].map(([value, label]) => (
          <button
            key={value}
            type="button"
            aria-pressed={filter === value}
            onClick={() => setFilter(value)}
          >
            {label}
          </button>
        ))}
      </div>

      {visibleTasks.length === 0 ? (
        <p className="empty">Chưa có công việc phù hợp.</p>
      ) : (
        <ul className="task-list">
          {visibleTasks.map(task => (
            <li key={task.id}>
              <label className={task.done ? 'done' : ''}>
                <input
                  type="checkbox"
                  checked={task.done}
                  onChange={() => toggleTask(task.id)}
                />
                <span>{task.title}</span>
              </label>
              <button
                type="button"
                onClick={() => removeTask(task.id)}
                aria-label={`Xóa ${task.title}`}
              >
                Xóa
              </button>
            </li>
          ))}
        </ul>
      )}
    </main>
  );
}
