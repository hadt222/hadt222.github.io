NỀN TẢNG

01. Pandas là gì?

Hiểu bức tranh tổng thể trước khi viết dòng mã đầu tiên.

Pandas là thư viện mã nguồn mở của Python dùng để xử lý, biến đổi và phân tích dữ liệu dạng bảng. Hai kiểu dữ liệu quan trọng nhất là Series (một chiều) và DataFrame (hai chiều).

1D

Series

Một cột dữ liệu có nhãn chỉ mục (index).

Ví dụ: doanh thu từng đơn
2D

DataFrame

Bảng gồm nhiều hàng và cột, mỗi cột có thể có kiểu dữ liệu riêng.

Ví dụ: bảng đơn hàng

Quy trình phân tích điển hình

Đọc dữ liệu→Khám phá→Làm sạch→Phân tích→Xuất kết quả

Phù hợp với CSV/Excel, báo cáo kinh doanh, dữ liệu sự kiện, dữ liệu thời gian và bước tiền xử lý trước khi trực quan hóa hoặc học máy.

06. Chọn cột, chọn dòng và lọc

Làm chủ sự khác nhau giữa loc và iloc — kỹ năng dùng hằng ngày.

Python
df["san_pham"]                       # Một cột -> Series
df[["san_pham", "doanh_thu"]]      # Nhiều cột -> DataFrame

df.loc[0, "san_pham"]              # Theo nhãn hàng/cột
df.loc[0:2, ["ma_don", "san_pham"]] # Nhãn 0,1,2 (bao gồm điểm cuối)

df.iloc[0, 3]                      # Theo vị trí: hàng 0, cột 3
df.iloc[0:3, 0:4]                  # Vị trí hàng 0,1,2; cột 0..3

df.loc[df["khu_vuc"] == "Bắc"]
df.loc[(df["khu_vuc"] == "Bắc") &
       (df["doanh_thu"] >= 400_000), ["ma_don", "doanh_thu"]]

df.loc[df["san_pham"].isin(["Áo", "Giày"])]
df.loc[df["san_pham"].str.contains("áo", case=False, na=False)]
df.query("doanh_thu > 500000")
.loc[] — nhãn

Dùng tên cột, nhãn index và biểu thức boolean. Lát cắt nhãn thường bao gồm điểm kết thúc.

.iloc[] — vị trí

Dùng số nguyên từ 0. Lát cắt theo vị trí giống Python: không lấy điểm kết thúc.

!
Lỗi thường gặp

Dùng & và | cho điều kiện trên Series; đặt mỗi điều kiện trong ngoặc. Không dùng and/or để kết hợp hai Series.

08. Làm sạch dữ liệu thiếu và trùng

Kiểm tra null, chuyển kiểu, xóa bản ghi trùng và xử lý phù hợp nghiệp vụ.

Python
raw = pd.DataFrame({
    "ten": ["An", "Bình", "Bình", None],
    "tuoi": [25, "30", "30", "không rõ"],
    "diem": [8.5, None, None, 7.0]
})

raw.isna().sum()             # Đếm giá trị thiếu theo từng cột
raw.duplicated().sum()       # Đếm dòng trùng hoàn toàn

# Chuẩn hóa kiểu số; dữ liệu không hợp lệ -> NaN
raw["tuoi"] = pd.to_numeric(raw["tuoi"], errors="coerce")

# Tạo bản mới; chỉ thay thế thiếu cho cột điểm
clean = raw.drop_duplicates().copy()
clean["diem"] = clean["diem"].fillna(clean["diem"].median())
clean = clean.dropna(subset=["ten"])

# Một số lựa chọn khác
# clean = clean.fillna({"diem": 0})
# clean = clean.dropna()  # Bỏ dòng nếu có bất kỳ ô thiếu

Thứ tự phổ biến: kiểm tra → hiểu lý do thiếu → chuẩn hóa kiểu → xử lý trùng → điền/xóa có chủ đích. Không nên mặc định điền 0 cho doanh thu, số lượng hoặc điểm khi chưa hiểu ý nghĩa nghiệp vụ.

11. GroupBy — tổng hợp theo nhóm

Từ dữ liệu giao dịch sang báo cáo doanh thu theo khu vực hoặc sản phẩm.

# Tổng doanh thu từng khu vực
vung = df.groupby("khu_vuc", as_index=False).agg(
    so_don=("ma_don", "count"),
    tong_doanh_thu=("doanh_thu", "sum"),
    gia_tri_don_tb=("doanh_thu", "mean")
)
print(vung.sort_values("tong_doanh_thu", ascending=False))

# Nhiều khóa nhóm
chi_tiet = df.groupby(["khu_vuc", "san_pham"], as_index=False).agg(
    doanh_thu=("doanh_thu", "sum")
)

# transform: trả về kết quả có cùng số dòng như ban đầu
df["tong_theo_vung"] = df.groupby("khu_vuc")["doanh_thu"].transform("sum")
df["ty_trong_trong_vung"] = df["doanh_thu"] / df["tong_theo_vung"]

agg() thường rút gọn thành một dòng mỗi nhóm; transform() trả lại dữ liệu có cùng độ dài với bảng gốc để so sánh từng dòng với nhóm.

13. Pivot, melt và định dạng bảng

Chuyển đổi giữa dữ liệu dạng dài (long) và dạng rộng (wide).

Python
# Bảng chéo: dòng = khu vực, cột = sản phẩm
goc_nhin = pd.pivot_table(
    df,
    index="khu_vuc",
    columns="san_pham",
    values="doanh_thu",
    aggfunc="sum",
    fill_value=0
)

# Chuyển các cột đo lường thành cặp (chi_so, gia_tri)
dang_dai = df.melt(
    id_vars=["ma_don", "khu_vuc"],
    value_vars=["so_luong", "doanh_thu"],
    var_name="chi_so",
    value_name="gia_tri"
)

# Bảng tần suất khu vực x sản phẩm
bang_dem = pd.crosstab(df["khu_vuc"], df["san_pham"])

pivot() phù hợp khi mỗi cặp khóa xác định một giá trị duy nhất; pivot_table() hỗ trợ tổng hợp khi có nhiều dòng trùng khóa.

14. Phân tích dữ liệu thời gian

Tổng hợp theo tháng và tính trung bình trượt.

Python
# Đặt ngày làm index và sắp xếp trước khi xử lý thời gian
chuoi = df.sort_values("ngay").set_index("ngay")

# Tổng doanh thu theo đầu tháng (Month Start)
theo_thang = chuoi["doanh_thu"].resample("MS").sum()

# Tổng doanh thu theo ngày; ngày không có đơn trong phạm vi được điền 0
theo_ngay = chuoi["doanh_thu"].resample("D").sum()

# Trung bình trượt 3 ngày, yêu cầu ít nhất 1 quan sát
trung_binh_truot = theo_ngay.rolling(window=3, min_periods=1).mean()

# Lọc khoảng thời gian
thang_mot = chuoi.loc["2026-01-01":"2026-01-31"]
i
resample() và groupby()

resample() chuyên cho nhóm theo khoảng thời gian, thường làm việc với DatetimeIndex; groupby() tổng quát hơn cho khóa nhóm bất kỳ.

17. Mini project: báo cáo doanh số

Chạy một ví dụ hoàn chỉnh từ đọc CSV đến xuất báo cáo.

Dự án đọc dữ liệu CSV ngay trong mã nguồn bằng StringIO, vì thế bạn không cần tải file đầu vào. Một đơn hàng thiếu số lượng sẽ được loại khỏi báo cáo và ghi nhận là dữ liệu cần kiểm tra.

Python
from io import StringIO
import pandas as pd

csv_text = """ma_don,ngay,khu_vuc,san_pham,so_luong,don_gia
1,2026-02-01,Bắc,Áo,2,150000
2,2026-02-01,Nam,Giày,1,650000
3,2026-02-02,Bắc,Áo,3,150000
4,2026-02-02,Trung,Quần,2,300000
5,2026-02-03,Nam,Giày,,650000
6,2026-02-03,Bắc,Quần,1,300000
"""

orders = pd.read_csv(StringIO(csv_text), parse_dates=["ngay"])
print("Dòng ban đầu:", len(orders))

# Thiếu số lượng: loại khỏi báo cáo để tránh tự ý coi là 0
orders = orders.dropna(subset=["so_luong"]).copy()
orders["so_luong"] = orders["so_luong"].astype("int64")
orders["doanh_thu"] = orders["so_luong"] * orders["don_gia"]

report = (
    orders.groupby("khu_vuc", as_index=False)
    .agg(so_don=("ma_don", "count"), doanh_thu=("doanh_thu", "sum"))
    .sort_values("doanh_thu", ascending=False)
)

print(report)
print("Tổng:", orders["doanh_thu"].sum())
assert orders["doanh_thu"].sum() == 2_300_000
report.to_csv("bao_cao_thang_2.csv", index=False, encoding="utf-8-sig")
KẾT QUẢ MONG ĐỢI2.300.000 VND

5 đơn hợp lệ · Bắc: 1.050.000 · Nam: 650.000 · Trung: 600.000

Gợi ý mở rộng: thêm doanh thu theo ngày, top sản phẩm, tỷ lệ đóng góp từng khu vực và biểu đồ cột. Trước khi loại dữ liệu thật, nên lưu log hoặc báo cáo các dòng bị thiếu để đối soát.
