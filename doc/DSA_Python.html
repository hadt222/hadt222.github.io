NỀN TẢNG 01

Bắt đầu: tư duy DSA

DSA (Data Structures & Algorithms) giúp lưu trữ dữ liệu hợp lý và giải bài toán nhanh, đúng, có thể mở rộng.

Một cấu trúc dữ liệu quy định cách tổ chức dữ liệu (list, hash table, cây, đồ thị…). Một thuật toán là dãy bước rõ ràng biến đầu vào thành kết quả (tìm kiếm, sắp xếp, duyệt, tối ưu…). Hai phần luôn đi cùng nhau: chọn cấu trúc dữ liệu đúng thường quyết định tốc độ thuật toán.

Cách học mỗi chủ đề

  1. Hiểu bài toán: đầu vào/đầu ra, điều kiện, ví dụ và trường hợp biên.
  2. Chọn cấu trúc dữ liệu: cần truy cập theo chỉ số, tra cứu khóa, lấy min hay duyệt quan hệ?
  3. Viết lời giải đúng: bất biến, trường hợp rỗng, trùng lặp, số âm.
  4. Phân tích thời gian và bộ nhớ: từ n nhỏ đến n rất lớn.
  5. Thực hành: tự code, test ngẫu nhiên, so với cách brute force.

Chuẩn bị Python

Python 3.10+ · mẫu chạy thử
def solve(nums: list[int]) -> int:
    """Trả về tổng các phần tử dương."""
    return sum(x for x in nums if x > 0)

if __name__ == "__main__":
    data = [-2, 3, 0, 5]
    assert solve(data) == 8
    print(solve(data))  # 8
✓
Quy ước trong tài liệu

n là kích thước đầu vào; V là số đỉnh và E là số cạnh; mã viết cho Python 3.10+; Big-O thường biểu diễn cận trên trong trường hợp xấu nhất, trừ khi ghi rõ.

Độ phức tạp và Big-O

Ước lượng tốc độ tăng chi phí khi đầu vào lớn; đây là kỹ năng cốt lõi trong mọi bài DSA.

O, Ω, Θ và các mức tăng trưởng

O(f(n)) là cận trên tiệm cận; Ω(f(n)) là cận dưới; Θ(f(n)) là cận chặt. Ví dụ, quét một mảng n phần tử có thời gian Θ(n).

Cách tính từ mã

Đếm số phép toán tăng theo n
def pair_count(a):
    n = len(a)
    count = 0
    for i in range(n):
        for j in range(i + 1, n):
            count += 1
    return count

print(pair_count([1, 2, 3, 4]))  # 6 = n(n-1)/2

Có khoảng n²/2 cặp, bỏ hằng số và bậc thấp ⇒ O(n²). Hai vòng lặp nối tiếp O(n) + O(n) vẫn là O(n), không phải O(n²).

Thời gian và không gian; amortized

  • Space complexity: bộ nhớ phụ thêm. Tạo mảng sao chép n phần tử dùng O(n); chỉ dùng vài biến dùng O(1).
  • Worst / average / best: tìm tuyến tính có worst O(n), best O(1).
  • Amortized: list.append thường O(1) trung bình phân bổ dù đôi lúc phải cấp phát lại O(n).
  • Đệ quy: nhớ chi phí call stack. Hàm đệ quy sâu n có thể tốn O(n) bộ nhớ ngăn xếp.
  • Đệ quy chia đôi: thường có dạng T(n)=2T(n/2)+O(n) ⇒ O(n log n).
✦
Đừng đánh giá chỉ bằng Big-O

Hằng số và đặc điểm dữ liệu thực tế vẫn quan trọng. Với n nhỏ, cách O(n²) đơn giản có thể nhanh hơn thuật toán O(n log n) phức tạp.

Duyệt, đổi chỗ, xoay mảng

Đảo mảng tại chỗ / xoay phải k bước
def reverse_range(a, left, right):
    while left < right:
        a[left], a[right] = a[right], a[left]
        left += 1
        right -= 1

def rotate_right(a, k):
    n = len(a)
    if n == 0:
        return a
    k %= n
    reverse_range(a, 0, n - 1)
    reverse_range(a, 0, k - 1)
    reverse_range(a, k, n - 1)
    return a

assert rotate_right([1, 2, 3, 4, 5], 2) == [4, 5, 1, 2, 3]

O(n) thời gian, O(1) bộ nhớ phụ.

KỸ THUẬT MẢNG 05

Two pointers và sliding window

Hai mẫu thường rút thuật toán O(n²) xuống O(n) cho mảng/chuỗi.

Two pointers: cặp tổng trong mảng đã sort

Tìm hai số có tổng target
def two_sum_sorted(a, target):
    left, right = 0, len(a) - 1
    while left < right:
        s = a[left] + a[right]
        if s == target:
            return (left, right)
        if s < target:
            left += 1
        else:
            right -= 1
    return None

assert two_sum_sorted([1, 2, 4, 6, 9], 10) == (0, 4)

Vì mảng tăng dần, điều chỉnh con trỏ vẫn đảm bảo không bỏ sót cặp. O(n) thời gian, O(1) bộ nhớ.

Sliding window cố định: tổng k phần tử liên tiếp lớn nhất

Fixed-size sliding window
def max_window_sum(a, k):
    if not 1 <= k <= len(a):
        raise ValueError("k phải nằm trong [1, len(a)]")
    cur = sum(a[:k])
    best = cur
    for right in range(k, len(a)):
        cur += a[right] - a[right - k]
        best = max(best, cur)
    return best

assert max_window_sum([2, 1, 5, 1, 3, 2], 3) == 9

Sliding window biến độ dài: chuỗi con không lặp

Longest substring without repeats
def longest_unique_substring(s):
    last = {}
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1
        last[ch] = right
        best = max(best, right - left + 1)
    return best

assert longest_unique_substring("abcabcbb") == 3
assert longest_unique_substring("") == 0

Mỗi vị trí được xử lý số lần hằng số ⇒ O(n) thời gian; O(min(n, số ký tự khác nhau)) bộ nhớ.

!
Điều kiện quan trọng

Sliding window kiểu “nới right rồi thu left để tổng ≤ K” chỉ hoạt động trực tiếp khi tổng có tính đơn điệu phù hợp (ví dụ các phần tử không âm). Với số âm, thường cần prefix sum và cấu trúc khác.

?Độ dài nhỏ nhất có tổng ≥ S

Mảng gồm toàn số nguyên dương, hãy tìm độ dài đoạn liên tiếp ngắn nhất có tổng ≥ S.

Xem gợi ý
Mở rộng right; khi tổng đủ lớn, thu hẹp left liên tục.
Xem hướng giải
Dùng sliding window hai con trỏ, cập nhật ans = min(ans, right-left+1) trước khi bỏ phần tử tại left. O(n).

Prefix sum, difference array và khoảng

Tiền xử lý để trả lời nhiều truy vấn đoạn con nhanh.

Prefix sum: truy vấn tổng [l, r)

Tiền tố và truy vấn O(1)
def prefix_sums(a):
    pref = [0]
    for x in a:
        pref.append(pref[-1] + x)
    return pref

a = [2, -1, 4, 3]
pref = prefix_sums(a)
assert pref[3] - pref[1] == 3  # a[1:3] = -1 + 4

Tạo prefix O(n) thời gian/bộ nhớ; mỗi truy vấn O(1). Với 2D, công thức cộng-trừ các hình chữ nhật tương tự.

Difference array: cộng v cho nhiều đoạn [l, r]

Range increment offline
def range_add(n, updates):
    diff = [0] * (n + 1)
    for l, r, value in updates:  # l và r inclusive
        diff[l] += value
        diff[r + 1] -= value
    result, run = [], 0
    for i in range(n):
        run += diff[i]
        result.append(run)
    return result

assert range_add(5, [(1, 3, 2), (2, 4, 1)]) == [0, 2, 3, 3, 1]

Áp dụng m cập nhật rồi khôi phục một lần: O(n+m). Nếu cần truy vấn xen kẽ với cập nhật, xem Fenwick/segment tree.

Merge intervals

Gộp các khoảng giao nhau / chạm nhau
def merge_intervals(intervals):
    if not intervals:
        return []
    intervals = sorted(intervals)
    ans = [list(intervals[0])]
    for start, end in intervals[1:]:
        if start <= ans[-1][1]:
            ans[-1][1] = max(ans[-1][1], end)
        else:
            ans.append([start, end])
    return ans

assert merge_intervals([(1, 3), (2, 6), (8, 10)]) == [[1, 6], [8, 10]]

Sắp xếp O(n log n), duyệt O(n). Với khoảng nửa mở [start,end), quy tắc “chạm nhau” có thể khác tùy bài toán.

CẤU TRÚC DỮ LIỆU 07

Linked list: danh sách liên kết

Các node nối bằng con trỏ; thao tác đầu danh sách nhanh nhưng không hỗ trợ truy cập theo chỉ số O(1).

Đơn liên kết, đảo và chu trình

Node, reverse, phát hiện cycle
class ListNode:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next

def reverse_list(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev, cur = cur, nxt
    return prev

def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False

head = ListNode(1, ListNode(2, ListNode(3)))
rev = reverse_list(head)
assert (rev.val, rev.next.val, rev.next.next.val) == (3, 2, 1)
assert has_cycle(rev) is False

Đảo: O(n) thời gian và O(1) bộ nhớ. Floyd slow/fast tìm chu trình O(n) thời gian, O(1) bộ nhớ.

CẤU TRÚC DỮ LIỆU 08

Stack, queue và deque

Hai cấu trúc nền tảng để duyệt cây/đồ thị, kiểm tra cú pháp và lập lịch.

Stack LIFO: ngoặc hợp lệ

Dùng list làm stack
def valid_parentheses(s):
    pairs = {')': '(', ']': '[', '}': '{'}
    opens = set(pairs.values())
    stack = []
    for ch in s:
        if ch in opens:
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack

assert valid_parentheses("({[]})")
assert not valid_parentheses("([)]")

Mỗi ký tự push/pop tối đa một lần ⇒ O(n) thời gian, O(n) bộ nhớ worst-case.

Queue FIFO và BFS tư duy mức

Dùng deque làm queue

queue.append("C")
assert queue.popleft() == "A"

Monotonic stack: phần tử lớn hơn tiếp theo

Next greater element to the right
def next_greater(a):
    ans = [-1] * len(a)
    stack = []  # các chỉ số có giá trị giảm dần
    for i, x in enumerate(a):
        while stack and a[stack[-1]] < x:
            ans[stack.pop()] = x
        stack.append(i)
    return ans

assert next_greater([2, 1, 2, 4, 3]) == [4, 2, 4, -1, -1]

Mỗi chỉ số push và pop nhiều nhất một lần ⇒ O(n), không phải O(n²) dù có while lồng trong for.

Monotonic deque: max của mỗi cửa sổ k

Sliding window maximum O(n)
from collections import deque

def max_sliding_window(a, k):
    if not 1 <= k <= len(a):
        return []
    dq, ans = deque(), []  # lưu chỉ số; a[dq] giảm dần
    for i, x in enumerate(a):
        while dq and dq[0] <= i - k:
            dq.popleft()
        while dq and a[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if i >= k - 1:
            ans.append(a[dq[0]])
    return ans

assert max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3) == [3, 3, 5, 5, 6, 7]
CẤU TRÚC DỮ LIỆU 09

Hash table, dict, set và tần suất

Tra cứu rất nhanh trung bình; nhóm công cụ thường giúp biến O(n²) thành O(n).

Hash table hoạt động như thế nào?

Hàm hash chuyển khóa thành giá trị nguyên; bảng băm dùng kết quả này để xác định vị trí lưu. Nhiều khóa có thể va chạm (collision), nên hệ thống có cơ chế xử lý.     return None

        else:
            hi = mid

    return lo

def bubble_sort(a):
    a = a.copy()
    for end in range(len(a) - 1, 0, -1):
        swapped = False
        for i in range(end):
            if a[i] > a[i + 1]:
                a[i], a[i + 1] = a[i + 1], a[i]
                swapped = True
        if not swapped:
            break
    return a

def selection_sort(a):
    a = a.copy()
    for i in range(len(a)):
        m = min(range(i, len(a)), key=lambda j: a[j])
        a[i], a[m] = a[m], a[i]
    return a

def insertion_sort(a):
    a = a.copy()
    for i in range(1, len(a)):
        key, j = a[i], i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a

def merge_sort(a):
    if len(a) <= 1:
        return a[:]
    mid = len(a) // 2
    left = merge_sort(a[:mid])
    right = merge_sort(a[mid:])
    i = j = 0
    out = []
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    return out + left[i:] + right[j:]

assert merge_sort([5, 1, 4, 2, 8]) == [1, 2, 4, 5, 8]

def quick_sort(a):
    if len(a) <= 1:
        return a[:]
    pivot = a[len(a) // 2]
    smaller = [x for x in a if x < pivot]
    equal = [x for x in a if x == pivot]
    larger = [x for x in a if x > pivot]
    return quick_sort(smaller) + equal + quick_sort(larger)

def counting_sort(a):
    if not a:
        return []
    if min(a) < 0:
        raise ValueError("Chỉ nhận số không âm")
    freq = [0] * (max(a) + 1)
    for x in a:
        freq[x] += 1
    return [x for x, count in enumerate(freq) for _ in range(count)]

Backtracking subsets
def subsets(a):
    ans, path = [], []
    def dfs(i):
        if i == len(a):
            ans.append(path.copy())
            return
        dfs(i + 1)  # Không lấy a[i]
        path.append(a[i])
        dfs(i + 1)  # Lấy a[i]
        path.pop()  # Undo
    dfs(0)
    return ans

assert len(subsets([1, 2, 3])) == 8

Có 2ⁿ tập con; thời gian tạo toàn bộ kết quả Θ(n·2ⁿ) nếu tính chi phí sao chép mỗi tập con, không tính riêng bộ nhớ đầu ra thì stack/path O(n).

def count_n_queens(n):
    if n < 0:
        raise ValueError("n không âm")
    cols, diag1, diag2 = set(), set(), set()
    def dfs(row):
        if row == n:
            return 1
        count = 0
        for col in range(n):
            d1, d2 = row - col, row + col
            if col in cols or d1 in diag1 or d2 in diag2:
                continue
            cols.add(col); diag1.add(d1); diag2.add(d2)
            count += dfs(row + 1)
            cols.remove(col); diag1.remove(d1); diag2.remove(d2)
        return count
    return dfs(0)

assert count_n_queens(4) == 2

Không gian O(n) cho các tập và stack; tìm kiếm theo số cấu hình khả thi, cận trên đơn giản O(n!) nút ứng viên (nhân chi phí duyệt cột).

Binary tree traversals
from collections import deque

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def inorder(root):
    result = []
    stack, cur = [], root
    while stack or cur:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        result.append(cur.val)
        cur = cur.right
    return result

def level_order(root):
    if not root:
        return []
    q = deque([root])
    result = []
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
        result.append(level)
    return result

root = TreeNode(2, TreeNode(1), TreeNode(3))
assert inorder(root) == [1, 2, 3]
assert level_order(root) == [[2], [1, 3]]

Duyệt tất cả n nút O(n). Inorder lặp dùng O(h) stack (h là chiều cao); level-order dùng O(w) queue (w là độ rộng cực đại).

def k_largest(a, k):
    if not 0 <= k <= len(a):
        raise ValueError("k không hợp lệ")
    heap = []
    for x in a:
        if len(heap) < k:
            heapq.heappush(heap, x)
        elif k and x > heap[0]:
            heapq.heapreplace(heap, x)
    return sorted(heap, reverse=True)

Trie insert, search, starts_with
class Trie:
    def __init__(self):
        self.root = {}

    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node["#"] = True  # Giả định dấu # không nằm trong từ

    def search(self, word):
        node = self.root
        for ch in word:
            if ch not in node:
                return False
            node = node[ch]
        return "#" in node

    def starts_with(self, prefix):
        node = self.root
        for ch in prefix:
            if ch not in node:
                return False
            node = node[ch]
        return True

t = Trie()
t.insert("cat"); t.insert("car")

Fenwick tree (Binary Indexed Tree): cộng điểm, tổng tiền tố

Fenwick: add và prefix_sum O(log n)
class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, index, delta):  # index 0-based
        i = index + 1
        while i <= self.n:
            self.bit[i] += delta
            i += i & -i

    def prefix_sum(self, end):  # tổng [0, end)
        total, i = 0, end
        while i > 0:
            total += self.bit[i]
            i -= i & -i
        return total

    def range_sum(self, left, right):  # [left, right)
        return self.prefix_sum(right) - self.prefix_sum(left)

fw = Fenwick(5)
for i, x in enumerate([1, 2, 3, 4, 5]):
    fw.add(i, x)
assert fw.range_sum(1, 4) == 9
fw.add(2, 10)
assert fw.range_sum(1, 4) == 19

Bộ nhớ O(n); build qua từng add là O(n log n), có cách build O(n). Dùng cho tổng/xử lý tần suất tích lũy.

Segment tree: range sum và point update

Segment tree dạng lặp 2n ô
class SegmentTree:
    def __init__(self, a):
        self.n = len(a)
        self.tree = [0] * (2 * self.n)
        self.tree[self.n:] = a[:]
        for i in range(self.n - 1, 0, -1):
            self.tree[i] = self.tree[2*i] + self.tree[2*i+1]

    def update(self, i, value):
        i += self.n
        self.tree[i] = value
        while i > 1:
            i //= 2
            self.tree[i] = self.tree[2*i] + self.tree[2*i+1]

    def query(self, left, right):  # [left, right)
        left += self.n; right += self.n
        result = 0
        while left < right:
            if left & 1:
                result += self.tree[left]; left += 1
            if right & 1:
                right -= 1; result += self.tree[right]
            left //= 2; right //= 2
        return result

st = SegmentTree([1, 2, 3, 4])
assert st.query(1, 4) == 9
st.update(2, 10)
assert st.query(1, 4) == 16

Build O(n), cập nhật/truy vấn O(log n), bộ nhớ O(n). Với cập nhật nguyên một đoạn, dùng lazy propagation (nâng cao).

Topological sort: Kahn

Thứ tự topo của đồ thị có hướng không chu trình (DAG) đảm bảo u đứng trước v cho mọi cạnh u → v. Nếu kết quả ít hơn V đỉnh, đồ thị có chu trình.

Sắp xếp topo bằng indegree
from collections import deque

def topological_sort(n, edges):
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        adj[u].append(v)
        indeg[v] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else None

assert topological_sort(4, [(0, 1), (0, 2), (1, 3), (2, 3)]) == [0, 1, 2, 3]
assert topological_sort(2, [(0, 1), (1, 0)]) is None

from collections import deque

def is_bipartite(g):
    color = [-1] * len(g)
    for start in range(len(g)):
        if color[start] != -1:
            continue
        q = deque([start])
        color[start] = 0
        while q:
            u = q.popleft()
            for v in g[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    return False
    return True

Shortest path weighted directed graph
import heapq

def dijkstra(graph, start):
    n = len(graph)
    dist = [float("inf")] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d != dist[u]:
            continue  # loại trạng thái lỗi thời
        for v, w in graph[u]:
            if w < 0:
                raise ValueError("Dijkstra cần trọng số >= 0")
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

Bellman-Ford và chu trình âm

Relax cạnh V−1 lần
def bellman_ford(n, edges, start):
    dist = [float("inf")] * n
    dist[start] = 0
    for _ in range(n - 1):
        changed = False
        for u, v, w in edges:
            if dist[u] != float("inf") and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                changed = True
        if not changed:
            break
    for u, v, w in edges:
        if dist[u] != float("inf") and dist[u] + w < dist[v]:
            raise ValueError("Có chu trình âm đi tới được từ start")
    return dist

assert bellman_ford(3, [(0, 1, 4), (0, 2, 5), (1, 2, -2)], 0) == [0, 4, 2]

O(VE) thời gian, O(V) bộ nhớ. Phát hiện chu trình âm đi tới được từ nguồn.

Floyd-Warshall: mọi cặp đỉnh

Dynamic programming theo đỉnh trung gian
def floyd_warshall(n, edges):
    inf = float("inf")
    dist = [[inf] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    for u, v, w in edges:
        dist[u][v] = min(dist[u][v], w)
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    return dist

assert D[0][2] == 5

O(V³) thời gian, O(V²) bộ nhớ. Nếu có dist[i][i] < 0, có chu trình âm. Với chu trình âm, một số khoảng cách ngắn nhất không xác định hữu hạn.

Disjoint Set Union với path compression + union by size

DSU gần O(1) amortized
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True

assert uf.union(0, 1)
assert uf.union(1, 2)
assert not uf.union(0, 2)

Mỗi thao tác có độ phức tạp amortized O(α(n)), α là hàm Ackermann đảo, tăng cực chậm.

Kruskal: chọn cạnh nhẹ nhất không tạo chu trình

MST / minimum spanning forest
def kruskal(n, edges):
    """edges: (weight, u, v); đồ thị vô hướng."""
    dsu = DSU(n)
    total = 0
    chosen = []
    for w, u, v in sorted(edges):
        if dsu.union(u, v):
            total += w
            chosen.append((u, v, w))
    return total, chosen

    (1, 0, 1), (4, 0, 2), (2, 1, 2),
    (3, 1, 3), (5, 2, 3)
])
assert weight == 6 and len(selected) == 3

Prim bắt đầu từ một đỉnh, luôn chọn cạnh nhẹ nhất nối từ tập đỉnh đã chọn sang đỉnh chưa chọn. Với adjacency list + heap: O(E log V) thường dùng. Kruskal thuận tiện khi có danh sách cạnh; Prim hợp lý khi mở rộng từ vùng đã thăm.

def max_nonoverlapping(intervals):
    # Dùng các khoảng nửa mở [start, end)
    intervals = sorted(intervals, key=lambda x: x[1])
    result = []
    last_end = float("-inf")
    for start, end in intervals:
        if start >= last_end:
            result.append((start, end))
            last_end = end
    return result

def coin_change(coins, amount):
    inf = amount + 1
    dp = [inf] * (amount + 1)
    dp[0] = 0
    for value in range(1, amount + 1):
        for coin in coins:
            if coin > 0 and value >= coin:
                dp[value] = min(dp[value], dp[value - coin] + 1)
    return -1 if dp[amount] == inf else dp[amount]

0/1 knapsack: mỗi món chỉ chọn một lần

Nén DP 2D xuống 1D
def knapsack_01(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for w, v in zip(weights, values):
        for c in range(capacity, w - 1, -1):
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[capacity]

assert knapsack_01([2, 3, 4], [4, 5, 6], 5) == 9

from bisect import bisect_left

def lis_length(a):

    for x in a:
        i = bisect_left(tails, x)
        if i == len(tails):

        else:
            tails[i] = x
    return len(tails)

DP 2D: LCS, edit distance và grid

Trạng thái có hai chỉ số thường biểu diễn hai tiền tố, hai trục hoặc tập lựa chọn.

Longest common subsequence (LCS)

Độ dài dãy con chung dài nhất
def lcs_length(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]

assert lcs_length("abcde", "ace") == 3

O(mn) thời gian/bộ nhớ. Subsequence không cần liên tiếp, khác substring.

Edit distance (Levenshtein)

Chèn / xóa / thay ký tự, mỗi phép tốn 1
def edit_distance(a, b):
    n = len(b)
    prev = list(range(n + 1))
    for i, ca in enumerate(a, 1):
        cur = [i] + [0] * n
        for j, cb in enumerate(b, 1):
            if ca == cb:
                cur[j] = prev[j - 1]
            else:
                cur[j] = 1 + min(prev[j], cur[j - 1], prev[j - 1])
        prev = cur
    return prev[n]

assert edit_distance("kitten", "sitting") == 3

O(mn) thời gian, O(n) bộ nhớ nhờ giữ hai hàng.

Grid paths với vật cản

Đếm đường đi chỉ sang phải hoặc xuống
def count_paths(grid):
    if not grid or not grid[0]:
        return 0
    rows, cols = len(grid), len(grid[0])
    dp = [0] * cols
    dp[0] = 0 if grid[0][0] == 1 else 1
    for row in grid:
        for j, cell in enumerate(row):
            if cell == 1:
                dp[j] = 0
            elif j > 0:
                dp[j] += dp[j - 1]
    return dp[-1]

assert count_paths([[0, 0, 0], [0, 1, 0], [0, 0, 0]]) == 2

0 = trống, 1 = vật cản; O(rows·cols) thời gian và O(cols) bộ nhớ. Grid phải là hình chữ nhật.

Các biến thể DP nâng cao

  • Interval DP: dp[l][r], ví dụ matrix-chain multiplication, burst balloons.
  • Tree DP: truyền trạng thái giữa node và cây con, ví dụ chọn tập node độc lập.
  • Bitmask DP: dp[mask][last], ví dụ Travelling Salesperson với n nhỏ, O(n²·2ⁿ).
  • Digit DP: đếm số thỏa điều kiện trong đoạn [0,N] theo chữ số.
  • DP optimization: prefix-min, deque, divide-and-conquer optimization, convex hull trick (khi có điều kiện thích hợp).

Thuật toán chuỗi: pattern matching và KMP

Cần phân biệt tìm chuỗi con liên tiếp, subsequence không liên tiếp và xử lý tiền tố/hậu tố.

Chuỗi trong Python

str là bất biến. Cắt chuỗi s[l:r] tạo chuỗi mới dài O(r−l); nối nhiều mảnh nên dùng "".join(parts). Tìm substring bằng needle in haystack hoặc str.find thường đủ trong ứng dụng; khi học thuật toán, KMP mang lại worst-case tuyến tính.

KMP: prefix function (LPS)

KMP tìm tất cả vị trí khớp
def kmp_search(text, pattern):
    if not pattern:
        return list(range(len(text) + 1))
    m = len(pattern)
    lps = [0] * m
    length = 0
    for i in range(1, m):
        while length and pattern[i] != pattern[length]:
            length = lps[length - 1]
        if pattern[i] == pattern[length]:
            length += 1
        lps[i] = length

    result, j = [], 0
    for i, ch in enumerate(text):
        while j and ch != pattern[j]:
            j = lps[j - 1]
        if ch == pattern[j]:
            j += 1
        if j == m:
            result.append(i - m + 1)
            j = lps[j - 1]
    return result

assert kmp_search("ababa", "aba") == [0, 2]
assert kmp_search("abc", "") == [0, 1, 2, 3]

Tiền xử lý LPS O(m), quét text O(n), tổng O(n+m), bộ nhớ O(m) ngoài kết quả. Hỗ trợ các lần khớp chồng lấn.

Rolling hash / Rabin-Karp

Rabin-Karp tính fingerprint dạng rolling hash để so sánh cửa sổ độ dài m nhanh hơn so với so từng ký tự. Trung bình thường O(n+m) với hash phù hợp, nhưng hash collision có thể xảy ra; nếu cần đúng tuyệt đối, phải xác minh chuỗi khi hash trùng. KMP cho bảo đảm worst-case O(n+m).

Z-function, suffix array và suffix automaton

  • Z-function: Z[i] là độ dài tiền tố khớp với chuỗi bắt đầu tại i; tính O(n).
  • Suffix array: sắp xếp các hậu tố, hỗ trợ nhiều truy vấn substring, thường đi kèm LCP.
  • Suffix automaton / suffix tree: cấu trúc chuyên sâu cho các truy vấn substring trên chuỗi lớn.
  • Aho–Corasick: trie kết hợp failure links để tìm đồng thời nhiều pattern trong văn bản.

Toán học và số học cho thuật toán

GCD, nguyên tố, lũy thừa nhanh và modular arithmetic thường xuất hiện trong lập trình thi đấu.

Euclid: GCD / LCM

GCD và LCM
from math import gcd

def lcm(a, b):
    return abs(a // gcd(a, b) * b) if a and b else 0

assert gcd(18, 24) == 6
assert lcm(18, 24) == 72

Thuật toán Euclid tính gcd trong O(log min(|a|,|b|)) bước với hai số khác 0.

Sàng Eratosthenes

Tìm các số nguyên tố ≤ n
def primes_up_to(n):
    if n < 2:
        return []
    prime = [True] * (n + 1)
    prime[0] = prime[1] = False
    p = 2
    while p * p <= n:
        if prime[p]:
            for multiple in range(p*p, n+1, p):
                prime[multiple] = False
        p += 1
    return [i for i, yes in enumerate(prime) if yes]

assert primes_up_to(20) == [2, 3, 5, 7, 11, 13, 17, 19]

O(n log log n) thời gian, O(n) bộ nhớ.

Modular exponentiation

Lũy thừa nhị phân modulo
def mod_pow(a, exponent, mod):
    if exponent < 0 or mod <= 0:
        raise ValueError("Yêu cầu exponent >= 0, mod > 0")
    result, a = 1 % mod, a % mod
    while exponent:
        if exponent & 1:
            result = result * a % mod
        a = a * a % mod
        exponent >>= 1
    return result

assert mod_pow(2, 10, 1000) == 24
assert pow(2, 10, 1000) == 24  # Python đã có sẵn

O(log exponent) phép nhân modulo. Modular inverse có thể tìm bằng extended Euclid nếu gcd(a,m)=1; khi mod là số nguyên tố, dùng a^(mod-2) mod mod cho a không chia hết mod.

Một số chủ đề mở rộng

  • Đếm tổ hợp C(n,k), Pascal, factorial modulo và inverse factorial.
  • Two-sum và congruence modulo; Chinese Remainder Theorem (CRT) khi cần ghép đồng dư.
  • Matrix exponentiation cho truy hồi tuyến tính O(log n) bước nhân ma trận.
  • Hình học tính toán: cross product, orientation, convex hull (Graham scan, monotonic chain).
  • Randomized algorithms và xác suất: reservoir sampling, randomized quickselect.

Bài tập có hướng dẫn

Tự giải trước khi mở phần gợi ý hoặc hướng giải. Mỗi bài minh họa một mẫu tiêu biểu.

?01 · Contains duplicate

Cho list a, trả về True nếu tồn tại ít nhất một giá trị lặp.

Xem gợi ý
Nếu số phần tử khác nhau nhỏ hơn độ dài a thì có trùng.
Xem hướng giải
return len(set(a)) != len(a) — trung bình O(n) thời gian và O(n) bộ nhớ.
?02 · Product except self

Với list a, tại mỗi i hãy tính tích của tất cả phần tử trừ a[i], không dùng phép chia.

Xem gợi ý
Nhân prefix và suffix; dùng output làm prefix, một biến suffix chạy từ phải sang trái.
Xem hướng giải
Hai lượt: ans[i]=prefix, prefix*=a[i]; rồi từ phải: ans[i]*=suffix, suffix*=a[i]. O(n) thời gian, O(1) bộ nhớ phụ ngoài output.
?03 · Search rotated sorted array

List đã sort tăng nhưng bị xoay một đoạn, phần tử phân biệt. Tìm chỉ số x.

Xem gợi ý
Tại mỗi bước nhị phân, ít nhất một nửa vẫn được sort.
Xem hướng giải
O(log n): so sánh a[lo], a[mid], a[hi] để xác định nửa được sort và liệu target nằm trong nửa đó.
?04 · Daily temperatures

Cho list nhiệt độ, với mỗi ngày tính sau bao nhiêu ngày có nhiệt độ cao hơn; nếu không có trả 0.

Xem gợi ý
Monotonic stack lưu các chỉ số có nhiệt độ giảm dần.
Xem hướng giải
Với mỗi i, khi a[i] > a[stack[-1]], pop j và gán ans[j]=i-j. O(n).
?05 · Number of islands

Grid ký tự 0/1, đếm các vùng 1 nối 4 hướng.

Xem gợi ý
Quét grid; gặp 1 chưa thăm thì BFS/DFS tô hết đảo rồi +1.
Xem hướng giải
O(R·C) thời gian; dùng visited hoặc đánh dấu trực tiếp nếu được phép sửa grid.
?06 · Course schedule

n môn học, cặp (a,b) nghĩa phải học b trước a. Có thể hoàn thành tất cả?

Xem gợi ý
Topo sort trên các cạnh b → a.
Xem hướng giải
Kahn: nếu xử lý được n đỉnh thì True; nếu còn cycle thì False. O(V+E).
?07 · K-th largest

Tìm phần tử lớn thứ k trong list không cần trả toàn bộ list đã sort.

Xem gợi ý
Min-heap k phần tử hoặc Quickselect.
Xem hướng giải
Min-heap O(n log k), bộ nhớ O(k); Quickselect kỳ vọng O(n), worst O(n²) nếu pivot kém.
?08 · Word break

Cho s và từ điển, xác định có thể tách s thành các từ trong từ điển không.

Xem gợi ý
dp[i] = có tách được s[:i] không?
Xem hướng giải
dp[0]=True; dp[i]=any(dp[j] and s[j:i] in words for j in range(i)). Với slicing và hash kiểm tra tùy độ dài từ, chi phí thực tế có thêm chi phí tạo chuỗi; tối ưu bằng giới hạn độ dài từ hoặc trie.
?09 · Minimum path sum

Tìm tổng đường đi nhỏ nhất từ góc trên trái đến dưới phải, chỉ đi sang phải hoặc xuống.

Xem gợi ý
dp[r][c] = grid[r][c] + min(top, left).
Xem hướng giải
O(R·C) thời gian; dùng mảng dp 1D O(C), xử lý biên hàng đầu/cột đầu.
?10 · Longest palindrome substring

Tìm chuỗi con đối xứng liên tiếp dài nhất.

Xem gợi ý
Thử mọi tâm đối xứng: tâm một ký tự hoặc giữa hai ký tự.
Xem hướng giải
Expand-around-center O(n²) thời gian, O(1) bộ nhớ. Manacher có thể O(n) nhưng khó hơn.
?11 · Validate BST

Kiểm tra cây nhị phân có thỏa quy tắc BST strict hay không.

Xem gợi ý
Truyền khoảng hợp lệ (low,high) từ tổ tiên xuống, không chỉ so với cha.
Xem hướng giải
Đi DFS, kiểm tra low < node.val < high, trái được high=node.val, phải được low=node.val. O(n) thời gian, O(h) stack.
?12 · Subarray sum equals k

Đếm số đoạn con liên tiếp có tổng đúng bằng k, có thể có số âm.

Xem gợi ý
Nếu prefix hiện tại s, cần đếm số prefix cũ bằng s−k.
Xem hướng giải
Đặt cnt={0:1}, duyệt cộng s, cộng vào đáp án cnt.get(s-k,0), rồi tăng cnt[s]. Trung bình O(n).

Công thức &amp; các lỗi hay gặp

  • Binary search: chọn khoảng [lo,hi) hoặc [lo,hi] nhất quán; mỗi bước phải làm khoảng nhỏ lại.
  • BFS: mark visited khi enqueue (thay vì dequeue) để không thêm một đỉnh nhiều lần.
  • Dijkstra: không dùng với cạnh âm; skip heap entries cũ.
  • DP 0/1 knapsack: duyệt capacity giảm; unlimited knapsack thường duyệt tăng.
  • Modulo: với số lớn, đưa phép chia thành nhân nghịch đảo chỉ khi nghịch đảo tồn tại.
  • Hash: không coi O(1) là bảo đảm worst-case; chú ý collision.
  • Indices: phân biệt [l,r] và [l,r), 0-based và 1-based.
  • Recursion: chú ý base case và chiều sâu stack.
  • Testing: luôn có case rỗng, trùng lặp, số âm, nhiều components, không có lời giải.
