Node.js là gì?

Node.js là môi trường chạy JavaScript bên ngoài trình duyệt, dựa trên V8 và cung cấp API để làm việc với hệ điều hành, mạng, tệp và tiến trình.

TRONG TRÌNH DUYỆTJavaScript + Web API

DOM, sự kiện click, giao diện, window, document.

⇄
TRONG NODE.JSJavaScript + Node API

HTTP server, file system, process, TCP, luồng dữ liệu.

Node.js thường dùng để làm gì?

Xây dựng API cho web/mobile, ứng dụng realtime (chat), công cụ dòng lệnh, xử lý tác vụ nền, tích hợp dịch vụ khác và các hệ thống I/O nhiều.

Vì sao Node.js xử lý nhiều request tốt?

JavaScript của ứng dụng thường chạy trên một luồng chính, trong khi các tác vụ I/O có thể được hệ điều hành và libuv hỗ trợ bất đồng bộ. Event loop nhận callback/kết quả khi tác vụ hoàn tất, giúp tránh phải chờ I/O theo cách chặn luồng.

  2. Cài theo hướng dẫn trên màn hình. Nếu dùng bộ quản lý phiên bản (ví dụ nvm trên macOS/Linux), cài phiên bản LTS tương ứng.

Modules: ESM và CommonJS

ES Modules (ESM) là chuẩn module của JavaScript. Các ví dụ chính dùng ESM để thống nhất với dự án mới.

math.js
JAVASCRIPT
export const PI = 3.14159;
export function add(a, b) {
  return a + b;
}
main.js
JAVASCRIPT
import { add, PI } from './math.js';
import { readFile } from 'node:fs/promises';

console.log(add(2, 3), PI);

Để dùng import/export trong tệp .js, đặt "type": "module" trong package.json; hoặc dùng phần mở rộng .mjs. Đường dẫn tương đối ESM thường cần ghi rõ .js.

Còn CommonJS?

Đọc và ghi tệp với fs/promises

Các tác vụ tệp nên dùng phiên bản bất đồng bộ để tránh chặn event loop của server.

files.js
JAVASCRIPT
import { readFile, writeFile, mkdir } from 'node:fs/promises';

const folder = new URL('./data/', import.meta.url);
const path = new URL('./data/users.json', import.meta.url);

async function main() {
  await mkdir(folder, { recursive: true });
  const users = [{ id: 1, name: 'Lan' }];
  await writeFile(path, JSON.stringify(users, null, 2), 'utf8');

  const content = await readFile(path, 'utf8');
  console.log(JSON.parse(content));
}

main().catch(error => {
  console.error('Lỗi đọc/ghi tệp:', error.message);
  process.exitCode = 1;
});

JSON.stringify() chuyển dữ liệu thành chuỗi; JSON.parse() chuyển chuỗi JSON thành dữ liệu JavaScript. Sử dụng new URL(..., import.meta.url) để định vị tương đối so với file module hiện tại thay vì phụ thuộc thư mục mở terminal.

!
Đọc file không phải cơ sở dữ liệu

Nếu nhiều request cùng ghi một file JSON, có thể xảy ra ghi đè, race condition hoặc lỗi dữ liệu. Học thuật phù hợp, sản phẩm thực tế nên dùng database.

Event loop & bất đồng bộ

Hiểu sự khác biệt giữa code đồng bộ và bất đồng bộ để viết server đáp ứng nhanh.

event-loop.js
JAVASCRIPT
console.log('A — chạy ngay');
setTimeout(() => console.log('D — timer'), 0);
Promise.resolve().then(() => console.log('C — promise'));
console.log('B — chạy ngay');
// Thứ tự thường thấy: A, B, C, D

Code đồng bộ chạy trước. Sau đó các microtask như callback của Promise được xử lý trước callback timer trong ví dụ này. Thời gian 0 không có nghĩa timer thực thi lập tức.

I/O-bound

Đọc DB, gọi API, đọc file — tận dụng async I/O để phục vụ nhiều request.

CPU-bound

Nén, tính toán nặng, xử lý ảnh — có thể chặn luồng JS; cân nhắc worker threads hoặc tiến trình riêng.

Không nên làm trên request handler
JAVASCRIPT
// Ví dụ minh họa tác vụ nặng, KHÔNG đưa vào HTTP handler:
const end = Date.now() + 3000;
while (Date.now() < end) { /* chặn event loop */ }

Promise, async/await & fetch

Một hàm async luôn trả về Promise; await chờ kết quả trong hàm async mà không chặn event loop giống vòng lặp đồng bộ.

async-example.js
JAVASCRIPT
async function getTodo(id) {
  const response = await fetch(
    `https://jsonplaceholder.typicode.com/todos/${id}`,
    { signal: AbortSignal.timeout(5000) }
  );
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }
  return response.json();
}

try {
  const [todo1, todo2] = await Promise.all([
    getTodo(1), getTodo(2)
  ]);
  console.log(todo1.title, todo2.title);
} catch (error) {
  console.error('Không lấy được dữ liệu:', error.message);
}

fetch có sẵn trong Node hiện đại. Promise.all cho phép chờ nhiều tác vụ độc lập; nếu một Promise từ chối, kết quả chung sẽ từ chối. Khi cần thu thập cả thành công và thất bại, tìm hiểu Promise.allSettled.

✦
Lỗi mạng thường gặp

Ví dụ này cần internet. fetch() chỉ reject khi có lỗi mạng/hủy yêu cầu; HTTP 404 hoặc 500 cần tự kiểm tra response.ok.

Xây HTTP server không cần thư viện

Module node:http giúp hiểu request, response, header, status code và routing.

server.js
JAVASCRIPT
import { createServer } from 'node:http';

const server = createServer((req, res) => {
  const url = new URL(req.url, `http://${req.headers.host ?? 'localhost'}`);
  res.setHeader('Content-Type', 'application/json; charset=utf-8');

  if (req.method === 'GET' && url.pathname === '/api/health') {
    res.writeHead(200);
    res.end(JSON.stringify({ status: 'ok', at: new Date().toISOString() }));
    return;
  }

  res.writeHead(404);
  res.end(JSON.stringify({ error: 'Không tìm thấy đường dẫn' }));
});

server.listen(3000, () => {
  console.log('Server: http://localhost:3000/api/health');
});

Middleware là gì?

Middleware là hàm nằm trong pipeline xử lý request. Nó có thể ghi log, xác thực, parse JSON, kiểm tra input, hoặc chuyển việc sang bước tiếp theo qua next().

Ví dụ middleware ghi log
JAVASCRIPT
app.use((req, res, next) => {
  console.log(req.method, req.path);
  next();
});

Đặt middleware ghi log trước các route nếu muốn ghi nhận mọi request. Trong Express 5, Promise bị reject từ async route handler được chuyển tới cơ chế xử lý lỗi.

Bước 2 — Tạo app.js và dán toàn bộ mã

todo-api/app.js
JAVASCRIPT
import express from 'express';

const app = express();
app.use(express.json({ limit: '16kb' }));

let tasks = [
  { id: 1, title: 'Học Node.js', done: false },
  { id: 2, title: 'Viết API', done: true }
];
let nextId = 3;

function findTask(req, res) {
  const id = Number(req.params.id);
  if (!Number.isSafeInteger(id) || id < 1) {
    res.status(400).json({ error: 'id không hợp lệ' });
    return null;
  }
  const task = tasks.find(item => item.id === id);
  if (!task) {
    res.status(404).json({ error: 'Không tìm thấy công việc' });
    return null;
  }
  return task;
}

app.get('/api/health', (req, res) => {
  res.json({ status: 'ok' });
});

app.get('/api/tasks', (req, res) => {
  res.json(tasks);
});

app.get('/api/tasks/:id', (req, res) => {
  const task = findTask(req, res);
  if (task) res.json(task);
});

app.post('/api/tasks', (req, res) => {
  const { title } = req.body ?? {};
  if (typeof title !== 'string' || !title.trim() || title.length > 200) {
    return res.status(400).json({ error: 'title phải là chuỗi từ 1 đến 200 ký tự' });
  }
  const task = { id: nextId++, title: title.trim(), done: false };
  tasks.push(task);
  res.status(201).json(task);
});

app.patch('/api/tasks/:id', (req, res) => {
  const task = findTask(req, res);
  if (!task) return;
  const body = req.body ?? {};
  if (typeof body !== 'object' || Array.isArray(body) ||
      !Object.keys(body).length ||
      Object.keys(body).some(k => !['title', 'done'].includes(k)) ||
      ('title' in body && (typeof body.title !== 'string' ||
        !body.title.trim() || body.title.length > 200)) ||
      ('done' in body && typeof body.done !== 'boolean')) {
    return res.status(400).json({ error: 'Chỉ được sửa title hoặc done với giá trị hợp lệ' });
  }
  if ('title' in body) task.title = body.title.trim();
  if ('done' in body) task.done = body.done;
  res.json(task);
});

app.delete('/api/tasks/:id', (req, res) => {
  const task = findTask(req, res);
  if (!task) return;
  tasks = tasks.filter(item => item.id !== task.id);
  res.status(204).end();
});

app.use((req, res) => {
  res.status(404).json({ error: 'Endpoint không tồn tại' });
});

app.use((err, req, res, next) => {
  console.error(err);
  const status = err.status === 400 ? 400 : 500;
  res.status(status).json({
    error: status === 400 ? 'JSON không hợp lệ' : 'Lỗi máy chủ'
  });
});

const port = Number(process.env.PORT ?? 3000);
app.listen(port, () => {
  console.log(`Todo API: http://localhost:${port}`);
});

16 / 21MỞ RỘNG DỰ ÁN

Kết nối cơ sở dữ liệu

Từ API in-memory, bạn có thể chuyển dữ liệu sang PostgreSQL, SQLite hoặc database phù hợp yêu cầu.

Trong ứng dụng thật, database lưu dữ liệu qua các lần khởi động và hỗ trợ truy vấn, chỉ mục, transaction, backup. Với hệ quan hệ như PostgreSQL, một bảng tasks có thể gồm id, title, done.

Ví dụ SQL khởi tạo bảng
SQL
CREATE TABLE tasks (
  id BIGSERIAL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  done BOOLEAN NOT NULL DEFAULT FALSE
);

Ví dụ sử dụng driver pg dưới đây yêu cầu PostgreSQL đang chạy và biến DATABASE_URL. Đây là ví dụ tích hợp độc lập, chưa thay thế trực tiếp code Todo phía trên.

Terminal
BASH / POWERSHELL
npm install pg
db.js
JAVASCRIPT
import pg from 'pg';

const pool = new pg.Pool({
  connectionString: process.env.DATABASE_URL
});

export async function listTasks() {
  const result = await pool.query(
    'SELECT id, title, done FROM tasks ORDER BY id DESC'
  );
  return result.rows;
}

export async function addTask(title) {
  const result = await pool.query(
    'INSERT INTO tasks(title) VALUES($1) RETURNING id, title, done',
    [title]
  );
  return result.rows[0];
}
✓
Luôn dùng truy vấn có tham số

$1 và mảng [title] giúp tránh ghép input trực tiếp vào câu lệnh SQL — cách ghép chuỗi có thể dẫn đến SQL injection.

Tra cứu lỗi phổ biến

Cannot use import statement outside a module

Kiểm tra "type": "module" trong package.json hoặc sử dụng .mjs; đảm bảo terminal đang ở đúng thư mục dự án.

ERR_MODULE_NOT_FOUND

Kiểm tra tên package, đã chạy npm install chưa và đường dẫn import tương đối đã có phần mở rộng .js hay chưa.

EADDRINUSE: address already in use

Đã có tiến trình khác chiếm cổng. Dừng server cũ bằng Ctrl+C hoặc đổi PORT.

Request POST trả về 400 / req.body không đúng

Bảo đảm có app.use(express.json()) trước route, header Content-Type: application/json và nội dung request là JSON hợp lệ.

Server chạy nhưng thay code không tự cập nhật

Khởi chạy qua node --watch app.js hoặc npm run dev với script phù hợp. Kiểm tra file đã được lưu.
