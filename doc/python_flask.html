Flask là gì?

Hiểu Flask xử lý một yêu cầu HTTP như thế nào trước khi viết dòng code đầu tiên.

Flask là một micro web framework viết bằng Python. “Micro” có nghĩa là phần lõi nhỏ và linh hoạt, không có nghĩa chỉ xây được ứng dụng nhỏ. Bạn chọn thư viện cơ sở dữ liệu, xác thực, biểu mẫu… phù hợp với dự án.

Flask dùng để làm gì?

  • Website có giao diện HTML, trang quản trị, dashboard.
  • REST API hoặc backend phục vụ ứng dụng mobile / frontend.
  • MVP, prototype, sản phẩm nội bộ và nhiều loại dịch vụ web.
  • Ứng dụng phức tạp khi được tổ chức bằng blueprint, tầng dịch vụ và các extension.

Ứng dụng đầu tiên: Hello, Flask!

Chỉ một file Python là đủ để Flask trả về nội dung trên trình duyệt.

Tạo file app.py

app.py
PYTHON
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "<h1>Xin chào Flask!</h1>"

@app.route("/about")
def about():
    return "Đây là website Flask đầu tiên của tôi."

Chạy ứng dụng

Terminal
BASH
python -m flask --app app run --debug
# Mở http://127.0.0.1:5000/
# Thử thêm http://127.0.0.1:5000/about
127.0.0.1:5000

Xin chào Flask!

Đây là nội dung HTML do Python trả về.

Giải thích từng dòng

  1. Flask là lớp tạo ứng dụng web.
  2. Flask(__name__) khởi tạo ứng dụng và giúp xác định vị trí tài nguyên.
  3. @app.route("/") gắn đường dẫn URL với hàm xử lý.
  4. Khi có request GET tới /, Flask gọi home(), rồi tạo HTTP response từ chuỗi trả về.
!

Routing, URL và HTTP methods

Decorator định tuyến quyết định request nào được xử lý bởi hàm nào.

URL động và kiểu dữ liệu

app.py · route parameters
PYTHON
from flask import Flask, abort, redirect, url_for

app = Flask(__name__)

@app.get("/hello/<name>")
def hello(name):
    return f"Xin chào {name}!"

@app.get("/users/<int:user_id>")
def user_detail(user_id):
    if user_id <= 0:
        abort(404)
    return f"ID người dùng: {user_id}"

@app.get("/go-home")
def go_home():
    return redirect(url_for("hello", name="Python"))

PYTHON
from flask import request

@app.route("/contact", methods=["GET", "POST"])
def contact():
    if request.method == "POST":

Bạn có thể dùng cú pháp ngắn @app.get(...), @app.post(...), @app.put(...)... url_for() sinh URL từ tên hàm, giúp đổi đường dẫn mà không sửa tất cả liên kết.

!
Lưu ý bảo mật
Nếu chèn nội dung người dùng vào HTML thủ công bằng f-string, có thể gây XSS. Các trang thực tế nên dùng render_template() để Jinja escape dữ liệu đúng cách.

Request & Response

Nhận dữ liệu từ query string, JSON, form, rồi trả status code hoặc JSON cho client.

Đọc dữ liệu từ client

app.py · request
PYTHON
from flask import Flask, jsonify, request

app = Flask(__name__)

@app.get("/search")
def search():
    keyword = request.args.get("q", "").strip()
    page = request.args.get("page", 1, type=int)
    return jsonify(keyword=keyword, page=page)

@app.post("/echo")
def echo():
    data = request.get_json(silent=True)
    if not isinstance(data, dict):
        return jsonify(error="Cần gửi JSON object"), 400
    return jsonify(received=data), 200

Dữ liệu nằm ở đâu?

APIÝ nghĩaVí dụ

request.formDữ liệu form URL-encoded / multiparttitle=Hello
request.get_json()JSON trong request body{"name":"An"}
request.filesFile tải lênrequest.files["avatar"]
request.headersHTTP headersAuthorization

Xử lý Form và validate dữ liệu

Nhận POST từ browser, kiểm tra dữ liệu đầu vào và chuyển hướng sau khi ghi.

app.py · form GET/POST
PYTHON
from flask import Flask, flash, redirect, render_template, request, url_for

app = Flask(__name__)
app.config["SECRET_KEY"] = "dev-only-change-me"

@app.route("/feedback", methods=["GET", "POST"])
def feedback():
    if request.method == "POST":
        message = request.form.get("message", "").strip()
        if not 1 <= len(message) <= 500:
            flash("Nội dung phải có từ 1 đến 500 ký tự", "error")
        else:
            # Demo: chưa lưu nội dung vào database.
            flash("Đã nhận phản hồi!", "success")
            return redirect(url_for("feedback"))
    return render_template("feedback.html")

Vì sao phải redirect sau POST?

Mô hình POST → Redirect → GET (PRG) giúp tránh trình duyệt gửi lại form khi người dùng nhấn Refresh sau một thao tác thành công.

!
Validate ở cả backend
Thuộc tính required/maxlength phía HTML chỉ hỗ trợ trải nghiệm; người dùng vẫn có thể gửi request trực tiếp. Backend phải tự kiểm tra dữ liệu. Với ứng dụng có xác thực và thay đổi dữ liệu, cần bảo vệ CSRF.

Session, Cookie và xác thực

Ghi nhớ trạng thái giữa các request và hiểu ranh giới an toàn của session.

app.py · session cơ bản
PYTHON
import os
from flask import Flask, redirect, request, session, url_for

app = Flask(__name__)
app.config["SECRET_KEY"] = os.environ.get("SECRET_KEY", "dev-key-only")

@app.post("/login-demo")
def login_demo():
    username = request.form.get("username", "").strip()
    if not username:
        return "Username là bắt buộc", 400
    # Chỉ là ví dụ session; KHÔNG phải đăng nhập thật.
    session["username"] = username
    return redirect(url_for("profile"))

@app.get("/profile")
def profile():
    if "username" not in session:
        return "Bạn chưa có session", 401
    return {"username": session["username"]}

@app.post("/logout")
def logout():
    session.clear()
    return "Đã xóa session demo"

Flask mặc định lưu session trong cookie có chữ ký. Người dùng có thể xem nội dung cookie nhưng không thể sửa hợp lệ nếu không biết khóa ký; cookie không được mã hóa, vì vậy không lưu mật khẩu, token bí mật hoặc dữ liệu nhạy cảm trong session.

Thực tế cần thêm gì để đăng nhập an toàn?

  • Lưu mật khẩu bằng generate_password_hash() và so khớp bằng check_password_hash(); không lưu plain text.
  • Kiểm tra username/password từ database trước khi tạo session.
  • Bảo vệ login form khỏi brute-force bằng rate limit và quy trình khóa / theo dõi phù hợp.
  • Thiết lập HTTPS, SESSION_COOKIE_SECURE=True, SESSION_COOKIE_HTTPONLY=True và SESSION_COOKIE_SAMESITE="Lax" trong production.
  • Đặt SECRET_KEY mạnh trong biến môi trường hoặc secret manager.
Terminal · tạo SECRET_KEY
BASH
python -c "import secrets; print(secrets.token_hex(32))"
!
Demo session ≠ hệ thống authentication
Đoạn code phía trên cho phép bất cứ ai tự gửi username nên chỉ dùng để học cách hoạt động của session; tuyệt đối không coi là cơ chế đăng nhập thật.

Lưu dữ liệu với SQLite

Kết nối database, tạo bảng và thao tác dữ liệu an toàn bằng câu lệnh có tham số.

SQLite đi kèm thư viện chuẩn Python, rất phù hợp để học, làm prototype và ứng dụng nhỏ. Bạn có thể dùng sqlite3 mà không cần cài driver riêng.

app.py · tích hợp SQLite
PYTHON
import sqlite3
from pathlib import Path
from flask import Flask, g

app = Flask(__name__)
app.config["DATABASE"] = Path(__file__).parent / "site.db"

def get_db():
    if "db" not in g:
        g.db = sqlite3.connect(app.config["DATABASE"])
        g.db.row_factory = sqlite3.Row
    return g.db

@app.teardown_appcontext
def close_db(error=None):
    db = g.pop("db", None)
    if db is not None:
        db.close()

def init_db():
    db = get_db()
    db.execute("""
        CREATE TABLE IF NOT EXISTS notes (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            content TEXT NOT NULL
        )
    """)
    db.commit()

with app.app_context():
    init_db()
Ví dụ INSERT / SELECT
PYTHON
# Chạy bên trong app context, ví dụ trong một view.
db = get_db()
db.execute("INSERT INTO notes (content) VALUES (?)", ("Học Flask",))
db.commit()

rows = db.execute(
    "SELECT id, content FROM notes WHERE content LIKE ?",
    ("%Flask%",)
).fetchall()
for row in rows:
    print(row["id"], row["content"])
✓
Luôn dùng SQL parameters
? và tuple tham số giúp tránh SQL injection. Không ghép dữ liệu đầu vào vào chuỗi SQL bằng f-string hoặc phép cộng chuỗi.

Ở hệ thống lớn, cân nhắc SQLAlchemy, Alembic để quản lý migration và một database phù hợp tải vận hành. Ví dụ trên cố ý tối giản để bạn hiểu rõ request context, g và vòng đời kết nối.

Xây dựng REST API trả JSON

Sử dụng Flask làm backend cho frontend JavaScript, mobile app hoặc hệ thống khác.

Một API endpoint cần xác định resource, HTTP method, cấu trúc JSON đầu vào và mã trạng thái trả về. Ví dụ dưới đây là một API độc lập, lưu dữ liệu trong RAM để tập trung vào HTTP.

api_demo.py · API độc lập
PYTHON
from flask import Flask, jsonify, request

app = Flask(__name__)
books = {1: {"id": 1, "title": "Flask căn bản"}}
next_id = 2

@app.get("/api/books")
def list_books():
    return jsonify(list(books.values()))

@app.get("/api/books/<int:book_id>")
def get_book(book_id):
    book = books.get(book_id)
    if book is None:
        return jsonify(error="Không tìm thấy sách"), 404
    return jsonify(book)

@app.post("/api/books")
def create_book():
    global next_id
    data = request.get_json(silent=True)
    if not isinstance(data, dict):
        return jsonify(error="Body phải là JSON object"), 400
    title = data.get("title")
    if not isinstance(title, str) or not title.strip():
        return jsonify(error="title phải là chuỗi không rỗng"), 400
    book = {"id": next_id, "title": title.strip()}
    books[next_id] = book
    next_id += 1
    return jsonify(book), 201

@app.delete("/api/books/<int:book_id>")
def delete_book(book_id):
    if books.pop(book_id, None) is None:
        return jsonify(error="Không tìm thấy sách"), 404
    return "", 204

Bước 2 — Backend Python hoàn chỉnh

Đặt toàn bộ code sau vào app.py. Các route chỉ thay đổi database bằng HTTP POST; các câu lệnh SQL dùng parameters.

todo-flask/app.py
PYTHON
import os
import sqlite3
from pathlib import Path

from flask import Flask, abort, flash, g, redirect, render_template, request, url_for

BASE_DIR = Path(__file__).resolve().parent
app = Flask(__name__)
app.config.update(
    SECRET_KEY=os.environ.get("SECRET_KEY", "dev-only-change-me"),
    DATABASE=BASE_DIR / "tasks.db",
)


def get_db():
    if "db" not in g:
        g.db = sqlite3.connect(app.config["DATABASE"])
        g.db.row_factory = sqlite3.Row
    return g.db


@app.teardown_appcontext
def close_db(error=None):
    db = g.pop("db", None)
    if db is not None:
        db.close()


def init_db():
    db = get_db()
    db.execute("""
        CREATE TABLE IF NOT EXISTS tasks (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            title TEXT NOT NULL,
            done INTEGER NOT NULL DEFAULT 0
        )
    """)
    db.commit()


@app.get("/")
def index():
    tasks = get_db().execute(
        "SELECT id, title, done FROM tasks ORDER BY id DESC"
    ).fetchall()
    return render_template("index.html", tasks=tasks)


@app.post("/add")
def add_task():
    title = request.form.get("title", "").strip()
    if not title or len(title) > 120:
        flash("Tên việc cần có từ 1 đến 120 ký tự.", "error")
    else:
        db = get_db()
        db.execute("INSERT INTO tasks (title) VALUES (?)", (title,))
        db.commit()
        flash("Đã thêm công việc!", "success")
    return redirect(url_for("index"))


@app.post("/toggle/<int:task_id>")
def toggle_task(task_id):
    db = get_db()
    cursor = db.execute(
        "UPDATE tasks SET done = CASE done WHEN 1 THEN 0 ELSE 1 END WHERE id = ?",
        (task_id,),
    )
    db.commit()
    if cursor.rowcount == 0:
        abort(404)
    return redirect(url_for("index"))


@app.post("/delete/<int:task_id>")
def delete_task(task_id):
    db = get_db()
    cursor = db.execute("DELETE FROM tasks WHERE id = ?", (task_id,))
    db.commit()
    if cursor.rowcount == 0:
        abort(404)
    flash("Đã xóa công việc.", "success")
    return redirect(url_for("index"))


# Khởi tạo bảng cho bản demo trước khi phục vụ request.
with app.app_context():
    init_db()

Bảo mật Flask trong thực tế

Những nguyên tắc tối thiểu trước khi để người khác truy cập ứng dụng.

01
Chống SQL injection

Dùng SQL parameters hoặc ORM; không nội suy input vào truy vấn.

02
Chống XSS

Dùng Jinja autoescaping; không đưa HTML không tin cậy vào |safe.

03
CSRF cho biểu mẫu

Thêm token CSRF cho form thay đổi trạng thái, nhất là khi xác thực bằng cookie.

04
Bảo vệ mật khẩu

Hash bằng thư viện uy tín; không lưu plain text, không tự chế thuật toán.

05
Cấu hình bí mật

SECRET_KEY và credentials nằm ngoài source code; không đẩy lên Git.

06
Production cứng cáp

HTTPS, cookie flags, headers phù hợp, logging, giới hạn request và cập nhật dependency.

Lỗi thường gặp & cách sửa

Nhận diện nhanh các vấn đề mà người mới học Flask hay gặp nhất.

ModuleNotFoundError: No module named flask+
Đã cài Flask ở một Python interpreter khác. Kích hoạt virtual environment, dùng python -m pip show Flask và kiểm tra IDE đang dùng đúng interpreter trong .venv.
Could not locate a Flask application+
Chạy từ thư mục có app.py rồi dùng python -m flask --app app run; nếu dùng factory, chọn --app myapp hoặc --app myapp:create_app.
jinja2.exceptions.TemplateNotFound+
Kiểm tra thư mục tên chính xác templates/, đường dẫn tương đối và tên file truyền cho render_template(); chú ý chữ hoa/chữ thường trên Linux.
405 Method Not Allowed+
Đang POST đến route chỉ nhận GET hoặc ngược lại. Kiểm tra methods=["GET", "POST"] / @app.post và method trên form.
404 Not Found+
Đường dẫn URL không trùng route, sai prefix Blueprint, sai converter ID hoặc tài nguyên không tồn tại. Dùng python -m flask --app app routes để xem các endpoint hiện có.
RuntimeError: Working outside of application context+
Đang truy cập g / current_app ngoài app context. Để khởi tạo database thủ công, dùng with app.app_context(): init_db().
Address already in use / Port 5000 bận+
Một chương trình khác đang giữ cổng. Tắt tiến trình cũ hoặc đổi cổng bằng python -m flask --app app run -p 5001.
CSS / static không tải+
Đặt file dưới static/ và dùng url_for("static", filename="style.css"); kiểm tra tab Network và thử hard refresh.
