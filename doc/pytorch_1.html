01 PyTorch là gì? Bạn sẽ học được gì?

PyTorch là thư viện Python phục vụ tính toán trên tensor và xây dựng mô hình học sâu. Bạn có thể viết các phép toán gần với Python/NumPy, chuyển tính toán lên GPU và tự động tính gradient để tối ưu tham số.

04 Chạy trên CPU, NVIDIA GPU hoặc Apple Silicon

PyTorch sử dụng khái niệm device: cpu (bộ xử lý chung), cuda (NVIDIA khi bản cài hỗ trợ) và mps (Metal trên máy Mac tương thích). Các tensor tham gia cùng một phép toán cần ở thiết bị phù hợp.

Python
import torch

if torch.cuda.is_available():
    device = torch.device('cuda')
elif hasattr(torch.backends, 'mps') and torch.backends.mps.is_available():
    device = torch.device('mps')
else:
    device = torch.device('cpu')

x = torch.ones(3).to(device)
y = torch.arange(3, dtype=torch.float32).to(device)
print('Đang dùng:', device)
print((x + y).device)
print((x + y).cpu().numpy())   # Chuyển về CPU trước khi dùng NumPy

Trong huấn luyện, cả mô hình và batch dữ liệu phải được chuyển thiết bị: model.to(device), x.to(device), y.to(device). .to(device) trả về tensor trên thiết bị đích, vì vậy hãy gán kết quả khi cần.

Tránh lỗi “Expected all tensors to be on the same device”

Không trộn tensor trên CPU và GPU trong cùng phép tính. Khi cần NumPy, dùng tensor.detach().cpu().numpy() (nếu tensor đang theo dõi gradient).

05 Autograd: tự động tính gradient

Nếu hàm mất mát là L(θ), việc học thường dựa vào đạo hàm ∂L/∂θ: tham số nào làm loss tăng, tham số nào làm loss giảm. torch.autograd ghi nhận các phép tính để lan truyền gradient từ đầu ra về các tham số.

Python
import torch

x = torch.tensor(3.0, requires_grad=True)
y = x**2 + 2*x + 1          # f(x) = x² + 2x + 1
y.backward()                # dy/dx = 2x + 2
print(x.grad.item())        # 8.0 khi x = 3

# Lần backward tiếp theo sẽ CỘNG vào x.grad:
x.grad = None               # xóa gradient cũ
(x**2).backward()
print(x.grad.item())        # 6.0

with torch.no_grad():
    z = x * 10              # không ghi đồ thị gradient
print(z.requires_grad)      # False
Ví dụ đại số
f(x) = x² + 2x + 1f′(x) = 2x + 2Khi x = 3, đạo hàm bằng 8.

Thử thay giá trị x

f(x)16.00
Gradient f′(x)8.00
Bước SGD (lr = 0.1)2.20

Minh họa một bước x_new = x − learning_rate × gradient, không phải mô hình huấn luyện thực.

Các khái niệm cần phân biệt

  • requires_grad=True: yêu cầu theo dõi đạo hàm của tensor.
  • loss.backward(): tính gradient và tích lũy vào .grad của các tensor lá liên quan.
  • optimizer.zero_grad(set_to_none=True): dọn gradient cũ trước bước mới.
  • torch.no_grad() hoặc torch.inference_mode(): tránh lưu đồ thị không cần thiết khi đánh giá; inference_mode còn có tối ưu bổ sung và hạn chế thao tác hơn.
  • detach(): lấy tensor không theo dõi tiếp gradient.
Vì sao gradient “tự nhiên” cộng dồn?

PyTorch tích lũy gradient để hỗ trợ các kỹ thuật như gradient accumulation. Trong huấn luyện thông thường, luôn reset trước khi tính gradient cho batch mới.

06 Chuẩn bị dữ liệu với Dataset và DataLoader

Dataset biết cách lấy một mẫu (x, y); DataLoader gom nhiều mẫu thành batch, có thể xáo trộn thứ tự và tải song song. torchvision hỗ trợ dữ liệu/biến đổi ảnh phổ biến.

Ta sử dụng FashionMNIST: bộ dữ liệu gồm ảnh thời trang xám 28 × 28 thuộc 10 lớp; phần train có 60.000 ảnh và phần test 10.000 ảnh.

Python
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

to_tensor = transforms.ToTensor()  # ảnh PIL [0, 255] -> float [0, 1]
train_data = datasets.FashionMNIST(
    root='data', train=True, download=True, transform=to_tensor
)
test_data = datasets.FashionMNIST(
    root='data', train=False, download=True, transform=to_tensor
)
train_loader = DataLoader(train_data, batch_size=128, shuffle=True)
test_loader = DataLoader(test_data, batch_size=128, shuffle=False)

images, labels = next(iter(train_loader))
print(images.shape)  # torch.Size([128, 1, 28, 28])
print(labels.shape)  # torch.Size([128])
print(train_data.classes)

Tự viết Dataset khi dữ liệu không có sẵn

Python
from torch.utils.data import Dataset
import torch

class MyDataset(Dataset):
    def __init__(self, features, labels):
        self.x = torch.as_tensor(features, dtype=torch.float32)
        self.y = torch.as_tensor(labels, dtype=torch.long)

    def __len__(self):
        return len(self.y)

    def __getitem__(self, idx):
        return self.x[idx], self.y[idx]

dataset = MyDataset([[1, 2], [3, 4], [5, 6]], [0, 1, 0])
print(dataset[1])

shuffle=TrueXáo trộn các mẫu mỗi epoch, thường dùng cho tập train.
transformTiền xử lý/biến đổi trước khi mô hình nhận dữ liệu.

Train / Validation / Test

Nên chia dữ liệu thành train để cập nhật trọng số, validation để chọn hyperparameter, và test để báo cáo kết quả cuối cùng. Dự án tối giản bên dưới dùng tập test để minh họa đánh giá qua epoch; trong dự án thực tế hãy tách riêng validation, tránh chọn mô hình dựa liên tục trên test.

07 Xây dựng mạng nơ-ron bằng nn.Module

Một mô hình là lớp Python kế thừa nn.Module. Tạo các lớp con trong __init__; định nghĩa luồng dữ liệu trong forward; gọi model(x) để chạy forward, thay vì tự gọi model.forward(x).

Python
import torch
from torch import nn

class FashionMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Flatten(),
            nn.Linear(28 * 28, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        return self.layers(x)  # logits, chưa Softmax

model = FashionMLP()
sample = torch.randn(32, 1, 28, 28)
print(model(sample).shape)  # torch.Size([32, 10])
Ảnh đầu vào 1 × 28 × 28
→
Flatten 784
→
Linear + ReLU 256
→
Linear + ReLU 128
→
Logits 10 lớp

ReLU tạo tính phi tuyến: max(0, x). Các lớp nn.Linear học trọng số và bias; model.parameters() đưa chúng cho optimizer cập nhật.

Vì sao đầu ra là logits?

Đầu ra cuối cùng gồm 10 điểm số chưa chuẩn hóa, gọi là logits. Hàm nn.CrossEntropyLoss nhận trực tiếp logits và nhãn nguyên từ 0 đến 9; không cần chèn Softmax vào mô hình khi dùng hàm loss này.

08 Loss function và Optimizer

Loss function đo mức sai lệch giữa dự đoán và nhãn. Optimizer dùng gradient để điều chỉnh tham số. Một lựa chọn tốt cho bài toán phân loại nhiều lớp là nn.CrossEntropyLoss() + torch.optim.AdamW.

Python
import torch
from torch import nn

logits = torch.tensor([[2.0, 0.1, -1.0], [0.1, 3.2, 0.5]])
target = torch.tensor([0, 1], dtype=torch.long)
criterion = nn.CrossEntropyLoss()
loss = criterion(logits, target)
print('Loss:', loss.item())
print('Class dự đoán:', logits.argmax(dim=1))

# Không gọi Softmax trước nn.CrossEntropyLoss().
Bài toánOutput của modelLoss phổ biến
Phân loại nhiều lớp (1 nhãn/mẫu)(N, C) logitsnn.CrossEntropyLoss
Phân loại nhị phân(N, 1) logitsnn.BCEWithLogitsLoss
Hồi quy(N, ...) giá trị thựcnn.MSELoss hoặc nn.L1Loss

SGD và AdamW khác nhau thế nào?

SGD là cập nhật theo hướng âm của gradient (có thể thêm momentum). AdamW tự điều chỉnh cỡ bước dựa trên thống kê gradient và tách biệt weight decay; thường là lựa chọn khởi đầu thuận tiện, không phải luôn tốt nhất.

optimizer = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)

lr (learning rate) quá lớn có thể làm loss dao động/phân kỳ; quá nhỏ khiến học chậm. weight_decay điều chuẩn tham số để hạn chế overfitting trong nhiều bối cảnh.

09 Viết vòng lặp train đúng cách

Ở mỗi batch, thứ tự cơ bản là: forward → loss → xóa gradient cũ → backward → optimizer step. Trong vòng lặp bên dưới, giả sử bạn đã tạo model, train_loader, device, loss_fn và optimizer.

Python
model.train()                              # chế độ huấn luyện
for x, y in train_loader:
    x, y = x.to(device), y.to(device)
    logits = model(x)                      # 1. forward
    loss = loss_fn(logits, y)              # 2. tính loss
    optimizer.zero_grad(set_to_none=True) # 3. xóa grad cũ
    loss.backward()                        # 4. backward
    optimizer.step()                       # 5. cập nhật tham số

Phân biệt train và eval

TRAIN model.train()

Kích hoạt hành vi huấn luyện của Dropout, BatchNorm; theo dõi gradient và cập nhật trọng số.

EVAL model.eval()

Đổi hành vi của Dropout/BatchNorm; hãy dùng thêm torch.inference_mode() khi chỉ dự đoán.

Lỗi rất thường gặp

model.eval() không tự tắt tính gradient. Ngược lại, torch.no_grad() không tự chuyển Dropout/BatchNorm sang chế độ đánh giá. Thông thường cần cả hai ý này trong vòng đánh giá.

File Python hoàn chỉnh

Nhấn Tải .py ngay trên khối mã để tải riêng dự án, hoặc Sao chép và lưu thành fashion_mnist.py. Cần cài torch và torchvision ở Chương 02.

fashion_mnist.py — Python (dự án hoàn chỉnh)
# fashion_mnist.py — chạy: python fashion_mnist.py
import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

torch.manual_seed(42)

if torch.cuda.is_available():
    device = torch.device('cuda')
elif hasattr(torch.backends, 'mps') and torch.backends.mps.is_available():
    device = torch.device('mps')
else:
    device = torch.device('cpu')
print('Thiết bị:', device)

transform = transforms.ToTensor()
train_ds = datasets.FashionMNIST(
    'data', train=True, download=True, transform=transform
)
test_ds = datasets.FashionMNIST(
    'data', train=False, download=True, transform=transform
)
train_loader = DataLoader(train_ds, batch_size=128, shuffle=True)
test_loader = DataLoader(test_ds, batch_size=128, shuffle=False)

class FashionMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Flatten(),
            nn.Linear(28 * 28, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        return self.net(x)

model = FashionMLP().to(device)
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)

def train_one_epoch():
    model.train()
    total_loss, correct, n = 0.0, 0, 0
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        optimizer.zero_grad(set_to_none=True)
        logits = model(x)
        loss = loss_fn(logits, y)
        loss.backward()
        optimizer.step()

        batch_size = x.size(0)
        total_loss += loss.item() * batch_size
        correct += (logits.argmax(dim=1) == y).sum().item()
        n += batch_size
    return total_loss / n, correct / n

@torch.inference_mode()
def evaluate():
    model.eval()
    total_loss, correct, n = 0.0, 0, 0
    for x, y in test_loader:
        x, y = x.to(device), y.to(device)
        logits = model(x)
        loss = loss_fn(logits, y)
        batch_size = x.size(0)
        total_loss += loss.item() * batch_size
        correct += (logits.argmax(dim=1) == y).sum().item()
        n += batch_size
    return total_loss / n, correct / n

for epoch in range(1, 4):
    train_loss, train_acc = train_one_epoch()
    test_loss, test_acc = evaluate()
    print(f'Epoch {epoch}: '
          f'train_loss={train_loss:.4f}, train_acc={train_acc:.1%}, '
          f'test_loss={test_loss:.4f}, test_acc={test_acc:.1%}')

path = 'fashion_mnist_mlp.pth'
torch.save(model.state_dict(), path)
print('Đã lưu:', path)

# Tạo mô hình mới cùng cấu trúc và nạp lại trọng số.
restored = FashionMLP().to(device)
weights = torch.load(path, map_location=device, weights_only=True)
restored.load_state_dict(weights)
restored.eval()

image, label = test_ds[0]
with torch.inference_mode():
    prediction = restored(image.unsqueeze(0).to(device)).argmax(1).item()
print('Nhãn thật:', test_ds.classes[label])
print('Dự đoán:', test_ds.classes[prediction])
Đọc kết quả thế nào?

Giá trị train_loss/test_loss càng nhỏ thường càng tốt. accuracy là tỷ lệ dự đoán đúng; kết quả cụ thể thay đổi tùy phiên bản thư viện, bộ xử lý, seed và điều kiện huấn luyện. Không có một con số chính xác được bảo đảm.

Giải thích quy trình chạy

  1. Chọn device: ưu tiên CUDA, rồi MPS, cuối cùng CPU.
  2. Tải FashionMNIST: ToTensor() biến ảnh thành tensor có shape (1,28,28).
  3. Tạo DataLoader: mỗi batch tối đa 128 ảnh, shape (N,1,28,28).
  4. Tạo MLP: 3 lớp Linear cho ra 10 logits trên mỗi ảnh.
  5. Huấn luyện: gọi train_one_epoch(); tính loss trung bình theo số ảnh (không phải trung bình đều giữa batch kích thước khác nhau).
  6. Đánh giá: chuyển eval(), dùng inference_mode(), tính accuracy.
  7. Lưu và nạp: sử dụng state_dict với weights_only=True.
Hướng mở rộng thực tế

Tách 10–20% tập train làm validation, thêm early stopping, theo dõi biểu đồ loss và thử CNN ở Chương 12. Chỉ dùng tập test để báo cáo cuối, sau khi chốt mô hình và hyperparameter.

11 Accuracy, precision, recall và confusion matrix

Accuracy = số dự đoán đúng / tổng số mẫu. Khi dữ liệu mất cân bằng (ví dụ 95% thuộc một lớp), accuracy có thể gây hiểu nhầm. Khi đó cần thêm precision, recall, F1-score theo từng lớp.

Chỉ sốCông thứcKhi nào hữu ích?
PrecisionTP / (TP + FP)Muốn giảm dự đoán dương tính sai.
RecallTP / (TP + FN)Muốn phát hiện càng nhiều mẫu dương càng tốt.
F12PR / (P + R)Cân bằng precision và recall.
Confusion matrixMa trận nhãn thật × nhãn dự đoánXem những lớp nào hay bị nhầm.

TP = true positive, FP = false positive, FN = false negative. Với nhiều lớp, áp dụng theo từng lớp theo cách one-vs-rest; nhớ xử lý trường hợp mẫu số bằng 0.

Python
# Chạy sau khi đã có model, test_loader và device.
import torch

cm = torch.zeros((10, 10), dtype=torch.int64)
model.eval()
with torch.inference_mode():
    for x, y in test_loader:
        preds = model(x.to(device)).argmax(dim=1).cpu()
        for truth, pred in zip(y, preds):
            cm[int(truth), int(pred)] += 1

print('Ma trận nhầm lẫn (hàng: thật, cột: dự đoán):')
print(cm)
print('Accuracy:', cm.diag().sum().item() / cm.sum().item())
Tránh data leakage

Không tính mean/std, tạo từ điển đặc trưng hay fit chuẩn hóa trên toàn bộ dữ liệu trước khi chia train/validation/test nếu quy trình đó làm rò rỉ thông tin từ tập đánh giá.

12 CNN: mạng tích chập cho dữ liệu ảnh

MLP làm phẳng ảnh và mất cấu trúc không gian. Convolutional Neural Network (CNN) sử dụng kernel trượt qua ảnh để học đặc trưng địa phương như cạnh, góc và họa tiết. MaxPool2d giảm kích thước không gian.

Input1 × 28 × 28
→
Conv + Pool16 × 14 × 14
→
Conv + Pool32 × 7 × 7
→
Linear10 logits
Python
import torch
from torch import nn

class FashionCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3, padding=1), nn.ReLU(),
            nn.MaxPool2d(2),  # 28x28 -> 14x14
            nn.Conv2d(16, 32, kernel_size=3, padding=1), nn.ReLU(),
            nn.MaxPool2d(2)   # 14x14 -> 7x7
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(32 * 7 * 7, 128), nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        return self.classifier(self.features(x))

model = FashionCNN().to(device)
# Dùng lại loss_fn, optimizer và các vòng lặp ở dự án trước;
# nhớ tạo lại optimizer với model.parameters() của CNN mới.
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)
print(model(torch.randn(4, 1, 28, 28).to(device)).shape)  # [4, 10]

Công thức kích thước sau Conv2d

Trên mỗi chiều không gian, kích thước đầu ra xấp xỉ floor((L + 2P − D(K − 1) − 1) / S + 1), với L là kích thước đầu vào, P padding, D dilation, K kernel size, S stride. Ở ví dụ trên, kernel_size=3, padding=1, stride=1 giữ nguyên H × W; MaxPool2d(2) giảm một nửa mỗi chiều.

Để thử CNN, thay phần khởi tạo MLP trong dự án bằng FashionCNN().to(device) và tạo lại optimizer. Các hàm train_one_epoch()/evaluate() vẫn dùng được vì nhận cùng định dạng dữ liệu và logits.

13 Transfer learning với mô hình pretrained

Khi dữ liệu ít, bạn có thể dùng mô hình đã huấn luyện trên tập ảnh lớn, đóng băng các lớp đặc trưng và chỉ học lớp phân loại mới. torchvision.models cung cấp các kiến trúc cùng weights và transforms phù hợp.

Python
from torch import nn
from torchvision.models import resnet18, ResNet18_Weights

weights = ResNet18_Weights.DEFAULT
preprocess = weights.transforms()  # resize/crop/normalize phù hợp weights
model = resnet18(weights=weights)   # tải trọng số nếu chưa có cache

for p in model.parameters():
    p.requires_grad = False

num_classes = 3  # ví dụ: tập dữ liệu tùy chỉnh có 3 lớp ảnh RGB
model.fc = nn.Linear(model.fc.in_features, num_classes)
model = model.to(device)
optimizer = torch.optim.AdamW(model.fc.parameters(), lr=1e-3)

# Áp dụng preprocess lên ảnh PIL trong Dataset trước khi huấn luyện.
Khác gì FashionMNIST?

ResNet18 pretrained thường mong đợi ảnh RGB với biến đổi đầu vào thích hợp; đừng đưa trực tiếp ảnh FashionMNIST 1 kênh mà không chuyển đổi/tiền xử lý đúng. weights.transforms() giúp áp dụng chuẩn preprocessing tương ứng. Tải weights cần Internet trong lần đầu.

Khi nào nên fine-tune?

Nếu chỉ thay lớp fc chưa đủ, bạn có thể mở khóa một số tầng cuối (requires_grad=True) và huấn luyện với learning rate nhỏ hơn. Luôn theo dõi validation loss để tránh overfitting.

14 Lưu mô hình, checkpoint và suy luận

Inference là dùng mô hình đã huấn luyện để dự đoán trên dữ liệu mới. Mô hình cần cùng cấu trúc khi nạp state_dict và nên đặt trong chế độ eval().

torch.save(model.state_dict(), 'weights.pth')model.load_state_dict(torch.load('weights.pth', map_location=device, weights_only=True))model.eval()

Nếu muốn tiếp tục huấn luyện đúng trạng thái, hãy lưu thêm optimizer.state_dict(), epoch và (nếu cần) trạng thái scheduler/scaler. Đây gọi là checkpoint.

Python
# Lưu để huấn luyện tiếp (giả sử model, optimizer, epoch đã tồn tại)
torch.save({
    'epoch': epoch,
    'model': model.state_dict(),
    'optimizer': optimizer.state_dict(),
}, 'checkpoint.pth')

# Phải khởi tạo lại cùng kiến trúc model & optimizer trước khi nạp.
ckpt = torch.load('checkpoint.pth', map_location=device, weights_only=True)
model.load_state_dict(ckpt['model'])
optimizer.load_state_dict(ckpt['optimizer'])
start_epoch = ckpt['epoch'] + 1
Bảo mật file mô hình

Không tải file checkpoint không đáng tin cậy và tùy tiện gọi torch.load(..., weights_only=False). Tham số weights_only=True hạn chế những đối tượng có thể giải tuần tự hóa, nhưng bạn vẫn cần coi file bên ngoài là dữ liệu không tin cậy.

15 Tăng tốc với AMP, DataLoader và torch.compile

Automatic Mixed Precision (AMP)

AMP cho phép một phần phép toán dùng độ chính xác thấp hơn trên thiết bị hỗ trợ để tăng tốc/giảm bộ nhớ. Ví dụ dưới đây chỉ dành cho CUDA, và giả sử model đã được chuyển sang cuda.

Python
# Ví dụ riêng cho máy hỗ trợ NVIDIA CUDA.
scaler = torch.amp.GradScaler('cuda')
model.train()
for x, y in train_loader:
    x = x.to('cuda', non_blocking=True)
    y = y.to('cuda', non_blocking=True)
    optimizer.zero_grad(set_to_none=True)

    with torch.autocast(device_type='cuda', dtype=torch.float16):
        logits = model(x)
        loss = loss_fn(logits, y)

    scaler.scale(loss).backward()
    scaler.step(optimizer)
    scaler.update()

Biên dịch tối ưu với torch.compile

Python
# Tùy chọn tăng tốc PyTorch 2.x (tùy backend/phần cứng).
model = FashionMLP().to(device)
model = torch.compile(model)
# Huấn luyện theo quy trình thông thường.
# Lần gọi đầu có thể chậm do biên dịch; hãy đo nhiều lượt.

torch.compile thuộc PyTorch 2.x, có thể tăng tốc một số workload nhưng không bảo đảm nhanh hơn mọi mô hình/thiết bị. Đợt đầu có thể mất thời gian compile, một số backend hoặc toán tử không tương thích; chỉ bật sau khi chương trình eager chạy đúng.

Checklist thực hành tối ưu

  • Đo trước khi tối ưu: xác định nghẽn ở đọc dữ liệu, CPU, GPU hay bộ nhớ.
  • Dùng batch đủ lớn nhưng vẫn vừa bộ nhớ; không tăng mù quáng.
  • Trên CUDA, cân nhắc pin_memory=True trong DataLoader và non_blocking=True khi chuyển tensor.
  • Dùng num_workers > 0 khi đã kiểm tra môi trường hỗ trợ; cân nhắc persistent_workers=True nếu có workers.
  • Không tính hoặc giữ lại các tensor gradient trong vòng đánh giá không cần thiết.
  • Theo dõi độ chính xác số học khi dùng mixed precision.

16 Debug PyTorch như thế nào?

Đừng chỉ đọc stack trace: hãy in shape, dtype, device của input, nhãn và logits tại nơi lỗi xảy ra. Nếu mô hình không học, thử overfit một batch nhỏ trước khi thay kiến trúc phức tạp.

Python
def inspect_batch(x, y, model):
    print('x:', x.shape, x.dtype, x.device)
    print('y:', y.shape, y.dtype, y.device)
    with torch.inference_mode():
        logits = model(x)
    print('logits:', logits.shape, logits.dtype)

# Dùng với model đang ở đúng device:
x, y = next(iter(train_loader))
inspect_batch(x.to(device), y.to(device), model)

Bảng tra lỗi nhanh

RuntimeError: mat1 and mat2 shapes cannot be multiplied⌄

Số đặc trưng của đầu vào không trùng in_features của nn.Linear. In x.shape và shape sau Flatten; sửa công thức kích thước hoặc dùng nn.LazyLinear khi phù hợp.

Expected all tensors to be on the same device⌄

Đưa mô hình, input và nhãn sang thiết bị phù hợp: model.to(device), x = x.to(device), y = y.to(device).

CrossEntropyLoss: kiểu nhãn hoặc shape không hợp lệ⌄

Với bài toán phân loại nhiều lớp bằng nhãn chỉ số, logits thường có shape (N,C), nhãn có shape (N,), dtype torch.long, giá trị trong [0,C−1].

CUDA out of memory (OOM)⌄

Giảm batch size, giảm kích thước mô hình/ảnh, tránh giữ tensor của nhiều bước trong list mà chưa detach(); cân nhắc AMP nếu phù hợp. Đừng mặc định rằng empty_cache() sẽ sửa được mọi OOM.

Loss = NaN hoặc bùng nổ⌄

Kiểm tra dữ liệu NaN/Inf, nhãn bất thường, learning rate quá lớn, loss thiếu ổn định số học và gradient. Thử giảm learning rate hoặc dùng torch.nn.utils.clip_grad_norm_ khi phù hợp.

Accuracy không tăng⌄

Kiểm tra nhãn và số lớp, preprocessing, thứ tự zero_grad/backward/step, learning rate, khả năng mô hình và dữ liệu. Test bằng cách cho mô hình học thuộc 16–32 mẫu; nếu không được, ưu tiên xem lại pipeline.

Kiểm tra gradient bằng sai phân hữu hạn

Python
# Kiểm tra gradient của một phép toán nhỏ bằng sai phân hữu hạn.
import torch

x = torch.tensor(1.5, requires_grad=True)
f = x**3
f.backward()
eps = 1e-3
numeric = ((1.5 + eps)**3 - (1.5 - eps)**3) / (2 * eps)
print('Autograd:', x.grad.item()) # 6.75
print('Sai phân:', numeric)        # xấp xỉ 6.75

17 Bài tập có gợi ý & quiz ngắn

Thử giải trước khi mở đáp án. Những bài này giúp bạn tự kiểm tra tensor, autograd, mô hình và phương pháp đánh giá.

Bài 01 Tạo tensor kích thước (4, 3), cộng vector (3,), tính mean theo hàng.

Gợi ý: tạo tensor bằng torch.arange(12), dùng reshape và mean(dim=1).

x = torch.arange(12, dtype=torch.float32).reshape(4, 3)y = x + torch.tensor([1., 2., 3.])row_means = y.mean(dim=1)
Bài 02 Viết hàm f(x) = 3x² − 4x và tính gradient tại x = 2.

Đáp án: đạo hàm là 6x − 4, tại x = 2 bằng 8.

x = torch.tensor(2., requires_grad=True)y = 3 * x**2 - 4 * xy.backward(); print(x.grad.item()) # 8.0
Bài 03 Thay MLP bằng CNN và so sánh validation accuracy.

Gợi ý: dùng lớp FashionCNN ở Chương 12; giữ cùng cách chia validation, số epoch và seed; tạo optimizer mới. So sánh không chỉ accuracy mà cả thời gian mỗi epoch.

Bài 04 Thêm tập validation và lưu best checkpoint.

Gợi ý: dùng torch.utils.data.random_split để chia tập train, ví dụ 54.000 train + 6.000 validation. Sau mỗi epoch, nếu val_loss < best_val_loss, lưu model.state_dict(). Test duy nhất sau khi đã chọn checkpoint tốt nhất.

Bài 05 Thử 3 learning rate: 0.01, 0.001 và 0.0001.

Gợi ý: huấn luyện độc lập từ trọng số khởi tạo mới, giữ nguyên dữ liệu và số epoch; lập bảng train/validation loss. Quan sát hiện tượng học chậm và dao động.
