Java là gì?

Hiểu Java dùng để làm gì, khác JavaScript ở đâu và cách chương trình chạy.

Java là ngôn ngữ lập trình kiểu tĩnh (statically typed), hướng đối tượng, đa nền tảng và được dùng nhiều trong backend, ứng dụng doanh nghiệp, công cụ xử lý dữ liệu và hệ sinh thái Android (bên cạnh Kotlin). Java ưu tiên tính rõ ràng, an toàn kiểu dữ liệu và khả năng bảo trì.

☕Ngôn ngữJava: cú pháp, lớp, phương thức, kiểu dữ liệu.
⚙JVMMáy ảo thực thi bytecode trên hệ điều hành.
🧰JDKBộ công cụ chứa trình biên dịch và các công cụ lập trình.

Chương trình Java chạy thế nào?

Main.javaMã nguồn
→ javac →
Main.classBytecode
→ JVM →
Kết quảTrên máy của bạn

JDK (Java Development Kit) dùng để phát triển; JVM (Java Virtual Machine) thực thi bytecode; JRE là môi trường chạy Java (khái niệm vẫn hữu ích, nhưng các bản JDK hiện đại thường đã đủ cho người học).

Java ≠ JavaScript
Hai ngôn ngữ khác nhau. Java thường biên dịch sang bytecode chạy trên JVM; JavaScript được dùng phổ biến cho web và chạy trong trình duyệt hoặc môi trường như Node.js.

Để thống nhất, các ví dụ trong tài liệu dùng cú pháp tương thích với Java 21 trở lên. Bạn có thể cài JDK 25 LTS để học và phát triển dự án dài hạn; Java 27 là bản tính năng mới hơn tại thời điểm cập nhật 11/2026.

Cài JDK và môi trường

Cài Java, kiểm tra cấu hình và chọn trình soạn thảo.

  1. Tải một bộ JDK 25 LTS từ Oracle hoặc bản phân phối Eclipse Temurin. Chọn đúng hệ điều hành và kiến trúc CPU.
  2. Cài đặt theo hướng dẫn của bộ cài. Đảm bảo lệnh java và javac có thể gọi được từ terminal; nếu không, hãy kiểm tra biến PATH.
  3. Chọn IDE: IntelliJ IDEA Community, VS Code với Java Extension Pack, hoặc Eclipse. Với bài đầu tiên, terminal + trình soạn thảo text là đủ.

Kiểm tra sau khi cài

Terminalbash
java -version
javac -version

Hai lệnh phải hiển thị phiên bản JDK (ví dụ 25.x). Nếu báo “command not found” hoặc “not recognized”, hãy mở lại terminal, kiểm tra JAVA_HOME và PATH.

Mở PowerShell, chạy java -version. Nếu thiếu, tìm vị trí thư mục bin của JDK rồi thêm nó vào biến môi trường Path. Mở PowerShell mới sau khi cập nhật.

Mở Terminal, kiểm tra java -version và /usr/libexec/java_home -V. Nếu dùng nhiều JDK, có thể thiết lập JAVA_HOME trỏ đến bản phù hợp.

Cài JDK bằng package manager của bản phân phối hoặc bộ cài Temurin. Kiểm tra java -version, javac -version và lựa chọn JDK mặc định nếu có nhiều bản.

Chọn phiên bản
Hãy dùng một bản LTS ổn định để học. Các tính năng mới trong Java 27 không cần thiết để hoàn thành giáo trình này.

Cú pháp, biến và kiểu dữ liệu

Phân biệt kiểu nguyên thủy, kiểu tham chiếu, hằng và phạm vi biến.

Biến là một tên trỏ đến giá trị theo kiểu đã khai báo. Trong Java, trình biên dịch kiểm tra kiểu dữ liệu. Biến cục bộ phải được gán giá trị trước khi đọc.

Main.javajava
public class Main {
    public static void main(String[] args) {
        int tuoi = 20;
        double diem = 8.75;
        boolean daTotNghiep = false;
        char xepLoai = 'A';
        String hoTen = "Nguyễn An";
        final double PI = 3.141592653589793;

        System.out.println(hoTen + " - " + tuoi);
        System.out.println("Điểm: " + diem);
    }
}

String, mảng và các đối tượng khác là kiểu tham chiếu, không phải kiểu nguyên thủy. Từ khóa final ngăn gán lại biến sau khi đã khởi tạo; điều đó không tự làm đối tượng được tham chiếu trở nên bất biến.

String và nhập dữ liệu

Nối chuỗi, so sánh chuỗi, định dạng và đọc bàn phím.

Một String là đối tượng bất biến (immutable): các phương thức như toUpperCase() trả về chuỗi mới thay vì sửa chuỗi gốc.

Main.javajava
public class Main {
    public static void main(String[] args) {
        String ten = "  Java  ";
        System.out.println(ten.trim().toUpperCase()); // JAVA
        System.out.println("Java".equals("java"));  // false
        System.out.println("Java".equalsIgnoreCase("java")); // true
        System.out.println("Xin chào".contains("chào")); // true
        System.out.printf("Giá: %.2f%n", 19.456);
    }
}

Nhập từ bàn phím bằng Scanner

Main.javajava
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        try (Scanner sc = new Scanner(System.in)) {
            System.out.print("Tên của bạn: ");
            String ten = sc.nextLine();
            System.out.print("Tuổi của bạn: ");
            int tuoi = Integer.parseInt(sc.nextLine());
            System.out.println("Chào " + ten + ", " + tuoi + " tuổi!");
        }
    }
}

Đọc cả dòng bằng nextLine() rồi chuyển sang số bằng Integer.parseInt giúp tránh tình huống ký tự xuống dòng còn sót lại khi trộn nextInt() và nextLine(). Nếu nhập số không hợp lệ, phương thức sẽ ném ngoại lệ NumberFormatException.

StringBuilder khi nối chuỗi trong vòng lặp

Ví dụ ngắnjava
StringBuilder sb = new StringBuilder();
for (int i = 1; i <= 3; i++) {
    sb.append(i).append(" ");
}
System.out.println(sb.toString().trim()); // 1 2 3

Mảng và duyệt dữ liệu

Tạo mảng, truy cập phần tử, tính tổng và tránh lỗi chỉ số.

Mảng (array) có số phần tử cố định. Chỉ số bắt đầu từ 0; phần tử cuối có chỉ số length - 1.

Main.javajava
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] diem = {7, 9, 8, 10};
        int tong = 0;
        for (int x : diem) {
            tong += x;
        }
        double trungBinh = (double) tong / diem.length;
        Arrays.sort(diem);
        System.out.println(Arrays.toString(diem)); // [7, 8, 9, 10]
        System.out.println("TB: " + trungBinh);

        int[][] maTran = {{1, 2}, {3, 4}};
        System.out.println(maTran[1][0]); // 3
    }
}

Nếu truy cập diem[4] khi mảng chỉ có 4 phần tử, chương trình ném ArrayIndexOutOfBoundsException. Mảng đa chiều trong Java thực chất là “mảng của các mảng”; độ dài từng hàng có thể khác nhau.

Mảng hay ArrayList?
Dùng mảng khi kích thước cố định hoặc khi làm việc sát với kiểu nguyên thủy; dùng ArrayList khi cần thêm và xóa phần tử linh hoạt.

Phương thức, tham số và scope

Tách chương trình thành các thao tác nhỏ và tái sử dụng.

Main.javajava
public class Main {
    static int cong(int a, int b) {
        return a + b;
    }

    static double trungBinh(double... diem) {
        double tong = 0;
        for (double x : diem) tong += x;
        return diem.length == 0 ? 0 : tong / diem.length;
    }

    public static void main(String[] args) {
        System.out.println(cong(3, 5));       // 8
        System.out.println(trungBinh(7, 8, 9)); // 8.0
    }
}

Một phương thức có kiểu trả về, tên, danh sách tham số và thân. void nghĩa là không trả về giá trị. static cho phép gọi thông qua lớp mà không tạo đối tượng. double... là varargs, nhận số lượng đối số linh hoạt.

Overloading và truyền tham số

Ví dụ ngắnjava
static int nhanDoi(int n) { return n * 2; }
static double nhanDoi(double n) { return n * 2; }

Đây là overloading: cùng tên, khác danh sách kiểu tham số. Java luôn truyền tham số theo giá trị: với đối tượng, giá trị được sao chép là tham chiếu. Phương thức có thể thay đổi trạng thái đối tượng thông qua tham chiếu đó, nhưng không thay được biến tham chiếu của nơi gọi.

Class, object và constructor

Tạo lớp, đối tượng và gom dữ liệu với hành vi.

Class (lớp) là bản thiết kế, object (đối tượng) là một thể hiện được tạo từ lớp đó. Lớp chứa trường dữ liệu (fields), phương thức (methods) và hàm khởi tạo (constructor).

Main.javajava
public class Main {
    static class TaiKhoan {
        private String chuSoHuu;
        private long soDu;

        TaiKhoan(String chuSoHuu, long soDuBanDau) {
            this.chuSoHuu = chuSoHuu;
            this.soDu = soDuBanDau;
        }

        void nap(long soTien) {
            if (soTien <= 0) throw new IllegalArgumentException("Số tiền phải dương");
            soDu += soTien;
        }

        long getSoDu() { return soDu; }
    }

    public static void main(String[] args) {
        TaiKhoan tk = new TaiKhoan("An", 100_000);
        tk.nap(50_000);
        System.out.println(tk.getSoDu()); // 150000
    }
}

new tạo một đối tượng. this tham chiếu đối tượng hiện tại. private che giấu dữ liệu khỏi mã bên ngoài lớp; các phương thức công khai được thiết kế để bảo vệ tính hợp lệ. Trong ví dụ này, nap từ chối số tiền không dương.

Nguyên tắc quan trọng
Đừng tự động tạo setter cho mọi field. Chỉ cung cấp thao tác mà đối tượng thật sự cần; giữ các quy tắc nghiệp vụ bên trong lớp.

04. Abstraction

Trừu tượng: biểu diễn điều quan trọng, che phần cài đặt.

Main.javajava
public class Main {
    static abstract class DongVat {
        abstract String tiengKeu();
    }

    static class Cho extends DongVat {
        @Override String tiengKeu() { return "Gâu gâu"; }
    }

    static class Meo extends DongVat {
        @Override String tiengKeu() { return "Meo meo"; }
    }

    public static void main(String[] args) {
        DongVat[] ds = {new Cho(), new Meo()};
        for (DongVat x : ds) {
            System.out.println(x.tiengKeu());
        }
    }
}

abstract cho phép khai báo phương thức chưa có phần thân; lớp con buộc triển khai nếu không còn trừu tượng. @Override giúp trình biên dịch kiểm tra việc ghi đè. Dù phần tử có kiểu khai báo DongVat, Java gọi phiên bản phương thức theo đối tượng thực tế: đó là đa hình.

Kế thừa hay kết hợp?
Ưu tiên composition (một lớp chứa đối tượng khác) khi quan hệ không thực sự là “A là một B”. Kế thừa sai cách dễ tạo phụ thuộc chặt.

Interface, enum, record và sealed

Interface là hợp đồng

class ViDienTu implements ThanhToan {

Một lớp có thể implements nhiều interface nhưng chỉ extends tối đa một lớp. Interface cũng có thể định nghĩa phương thức default và static.

Record cho dữ liệu bất biến theo thành phần

public class Main {

equals, hashCode và sắp xếp

So sánh nội dung đối tượng, dùng HashMap và Comparator.

Mặc định, Object.equals so sánh theo danh tính đối tượng. Với kiểu dữ liệu có ý nghĩa giá trị, hãy định nghĩa equals và hashCode nhất quán; record tự sinh hai phương thức này theo các thành phần.

Main.javajava
import java.util.*;

public class Main {
    record SanPham(String ten, int gia) {}

    public static void main(String[] args) {
        var a = new SanPham("Bút", 5000);
        var b = new SanPham("Bút", 5000);
        System.out.println(a.equals(b)); // true

        List<SanPham> ds = new ArrayList<>(List.of(
            new SanPham("Vở", 12000), new SanPham("Bút", 5000)
        ));
        ds.sort(Comparator.comparingInt(SanPham::gia));
        System.out.println(ds); // Bút trước Vở
    }
}

Quy tắc cốt lõi: nếu a.equals(b) là true, thì a.hashCode() == b.hashCode() phải đúng. Khi làm khóa trong HashMap, tránh thay đổi các thuộc tính tham gia tính hash sau khi đưa vào map.

Exception và xử lý lỗi

Bắt lỗi có chủ đích và giải phóng tài nguyên.

Main.javajava
public class Main {
    static int parseTuoi(String raw) {
        int tuoi = Integer.parseInt(raw);
        if (tuoi < 0) throw new IllegalArgumentException("Tuổi không âm");
        return tuoi;
    }

    public static void main(String[] args) {
        try {
            System.out.println(parseTuoi("abc"));
        } catch (NumberFormatException e) {

        } finally {
            System.out.println("Đã xử lý xong.");
        }
    }
}

Có hai nhóm quan trọng: checked exceptions (ví dụ IOException) phải được bắt hoặc khai báo throws; unchecked exceptions (như IllegalArgumentException) không bắt buộc khai báo. Error thường biểu thị sự cố nghiêm trọng và không nên xử lý như lỗi nghiệp vụ thông thường.

Lambda, Stream và Optional

Viết thao tác lọc, biến đổi và tổng hợp gọn gàng.

Lambda là cách viết ngắn cho một triển khai của functional interface (interface có đúng một phương thức trừu tượng). Stream mô tả chuỗi thao tác dữ liệu, thường gồm nguồn, các thao tác trung gian và thao tác kết thúc.

Main.javajava
import java.util.*;

public class Main {
    record HocVien(String ten, int diem) {}

    public static void main(String[] args) {
        List<HocVien> ds = List.of(
            new HocVien("An", 8),
            new HocVien("Bình", 5),
            new HocVien("Lan", 9)
        );

        List<String> gioi = ds.stream()
            .filter(h -> h.diem() >= 8)
            .map(HocVien::ten)
            .sorted()
            .toList();

        int tongDiem = ds.stream().mapToInt(HocVien::diem).sum();
        System.out.println(gioi);    // [An, Lan]
        System.out.println(tongDiem); // 22
    }
}

Optional tránh kết quả vắng mặt

Ví dụ ngắnjava
Optional<String> ten = List.of("An", "Bình")
    .stream()
    .filter(s -> s.startsWith("L"))
    .findFirst();
System.out.println(ten.orElse("Không tìm thấy"));

Stream.toList() cho một danh sách không thể sửa đổi. Không tái sử dụng một stream sau thao tác kết thúc. Không lạm dụng Stream cho mọi vòng lặp: for vẫn rất tốt khi mã sẽ dễ hiểu hơn.

Ngày giờ, số tiền và định dạng

Sử dụng java.time và BigDecimal thay vì sai số số thực.

Main.javajava
import java.time.*;
import java.time.format.DateTimeFormatter;
import java.math.BigDecimal;

public class Main {
    public static void main(String[] args) {
        LocalDate homNay = LocalDate.now();
        LocalDate hanNop = homNay.plusDays(7);
        System.out.println(hanNop.format(
            DateTimeFormatter.ofPattern("dd/MM/yyyy")
        ));

        BigDecimal gia = new BigDecimal("19.90");
        BigDecimal soLuong = new BigDecimal("3");
        System.out.println(gia.multiply(soLuong)); // 59.70

Các lớp phổ biến: LocalDate (ngày), LocalTime (giờ), LocalDateTime (ngày giờ không có múi giờ), Instant (thời điểm trên dòng thời gian), ZonedDateTime (gắn múi giờ). Khi lưu thời điểm toàn cầu, ưu tiên Instant; lúc hiển thị mới chuyển sang múi giờ người dùng.

Không dùng double cho tiền

Luồng, đồng thời và virtual threads

Hiểu Thread, Runnable và khi nào dùng virtual thread.

Một thread là luồng thực thi. Nhiều thread hữu ích cho tác vụ I/O và có thể giúp tận dụng CPU, nhưng dễ phát sinh tranh chấp dữ liệu nếu cùng ghi biến chia sẻ.

Main.javajava
public class Main {
    public static void main(String[] args) throws InterruptedException {
        Thread t = Thread.startVirtualThread(() -> {
            System.out.println("Xin chào từ virtual thread!");
        });
        t.join(); // Chờ luồng hoàn thành
    }
}

Virtual threads được đưa vào Java 21 dưới dạng tính năng chính thức. Chúng đặc biệt hữu ích khi có nhiều tác vụ chờ I/O; chúng không tự làm một phép tính nặng CPU chạy nhanh hơn. Với xử lý CPU-bound, hãy cân nhắc pool có mức song song được giới hạn.

Giảm race condition

Ví dụ ngắnjava
import java.util.concurrent.atomic.AtomicInteger;

AtomicInteger dem = new AtomicInteger(0);
dem.incrementAndGet();
System.out.println(dem.get());

Khi nhiều luồng cùng thay đổi dữ liệu, cân nhắc bất biến, synchronized, AtomicInteger, cấu trúc trong java.util.concurrent và cách thiết kế không chia sẻ trạng thái. Không mặc định dùng multi-thread cho mọi bài toán.

Lỗi phổ biến, cách gỡ lỗi và nguyên tắc clean code.

Hiện tượngNguyên nhân thường gặpCách kiểm tra
cannot find symbolSai tên biến/lớp hoặc thiếu import.Kiểm tra chính tả, package, import.

Quy trình debug 4 bước

  1. Đọc stack trace từ trên xuống; xác định file và dòng gây lỗi.
  2. Tạo đầu vào nhỏ nhất tái hiện được lỗi.
  3. Dùng breakpoint trong IDE để theo dõi biến từng bước; thêm log có chọn lọc.
  4. Sửa nguyên nhân, chạy lại test và bổ sung bài kiểm thử ngăn lỗi tái diễn.

Quy tắc nên áp dụng

  • Tên lớp PascalCase, tên biến/phương thức camelCase, hằng số UPPER_SNAKE_CASE.
  • Một phương thức nên làm một công việc rõ ràng, có tên mô tả được mục đích.
  • Ưu tiên dữ liệu bất biến, xử lý đầu vào và tránh trạng thái toàn cục mutable.
  • Không lưu bí mật trong mã nguồn; dùng biến môi trường hoặc hệ thống quản lý secret.
  • Test cả trường hợp thông thường lẫn biên: rỗng, 0, âm, null, dữ liệu lớn.

    }

    static int timViTri(int id) {
        for (int i = 0; i < ds.size(); i++) {
            if (ds.get(i).id() == id) return i;
        }
        return -1;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        while (true) {
            System.out.println("\n1. Thêm | 2. Xem | 3. Xong | 4. Xóa | 0. Thoát");
            System.out.print("Chọn: ");
            String chon = sc.nextLine().trim();

            switch (chon) {
                case "1" -> {
                    System.out.print("Nội dung: ");
                    String noiDung = sc.nextLine().trim();
                    if (noiDung.isEmpty()) {
                        System.out.println("Nội dung không được rỗng.");
                    } else {
                        ds.add(new CongViec(idTiepTheo++, noiDung, false));
                        System.out.println("Đã thêm.");
                    }
                }
                case "2" -> inDanhSach();
                case "3", "4" -> {
                    System.out.print("Nhập ID: ");
                    try {
                        int id = Integer.parseInt(sc.nextLine().trim());
                        int viTri = timViTri(id);
                        if (viTri == -1) {
                            System.out.println("Không tìm thấy ID.");
                        } else if (chon.equals("3")) {
                            ds.set(viTri, ds.get(viTri).hoanThanh());
                            System.out.println("Đã đánh dấu hoàn thành.");
                        } else {
                            ds.remove(viTri);
                            System.out.println("Đã xóa.");
                        }
                    } catch (NumberFormatException e) {
                        System.out.println("ID phải là số nguyên.");
                    }
                }
                case "0" -> {
                    System.out.println("Tạm biệt!");
                    return;
                }
                default -> System.out.println("Lựa chọn không hợp lệ.");
            }
        }
    }
}

Phân tích thiết kế

  • record CongViec mô tả dữ liệu và trả về bản sao cập nhật khi hoàn thành.
  • ArrayList giữ các công việc theo thứ tự; idTiepTheo cấp ID duy nhất trong một phiên chạy.
  • timViTri tách thao tác tìm kiếm, tránh lặp code.
  • switch điều khiển menu; try/catch xử lý ID sai kiểu.
