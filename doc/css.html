01

CSS là gì, và tại sao cần học?

CSS là viết tắt của Cascading Style Sheets, ngôn ngữ dùng để quyết định giao diện của tài liệu HTML: màu sắc, kiểu chữ, khoảng cách, bố cục, khả năng co giãn theo màn hình và hiệu ứng.

Hãy hình dung một trang web như ngôi nhà: HTML tạo khung và các phòng, CSS lựa chọn vật liệu, màu sơn, cách sắp xếp nội thất, còn JavaScript thêm tương tác.

HTML = nội dung

Tiêu đề, đoạn văn, liên kết, hình ảnh, biểu mẫu… mang ý nghĩa ngữ nghĩa.

CSS = trình bày

Màu sắc, kích thước, căn chỉnh, chia cột, hiệu ứng và responsive.

Mục tiêu thực tế: sau bài viết, bạn có thể đọc hiểu CSS phổ biến, tạo landing page đơn giản, sử dụng Flexbox/Grid và xử lý giao diện trên điện thoại.

02

Cú pháp và 3 cách dùng CSS

Một quy tắc CSS gồm bộ chọn (selector) và các cặp thuộc tính: giá trị. Mỗi khai báo thường kết thúc bằng dấu ;.

CSS · cấu trúc một quy tắc
h1 {
  color: #4b54e6;
  font-size: 40px;
  text-align: center;
}

Trong ví dụ: h1 là selector; color và font-size là thuộc tính; #4b54e6 và 40px là giá trị.

Cách 1: Inline CSS

HTML
<p style="color: tomato;">Xin chào!</p>

Nhanh cho trường hợp đặc biệt, nhưng khó quản lý khi dự án lớn.

Cách 2: Internal CSS

HTML
<head>
  <style>
    p { color: tomato; }
  </style>
</head>

Phù hợp với demo hoặc trang nhỏ. Chính trang blog bạn đang đọc cũng dùng cách này để hoạt động trong một file.

Cách 3: External CSS (khuyến nghị cho dự án)

HTML + CSS
<!-- index.html, đặt trong <head> -->
<link rel="stylesheet" href="style.css">

/* style.css */
p { color: tomato; }

Tách kiểu dáng khỏi nội dung để dễ tái sử dụng, bảo trì và tổ chức.

03

Selectors: chọn đúng phần tử

Selector là cách CSS xác định phần tử HTML nào sẽ được áp dụng quy tắc.

SelectorChọn phần tửVí dụ
pTất cả thẻ <p>p { ... }
.cardCó class="card".card { ... }
#heroCó id="hero"#hero { ... }
.card pMọi p nằm trong .card.card p { ... }
.card > pp là con trực tiếp của .card.card > p { ... }
input[type="email"]Input có thuộc tính type=emailinput[type="email"] { ... }
h1, h2Gộp nhiều selectorh1, h2 { ... }
HTML + CSS · class có thể tái sử dụng
<article class="card featured">
  <h2>Tiêu đề</h2>
  <p>Nội dung thẻ bài viết.</p>
</article>

.card { padding: 24px; border-radius: 12px; }
.card.featured { border: 2px solid royalblue; }
.card > h2 { margin-top: 0; }

.card.featured nghĩa là cùng một phần tử có cả hai class. Khác với .card .featured, nghĩa là phần tử .featured nằm bên trong .card.

Thực hành tốt: ưu tiên class để tạo component, dùng ID chủ yếu cho điểm neo hoặc hành vi cụ thể; tránh selector quá dài gây khó ghi đè.

04

Cascade, kế thừa và specificity

Khi nhiều quy tắc cùng tác động lên một thuộc tính, trình duyệt dùng cascade để chọn giá trị cuối cùng. Specificity chỉ là một phần của quá trình này.

Trong cùng nguồn gốc, mức quan trọng và cascade layer, cách hiểu nhanh độ ưu tiên selector thông thường là:

Inline style›#id›.class / :hover / [attr]›div / ::before
CSS · ví dụ specificity
p { color: gray; }             /* (0,0,1) */
.note { color: blue; }         /* (0,1,0) */
#intro { color: tomato; }      /* (1,0,0) */

/* <p id="intro" class="note">...</p>
   → tomato, nếu các quy tắc cùng mức cascade */

Nếu hai selector có cùng specificity và cùng mức cascade, quy tắc xuất hiện sau thường thắng. Một số thuộc tính như color và font-family được kế thừa từ cha; margin, padding, border thì không.

Lưu ý nâng cao: !important, nguồn gốc style (trình duyệt, người dùng, tác giả), cascade layers (@layer) và transition có thể thay đổi kết quả. Không nên dùng !important liên tục để “chữa cháy”; hãy kiểm tra bằng DevTools → Computed/Styles.

05

Màu sắc, đơn vị và typography

Màu sắc

CSS hỗ trợ tên màu (tomato), HEX (#4b54e6), rgb(), hsl() và nhiều hệ màu hiện đại. Thêm alpha để tạo độ trong suốt, ví dụ rgb(75 84 230 / 50%).

CSS · màu và nền
.banner {
  color: white;
  background: linear-gradient(135deg, #4b54e6, #a56cff);
  border: 1px solid rgb(255 255 255 / 30%);
  border-radius: 16px;
  box-shadow: 0 12px 30px rgb(0 0 0 / 12%);
}

Đơn vị cần nắm

Kiểu chữ dễ đọc

CSS · typography
html { font-size: 100%; }
body {
  font-family: system-ui, -apple-system, sans-serif;
  font-size: 1rem;
  line-height: 1.7;
}
h1 {
  font-size: clamp(2.5rem, 6vw, 5rem);
  line-height: 1.1;
  letter-spacing: -0.04em;
}
p { max-width: 68ch; }

clamp(min, preferred, max) giúp cỡ chữ lớn dần theo màn hình mà vẫn có giới hạn. ch hữu ích khi khống chế độ dài dòng văn bản.

06

Box model: nền tảng của khoảng cách

Mọi phần tử có thể xem như một chiếc hộp với bốn lớp: content → padding → border → margin.

Margin · khoảng cách bên ngoài
Border · đường viền
Padding · khoảng đệm
CONTENT
CSS · box sizing
*, *::before, *::after { box-sizing: border-box; }

.card {
  width: 320px;
  max-width: 100%;
  padding: 24px;
  border: 2px solid #ddd;
  margin: 16px auto;
}

Với mặc định content-box, width chỉ tính content. Khi đặt box-sizing: border-box, chiều rộng đã bao gồm content + padding + border, giúp layout dễ kiểm soát hơn. Margin luôn ở ngoài kích thước đó.

Phân biệt nhanh: padding tăng khoảng cách bên trong viền; margin tạo khoảng cách bên ngoài. Hai margin theo trục dọc của phần tử block trong normal flow có thể bị margin collapsing.

07

Display và luồng bố cục mặc định

Trước khi sắp xếp bố cục, hãy hiểu các phần tử thường nằm trong normal flow — trình duyệt bố trí theo thứ tự HTML.

Giá trịĐặc điểm
display: blockThường xuống dòng, chiếm bề ngang khả dụng; div, p mặc định kiểu này.
display: inlineNằm cùng dòng; span là ví dụ. width/height không hoạt động như block.
display: inline-blockNằm cùng dòng nhưng có hộp kích thước riêng.
display: noneKhông tạo hộp trong layout; thường cũng bị loại khỏi cây truy cập.
display: flex / gridTạo ngữ cảnh bố cục linh hoạt cho phần tử con.

Tránh dùng display: none chỉ để “ẩn khỏi mắt” nếu nội dung vẫn cần được trình đọc màn hình truy cập. Tùy mục tiêu, bạn có thể cần kỹ thuật ẩn trực quan khác.

08

Flexbox: sắp xếp theo một chiều

Flexbox cực kỳ phù hợp cho thanh điều hướng, dãy nút, căn giữa nội dung, danh sách thẻ và các bố cục chủ yếu theo một trục.

CSS · flexbox
.toolbar {
  display: flex;
  flex-direction: row;       /* trục chính: ngang */
  justify-content: space-between;
  align-items: center;      /* trục phụ */
  flex-wrap: wrap;
  gap: 16px;
}
.toolbar__item { flex: 1; }

justify-content căn theo trục chính; align-items căn theo trục vuông góc. Khi dùng flex-direction: column, hướng hai trục cũng đổi theo.

Khi nào dùng? Nếu bạn cần xếp một dãy phần tử hoặc căn chỉnh nội dung theo một hướng, chọn Flexbox. Nếu cần kiểm soát cả hàng và cột, xem CSS Grid.

09

CSS Grid: layout hai chiều

Grid được thiết kế để định vị nội dung trên cả hàng và cột. Nó đặc biệt mạnh với gallery, dashboard và bố cục trang.

CSS · grid cơ bản
.gallery {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 20px;
}

/* Card đầu tiên chiếm 2 cột */
.gallery__featured { grid-column: span 2; }

repeat(3, 1fr) nghĩa là ba cột chia đều phần không gian phân bổ. minmax(0, 1fr) giúp cột dễ co lại khi nội dung có xu hướng tràn.

Grid tự đổi số cột

CSS · responsive grid
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 240px), 1fr));
  gap: 1.25rem;
}

Trình duyệt tự tạo số cột phù hợp với chiều rộng; mỗi card cố gắng rộng ít nhất 240px nhưng không vượt quá container hẹp.

Flexbox

Menu, thanh công cụ, danh sách theo hàng/cột, căn giữa.

Grid

Dashboard, thẻ bài viết nhiều cột, bố cục phức tạp có hàng và cột.

10

Position, stacking và z-index

PositionHoạt động
staticMặc định, theo normal flow; top/left không có tác dụng.
relativeVẫn giữ chỗ trong flow; có thể dịch chuyển so với vị trí ban đầu, tạo mốc cho con absolute.
absoluteThoát normal flow, định vị theo containing block tương ứng, thường là tổ tiên đã positioned gần nhất.
fixedThường cố định so với viewport; một số tổ tiên có thể làm thay đổi containing block.
stickyKết hợp flow và bám theo ngưỡng cuộn trong scroll container liên quan.
CSS · badge trên ảnh
.product { position: relative; }
.product__badge {
  position: absolute;
  top: 12px;
  right: 12px;
  z-index: 2;
}

/* Thanh menu bám khi cuộn */
.navbar { position: sticky; top: 0; z-index: 10; }

Vì sao z-index: 9999 vẫn không nổi? Vì stacking context có thể tạo ra bởi transform, opacity nhỏ hơn 1, hoặc phần tử positioned kèm z-index. Một phần tử con không thể thoát khỏi stacking context của cha chỉ bằng số lớn hơn.

11

Responsive: đẹp trên mọi kích thước

Responsive không phải chỉ là “thu nhỏ desktop”, mà là để nội dung và bố cục thích ứng tự nhiên với vùng hiển thị.

Bắt đầu với viewport

HTML · trong <head>
<meta name="viewport" content="width=device-width, initial-scale=1">

Mobile-first với media query

CSS · mobile first
.layout { display: grid; grid-template-columns: 1fr; gap: 16px; }

@media (min-width: 768px) {
  .layout { grid-template-columns: 240px minmax(0, 1fr); }
}

img, video { max-width: 100%; height: auto; }

Ví dụ trên mặc định một cột, chỉ chuyển thành hai cột khi đủ không gian. Chọn breakpoint dựa vào lúc nội dung cần thay đổi, không nhất thiết bám cứng vào từng dòng điện thoại.

Bộ ba công cụ responsive đáng nhớ

  • max-width: 100% tránh ảnh rộng vượt container.
  • min(), max(), clamp() giới hạn kích thước linh hoạt.
  • flex-wrap, auto-fit và minmax() tạo bố cục tự thích ứng.

Checklist: kiểm tra tối thiểu ở màn hình hẹp khoảng 320–375px, tablet và desktop; đảm bảo chữ không quá nhỏ, không cuộn ngang ngoài ý muốn, các vùng bấm đủ dễ chạm.

12

Pseudo-class và pseudo-element

Pseudo-class (:) chọn trạng thái hoặc vị trí; pseudo-element (::) tạo mục tiêu kiểu dáng cho một phần của phần tử.

CSS · trạng thái và nội dung trang trí
a:hover { color: tomato; }
button:focus-visible { outline: 3px solid royalblue; }
input:invalid { border-color: crimson; }
li:nth-child(odd) { background: #f4f5fa; }

/* Chọn card chứa ảnh */
.card:has(img) { padding-top: 0; }

/* Trang trí, không nên chứa nội dung quan trọng */
.heading::before { content: "✦ "; color: tomato; }
p::selection { background: #ffe5a6; }

:hover chỉ là một trạng thái; người dùng bàn phím cần :focus-visible. ::before/::after phù hợp cho trang trí nhưng không thay thế nội dung HTML có ý nghĩa.

13

Biến CSS và các hàm thiết kế

Custom properties giúp đổi màu, khoảng cách và kích thước nhất quán trên toàn trang. Chúng được khai báo bằng tiền tố -- và đọc qua var().

CSS · design tokens
:root {
  --primary: #4b54e6;
  --space: 16px;
  --radius: 12px;
}
.button {
  background: var(--primary);
  padding: calc(var(--space) / 2) var(--space);
  border-radius: var(--radius);
}
.card { width: min(100%, 480px); }
h1 { font-size: clamp(2rem, 5vw, 4rem); }

Đổi giao diện sáng / tối

CSS · theme
:root { --bg: #ffffff; --text: #202a38; }
[data-theme="dark"] { --bg: #121923; --text: #ffffff; }
body { background: var(--bg); color: var(--text); }

Thử nút ☾ Tối ở góc trên của trang: trang blog thực tế đang sử dụng CSS custom properties để thay đổi toàn bộ màu giao diện.

14

Transition, transform và animation

transition dùng khi một thuộc tính thay đổi giữa các trạng thái (ví dụ hover). animation chạy theo khung hình do @keyframes định nghĩa.

CSS · chuyển động nhẹ nhàng
.button {
  transition: transform .2s ease, background-color .2s ease;
}
.button:hover { transform: translateY(-3px); }

@keyframes float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-8px); }
}
.icon { animation: float 2s ease-in-out infinite; }

@media (prefers-reduced-motion: reduce) {
  .icon { animation: none; }
  .button { transition: none; }
}

Ưu tiên animate transform và opacity cho chuyển động mượt; thay đổi các thuộc tính ảnh hưởng layout như width hoặc top có thể tốn chi phí hơn. Luôn cân nhắc người dùng muốn giảm chuyển động.

15

CSS hiện đại đáng học

Container queries

Media query thường dựa vào viewport; container query giúp component đổi bố cục dựa vào kích thước container chứa nó, phù hợp với hệ thống component tái sử dụng.

CSS · container query
.card-list { container-type: inline-size; }
.card { display: grid; gap: 12px; }

@container (min-width: 520px) {
  .card { grid-template-columns: 180px 1fr; }
}

CSS nesting

CSS · lồng quy tắc
.button {
  padding: 12px 20px;
  background: royalblue;
  color: white;

  &:hover { background: mediumblue; }
  &.is-active { outline: 2px solid orange; }
}

Logical properties và cascade layers

CSS · viết dễ mở rộng
.card {
  padding-inline: 24px; /* theo hướng viết, thay vì trái/phải */
  margin-block: 16px;   /* theo hướng viết, thay vì trên/dưới */
}

@layer base, components;
@layer base { button { font: inherit; } }
@layer components { .button { font-weight: 700; } }

Với các quy tắc normal cùng nguồn gốc, layer khai báo sau có ưu tiên cao hơn layer trước, dù specificity thấp hơn. Với khai báo !important, thứ tự ưu tiên giữa các layer đảo ngược. Tính tương thích và mức hỗ trợ có thể thay đổi; dùng MDN CSS để tra cứu từng tính năng.

16

Viết CSS sạch, dễ bảo trì

  • Đặt tên class có nghĩa: .product-card, .site-nav, .button--primary tốt hơn .abc2.
  • Nhất quán khoảng cách: tạo hệ scale, chẳng hạn 4 / 8 / 12 / 16 / 24 / 32px.
  • Ưu tiên bố cục linh hoạt: dùng Flexbox/Grid thay cho định vị tuyệt đối cho toàn bộ layout.
  • Hạn chế !important: giữ specificity vừa phải và quy tắc có tổ chức.
  • Quan tâm truy cập: tương phản màu đủ tốt, focus rõ ràng, không dùng màu làm tín hiệu duy nhất.
  • Kiểm tra nhiều kích thước: sử dụng Device Toolbar và panel Styles/Computed trong DevTools.
  • Giảm hiệu ứng nặng: đừng animate mọi thứ; hỗ trợ prefers-reduced-motion.

Tổ chức file CSS khi dự án lớn

Ví dụ cấu trúc thư mục
styles/
├── tokens.css       /* màu, spacing, font, radius */
├── base.css         /* reset, element defaults */
├── layout.css       /* header, footer, container */
├── components.css   /* button, card, form */
└── utilities.css    /* class hỗ trợ nhỏ */

Bước 3. Tự nâng cấp

Hãy tự chuyển component thành hai hoặc ba gói trong một display: grid, thêm biểu tượng cho mỗi lợi ích, thử màu chủ đạo khác và kiểm tra hiển thị tại màn hình 360px.

Bài tập và bảng ghi nhớ

5 bài tập tăng dần độ khó

  1. Thẻ hồ sơ cá nhân Tạo avatar hình tròn, tiêu đề, mô tả và nút theo dõi. Luyện border-radius, spacing, typography.
  2. Thanh navigation Logo trái, menu phải, xuống màn hình hẹp thì xuống hàng. Luyện display: flex, gap, flex-wrap.
  3. Gallery ảnh Desktop 3 cột, mobile 1 cột. Luyện Grid và media query hoặc auto-fit.
  4. Landing page responsive Hero, phần tính năng, bảng giá và footer. Luyện kết hợp layout, typography, button states.
  5. Hai giao diện sáng/tối Tạo design tokens bằng biến CSS và đổi theme qua data-theme. Luyện custom properties.

Câu hỏi thường gặp

Nên học Flexbox hay Grid trước?

Nên học Flexbox trước vì dễ bắt đầu với bố cục một chiều, rồi học Grid cho bố cục hai chiều. Trong dự án thực tế chúng thường được dùng chung.

CSS có phải ngôn ngữ lập trình không?

CSS thường được gọi là ngôn ngữ định kiểu, không phải ngôn ngữ lập trình đa dụng. Dù vậy, CSS có logic tương đối phức tạp: cascade, selector, biến, phép tính, điều kiện theo môi trường và animation.

Nên dùng px, rem hay em?

Không có một đơn vị đúng cho mọi trường hợp. rem hữu ích cho chữ và spacing theo hệ thống; em cho kích thước tương đối trong component; px hữu ích cho border và chi tiết nhỏ. Quan trọng là dùng nhất quán, theo ngữ cảnh.

Vì sao CSS của tôi không hoạt động?

Kiểm tra đường dẫn CSS, selector có khớp HTML không, dấu ngoặc và dấu chấm phẩy, thuộc tính có hợp lệ không, quy tắc có bị ghi đè không. Mở DevTools (F12) rồi xem tab Elements → Styles/Computed để lần theo nguyên nhân.

Có cần học framework CSS ngay không?

Không cần. Biết CSS cơ bản, Flexbox, Grid và responsive trước sẽ giúp bạn dùng Tailwind CSS, Bootstrap hay bất kỳ công cụ nào một cách chủ động thay vì chỉ ghi nhớ class.
