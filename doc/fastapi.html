FastAPI là gì?

FastAPI là framework Python để xây dựng API HTTP theo chuẩn ASGI. Framework tận dụng type hints của Python để đọc tham số, xác thực dữ liệu, tuần tự hóa kết quả và tạo tài liệu OpenAPI tự động.

⚡Hiệu năng & async

Hỗ trợ async def, phù hợp ứng dụng có nhiều thao tác chờ I/O.

✓Xác thực dữ liệu

Pydantic kiểm tra request/response dựa trên kiểu dữ liệu.

📖API docs sẵn có

Swagger UI tại /docs, ReDoc tại /redoc.

→

Thích hợp cho backend của web/mobile, microservices, dịch vụ AI/ML, API nội bộ và hệ thống tích hợp. FastAPI không tự quyết định cơ sở dữ liệu, ORM hoặc kiến trúc dự án: bạn chủ động chọn các thành phần này.

ⓘ
Giải thích
Điều kiện học: biết Python cơ bản (hàm, class, kiểu dữ liệu), JSON và ý nghĩa của GET/POST. Các ví dụ dùng cú pháp Python hiện đại và Pydantic v2.

HTTP, route & status code

Mỗi endpoint thường được mô tả bằng HTTP method + URL path. Trong FastAPI, decorator định nghĩa cặp này và gắn với một Python function.

MethodMục đíchVí dụMã thành công thường gặp
GETĐọc tài nguyên/products200
POSTTạo tài nguyên/products201
PUTThay thế tài nguyên/products/7200
PATCHCập nhật một phần/products/7200
DELETEXóa tài nguyên/products/7204

Response thường có 3 phần

Ví dụ HTTP responsehttp
HTTP/1.1 200 OK
Content-Type: application/json

{"message": "Xin chào FastAPI!"}

2xx = thành công; 4xx = vấn đề từ request (400, 401, 403, 404, 422); 5xx = lỗi phía server. FastAPI thường trả 422 khi dữ liệu đầu vào không hợp lệ.

💡
Mẹo thực hành
REST không bắt buộc mọi dự án phải dùng đúng một mẫu URL, nhưng đặt tên tài nguyên bằng danh từ số nhiều và dùng method nhất quán giúp API dễ hiểu.

Path, query, header & cookie

FastAPI tự nhận biết nơi lấy dữ liệu: tên tham số trùng {...} nằm ở path; kiểu đơn giản còn lại thường là query; Header và Cookie đọc các phần tương ứng của HTTP request.

main.pypython
from typing import Annotated
from fastapi import FastAPI, Path, Query, Header

app = FastAPI()

@app.get("/users/{user_id}")
def get_user(
    user_id: Annotated[int, Path(ge=1)],
    page: Annotated[int, Query(ge=1, le=100)] = 1,
    q: Annotated[str | None, Query(max_length=50)] = None,
    user_agent: Annotated[str | None, Header()] = None,
):
    return {
        "user_id": user_id,
        "page": page,
        "query": q,
        "user_agent": user_agent,
    }
GET/users/42?page=2&q=an

user_id = 42, page = 2, q = "an". Nếu page=0 hoặc user_id=abc, FastAPI trả lỗi validation. Annotated giúp giữ type hint, gắn metadata và ràng buộc rõ ràng.

⚠
Lưu ý quan trọng
Route tĩnh như /users/me nên khai báo trước route động /users/{user_id}; thứ tự khai báo có thể ảnh hưởng việc khớp route.

Request body & Pydantic v2

Với JSON body, định nghĩa model kế thừa BaseModel. Pydantic hỗ trợ kiểu dữ liệu, giá trị mặc định và điều kiện validation bằng Field.

main.pypython
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()

class ProductCreate(BaseModel):
    name: str = Field(min_length=2, max_length=100)
    price: float = Field(gt=0)
    quantity: int = Field(ge=0, default=0)
    tags: list[str] = Field(default_factory=list)

@app.post("/products", status_code=201)
def create_product(payload: ProductCreate):
    return {"message": "Đã nhận sản phẩm", "data": payload.model_dump()}

Request hợp lệ:

Request JSONjson
{
  "name": "Bàn phím cơ",
  "price": 890000,
  "quantity": 5,
  "tags": ["phu-kien", "cong-nghe"]
}

Nếu price <= 0, tên quá ngắn hoặc quantity < 0, API trả 422 Unprocessable Entity kèm vị trí và nguyên nhân của lỗi.

model_dump()

Xuất model thành dict Python; dùng thay .dict() cũ.

model_validate(data)

Xác thực và tạo model từ dữ liệu; dùng thay parse_obj() cũ.

ⓘ
Giải thích
Trong Pydantic v2, ưu tiên model_dump(), model_validate(), model_copy(). Những tutorial dùng .dict() hoặc .copy() thường là cú pháp đời cũ.

Response model, status & lỗi

response_model định nghĩa hợp đồng dữ liệu trả về: FastAPI xác thực, chuẩn hóa, tạo schema và lọc bớt trường không có trong model đầu ra. Đây là lớp bảo vệ quan trọng tránh vô tình trả dữ liệu nội bộ.

main.pypython
from fastapi import FastAPI, HTTPException, status
from pydantic import BaseModel

app = FastAPI()

class UserInternal(BaseModel):
    id: int
    username: str
    hashed_password: str

class UserPublic(BaseModel):
    id: int
    username: str

@app.get("/users/{user_id}", response_model=UserPublic)
def get_user(user_id: int):
    if user_id != 1:
        raise HTTPException(status_code=404, detail="Không có người dùng")
    return UserInternal(
        id=1, username="linh", hashed_password="not-for-api"
    )

Trả JSON chỉ có id, username; trường hashed_password không xuất hiện. Không dùng response_model như biện pháp duy nhất để bảo vệ dữ liệu nhạy cảm: vẫn cần thiết kế phân quyền, query và xử lý dữ liệu an toàn.

Dự án thực hành: CRUD sản phẩm

Ví dụ dưới đây là một file main.py có thể chạy độc lập, gồm tạo, đọc danh sách, đọc chi tiết, cập nhật một phần và xóa sản phẩm. Có validation, phân biệt input/output, 404, 201 và 204.

main.py — chạy độc lậppython
from typing import Annotated
from fastapi import FastAPI, HTTPException, Query, Response, status
from pydantic import BaseModel, Field

app = FastAPI(title="Product CRUD", version="1.0")

class ProductCreate(BaseModel):
    name: str = Field(min_length=2, max_length=100)
    price: float = Field(gt=0)
    in_stock: bool = True

class ProductPublic(ProductCreate):
    id: int

class ProductPatch(BaseModel):
    name: str | None = Field(default=None, min_length=2, max_length=100)
    price: float | None = Field(default=None, gt=0)
    in_stock: bool | None = None

products: dict[int, ProductPublic] = {}
next_id = 1

@app.get("/health")
def health():
    return {"status": "ok"}

@app.post("/products", response_model=ProductPublic,
          status_code=status.HTTP_201_CREATED)
def create_product(payload: ProductCreate):
    global next_id
    product = ProductPublic(id=next_id, **payload.model_dump())
    products[next_id] = product
    next_id += 1
    return product

@app.get("/products", response_model=list[ProductPublic])
def list_products(
    q: str | None = None,
    limit: Annotated[int, Query(ge=1, le=100)] = 20,
):
    result = list(products.values())
    if q:
        result = [p for p in result if q.lower() in p.name.lower()]
    return result[:limit]

@app.get("/products/{product_id}", response_model=ProductPublic)
def read_product(product_id: int):
    product = products.get(product_id)
    if product is None:
        raise HTTPException(status_code=404, detail="Không tìm thấy sản phẩm")
    return product

@app.patch("/products/{product_id}", response_model=ProductPublic)
def update_product(product_id: int, payload: ProductPatch):
    product = products.get(product_id)
    if product is None:
        raise HTTPException(status_code=404, detail="Không tìm thấy sản phẩm")
    changes = payload.model_dump(exclude_unset=True, exclude_none=True)
    if not changes:
        raise HTTPException(status_code=400, detail="Không có trường để sửa")
    updated = product.model_copy(update=changes)
    products[product_id] = updated
    return updated

@app.delete("/products/{product_id}", status_code=204)
def delete_product(product_id: int):
    if product_id not in products:
        raise HTTPException(status_code=404, detail="Không tìm thấy sản phẩm")
    del products[product_id]
    return Response(status_code=204)

Điểm cần hiểu thật rõ

  1. ProductCreate định nghĩa dữ liệu tạo; ProductPublic định nghĩa response có id; ProductPatch cho phép gửi thiếu trường.
  2. exclude_unset=True chỉ lấy trường đã gửi; exclude_none=True làm ví dụ này bỏ qua giá trị null, nên không hỗ trợ xóa một trường bằng null.
  3. model_copy(update=...) tạo bản sao cập nhật; dữ liệu đã được model request xác thực trước. Với dữ liệu/logic phức tạp, cần xác thực lại invariant sau khi gộp.
  4. products chỉ là dict trong RAM: restart sẽ mất dữ liệu; nhiều worker sẽ có bộ nhớ tách biệt. Phần SQL bên dưới khắc phục vấn đề lưu trữ.

Dependency Injection với Depends

Dependency là hàm hoặc callable cung cấp một giá trị cho endpoint. Depends giúp gom logic kiểm tra, kết nối DB, lấy user hiện tại, phân trang… thành khối tái sử dụng, dễ thay thế khi kiểm thử.

main.pypython
from typing import Annotated
from fastapi import Depends, FastAPI, Query

app = FastAPI()

def pagination(
    skip: Annotated[int, Query(ge=0)] = 0,
    limit: Annotated[int, Query(ge=1, le=100)] = 20,
) -> dict[str, int]:
    return {"skip": skip, "limit": limit}

@app.get("/articles")
def list_articles(page: Annotated[dict, Depends(pagination)]):
    return {"pagination": page, "items": []}

Khi gọi /articles?skip=10&limit=5, FastAPI gọi pagination(), kiểm tra tham số rồi truyền kết quả vào page. Dependency có thể lồng nhau và dùng yield để quản lý tài nguyên.

💡
Mẹo thực hành
Đặt các thành phần hay sử dụng như get_session(), get_current_user(), get_settings() trong module riêng để dễ kiểm thử và tránh lặp code.

Database với SQLite & SQLModel

FastAPI không tích hợp ORM bắt buộc. Ví dụ này chọn SQLModel (dựa trên SQLAlchemy/Pydantic) và SQLite để học thao tác DB có persistence. Đây là ứng dụng độc lập với phần CRUD trong RAM.

Terminalbash
python -m pip install sqlmodel
main.py — SQLite + SQLModelpython
from contextlib import asynccontextmanager
from typing import Annotated
from fastapi import Depends, FastAPI, HTTPException
from sqlmodel import Field, Session, SQLModel, create_engine, select

class NoteBase(SQLModel):
    title: str
    content: str | None = None

class Note(NoteBase, table=True):
    id: int | None = Field(default=None, primary_key=True)

class NoteCreate(NoteBase):
    pass

class NotePublic(NoteBase):
    id: int

engine = create_engine(
    "sqlite:///./notes.db",
    connect_args={"check_same_thread": False},
)

def get_session():
    with Session(engine) as session:
        yield session

@asynccontextmanager
async def lifespan(app: FastAPI):
    SQLModel.metadata.create_all(engine)
    yield

app = FastAPI(lifespan=lifespan)
SessionDep = Annotated[Session, Depends(get_session)]

@app.post("/notes", response_model=NotePublic, status_code=201)
def create_note(payload: NoteCreate, session: SessionDep):
    note = Note.model_validate(payload)
    session.add(note)
    session.commit()
    session.refresh(note)
    return note

@app.get("/notes", response_model=list[NotePublic])
def read_notes(session: SessionDep):
    return session.exec(select(Note)).all()

@app.get("/notes/{note_id}", response_model=NotePublic)
def read_note(note_id: int, session: SessionDep):
    note = session.get(Note, note_id)
    if note is None:
        raise HTTPException(status_code=404, detail="Note không tồn tại")
    return note

Điều gì đang diễn ra?

  1. Note(..., table=True) khai báo bảng; NoteCreate/NotePublic là schema vào/ra.
  2. engine quản lý kết nối; Session đại diện phiên làm việc với DB.
  3. get_session() dùng yield để đóng session khi kết thúc phạm vi dependency.
  4. lifespan chạy trước khi phục vụ request; ở demo, nó tạo các bảng chưa tồn tại.
  5. session.commit() lưu thay đổi; session.refresh() tải lại giá trị được DB sinh ra như ID.
⚠
Lưu ý quan trọng
Trong production: dùng PostgreSQL khi phù hợp, migration bằng Alembic, quản lý transaction, connection pool, index và sao lưu. create_all() chỉ tiện cho demo, không thay migration. Vì ví dụ dùng SQLModel/Session đồng bộ, endpoint dùng def thay vì ép vào async def.

async def hay def?

async phát huy hiệu quả khi thao tác I/O dùng thư viện hỗ trợ bất đồng bộ, chẳng hạn HTTP client, database driver async. async không tự động làm CPU-bound code nhanh hơn.

Dùng async def khi…

Bạn gọi await đến thư viện async: httpx.AsyncClient, async DB driver, WebSocket, v.v.

Dùng def khi…

SDK/ORM đồng bộ, xử lý blocking thông thường. FastAPI chạy path operation đồng bộ trong thread pool.

main.pypython
import httpx
from fastapi import FastAPI

app = FastAPI()

@app.get("/upstream")
async def get_upstream():
    async with httpx.AsyncClient(timeout=5.0) as client:
        response = await client.get("https://httpbin.org/json")
        response.raise_for_status()
        return response.json()

Ví dụ gọi server bên ngoài, nên cần kết nối internet. Với hệ thống thực tế, hãy xử lý timeout, exception, retry có giới hạn và không tự động retry những thao tác không idempotent.

⚠
Lưu ý quan trọng

Authentication & Authorization

Authentication trả lời “ai đang gọi API?”, còn authorization trả lời “người đó được phép làm gì?”. FastAPI có cơ chế security dependency để kết nối OAuth2, Bearer token, API key và tích hợp OpenAPI.

Ví dụ tối thiểu: API key từ biến môi trường

main.py — API key minh họapython
import os
import secrets
from typing import Annotated
from fastapi import Depends, FastAPI, HTTPException
from fastapi.security import APIKeyHeader

app = FastAPI()
key_header = APIKeyHeader(name="X-API-Key", auto_error=False)

def require_api_key(key: Annotated[str | None, Depends(key_header)]):
    expected = os.environ.get("API_KEY")
    if not expected or not key or not secrets.compare_digest(key, expected):
        raise HTTPException(status_code=401, detail="Invalid API key")
    return key

@app.get("/private", dependencies=[Depends(require_api_key)])
def private_data():
    return {"message": "Access granted"}

# macOS / Linux:
export API_KEY="replace-with-a-long-random-secret"

  http://127.0.0.1:8000/private

Nếu ứng dụng có tài khoản người dùng

  1. Lưu password dưới dạng hash phù hợp (ví dụ Argon2), không lưu password thô.
  2. Với JWT, kiểm tra chữ ký, algorithm cố định, hạn dùng (exp), issuer/audience nếu có; không chỉ decode payload.
  3. Thực thi phân quyền tại server cho từng hành động/tài nguyên; token hợp lệ không đồng nghĩa được quyền truy cập mọi dữ liệu.
  4. Secrets lưu ở environment/secret manager; bật HTTPS, rate limiting, log truy cập và chính sách hết hạn/thu hồi token.
⚠
Lưu ý quan trọng
Đoạn API key phù hợp để minh họa hoặc bảo vệ service nội bộ trong môi trường kiểm soát; không phải một hệ thống đăng nhập đầy đủ. Xem hướng dẫn OAuth2/JWT chính thức để triển khai đăng nhập người dùng an toàn.

CORS, Middleware & cấu hình

Nếu frontend chạy ở http://localhost:5173 và backend ở http://localhost:8000, trình duyệt coi đây là hai origin khác nhau. CORS điều khiển origin nào được trình duyệt cho phép đọc response.

main.pypython
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],
    allow_credentials=True,
    allow_methods=["GET", "POST", "PATCH", "DELETE"],
    allow_headers=["Content-Type", "Authorization"],
)

@app.get("/health")
def health():
    return {"status": "ok"}

Middleware chạy quanh vòng đời xử lý request/response, thường dùng cho timing, request ID, logging hoặc các chính sách chung. CORS là chính sách của trình duyệt, không thay thế xác thực/phân quyền phía server; curl và máy chủ khác không chịu ràng buộc CORS như trình duyệt.

⚠
Lưu ý quan trọng
Khi gửi cookie hoặc credentials, khai báo origin, method và header rõ ràng; không cấu hình wildcard * cho các phần này. Cho phép mọi origin chỉ để thử nhanh trong bối cảnh không cần credentials.

Upload file & BackgroundTasks

Nhận một file bằng multipart/form-data

main.py — uploadpython
from typing import Annotated
from fastapi import FastAPI, File, HTTPException, UploadFile

app = FastAPI()

@app.post("/upload")
async def upload_file(file: Annotated[UploadFile, File()]):
    max_bytes = 2 * 1024 * 1024
    content = await file.read(max_bytes + 1)
    if len(content) > max_bytes:
        raise HTTPException(status_code=413, detail="File quá lớn")
    return {"filename": file.filename, "size": len(content)}

UploadFile hỗ trợ thao tác file, thường thích hợp hơn đọc tất cả vào bytes cho file lớn. Ví dụ trên chủ động giới hạn 2 MiB nhưng vẫn chỉ là demo; production cần kiểm tra nội dung thực tế, loại file, vị trí lưu, quota và quét mã độc tùy hệ thống.

Chạy công việc nhỏ sau khi trả response

main.py — background taskpython
from fastapi import BackgroundTasks, FastAPI

app = FastAPI()

def append_log(message: str):
    with open("events.log", "a", encoding="utf-8") as f:
        f.write(message + "\n")

@app.post("/events", status_code=202)
def create_event(background_tasks: BackgroundTasks):
    background_tasks.add_task(append_log, "created event")
    return {"queued": True}

BackgroundTasks tiện cho tác vụ nhỏ cùng process. Không bảo đảm lưu trữ bền vững khi process crash hoặc deploy lại. Với tác vụ nặng, retry, hàng đợi hoặc chạy nhiều máy, dùng worker/queue độc lập như Celery, RQ hay kiến trúc tương đương.

Viết test bằng pytest & TestClient

Test tự động giúp ngăn bug khi sửa route, schema và business logic. TestClient cho phép gọi API ngay trong process mà không cần khởi động server HTTP riêng.

Terminalbash
python -m pip install pytest httpx

Với file CRUD sản phẩm ở bài 07, tạo test_main.py:

test_main.pypython
from fastapi.testclient import TestClient
from main import app

client = TestClient(app)

def test_create_and_read_product():
    response = client.post(
        "/products",
        json={"name": "Chuột không dây", "price": 250000},
    )
    assert response.status_code == 201
    product_id = response.json()["id"]

    result = client.get(f"/products/{product_id}")
    assert result.status_code == 200
    assert result.json()["name"] == "Chuột không dây"

def test_product_validation():
    response = client.post(
        "/products", json={"name": "X", "price": -1}
    )
    assert response.status_code == 422

def test_missing_product():
    response = client.get("/products/999999")
    assert response.status_code == 404
