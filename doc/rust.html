Rust là gì? Tư duy học đúng ngay từ đầu

Rust là ngôn ngữ lập trình biên dịch, kiểu tĩnh, hướng đến hiệu năng, an toàn bộ nhớ và độ tin cậy. Rust thường phù hợp cho công cụ dòng lệnh, backend, hệ thống nhúng, WebAssembly và những thành phần cần kiểm soát tài nguyên.

Điểm khác biệt quan trọng nhất: Rust kiểm tra quyền sở hữu và việc mượn dữ liệu tại thời điểm biên dịch. Bạn có thể viết chương trình nhanh mà trong phần lớn mã Rust an toàn (safe Rust) không cần garbage collector và không phải tự free bộ nhớ.

Khái niệm Hiểu nhanh Tại sao quan trọng?
ownership Mỗi giá trị có chủ sở hữu theo quy tắc của Rust Quản lý vòng đời tài nguyên
borrowing Cho mượn qua &T hoặc &mut T Tránh sao chép không cần thiết
Option<T> Có giá trị hoặc không Tránh lạm dụng null
Result<T, E> Thành công hoặc lỗi Lỗi phải được xử lý tường minh
trait Mô tả hành vi mà kiểu có thể cung cấp Tái sử dụng và trừu tượng hóa
Cargo Công cụ build và quản lý thư viện Chuẩn hóa quy trình dự án

Lộ trình gợi ý: Đọc tuần tự từ phần 1 đến 16, sau đó chọn mảng ứng dụng. Hãy gõ và chạy ví dụ thay vì chỉ đọc. Ví dụ mặc định dùng Rust Edition 2024.

Khi nào nên chọn Rust?

  • Nên cân nhắc: CLI, dịch vụ chạy lâu dài, xử lý dữ liệu, thư viện hiệu năng cao, mã gần hệ điều hành, embedded.
  • Cần cân nhắc chi phí học: ownership, lifetimes và thời gian biên dịch có thể khiến người mới mất thời gian ban đầu.
  • Không phải lời giải cho mọi thứ: một bản mẫu web nhỏ có thể triển khai nhanh hơn bằng ngôn ngữ khác quen thuộc với nhóm.

Cài đặt Rust và thiết lập môi trường

Cách được Rust khuyên dùng là rustup, công cụ cài đặt và quản lý các toolchain. Sau khi cài, bạn sẽ có rustc (trình biên dịch), cargo (build, dependency, test) và rustup.

Linux / macOS / WSL

BASH
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Làm theo hướng dẫn trên màn hình, mở lại terminal (hoặc nạp lại cấu hình shell), rồi kiểm tra:

BASH
rustc --version
cargo --version
rustup --version
rustup update stable

Windows

Tải trình cài rustup-init.exe từ trang Install Rust, chạy theo hướng dẫn. Tùy máy, bộ công cụ biên dịch C++ của Visual Studio có thể được yêu cầu. Với WSL, dùng lệnh Linux ở trên.

Bộ công cụ nên biết

Lệnh Công dụng
cargo new ten_du_an Tạo dự án nhị phân mới
cargo run Biên dịch và chạy

IDE: VS Code + extension rust-analyzer là một lựa chọn phổ biến; các IDE hỗ trợ rust-analyzer cũng hoạt động tốt. Bạn có thể thử ví dụ ngay trên Rust Playground.

Dự án đầu tiên với Cargo

Tạo ứng dụng mới và chạy:

BASH
cargo new hello_rust

cargo run

Cấu trúc thông thường:

TEXT
hello_rust/

└── src/
    └── main.rs     # điểm bắt đầu của binary

Cargo.toml tối thiểu:

TOML
[package]
name = "hello_rust"
version = "0.1.0"

[dependencies]

Nội dung src/main.rs:

RUST
fn main() {
    let name = "Rust";
    println!("Xin chào, {name}!");
}

fn main() là điểm khởi chạy; let khai báo biến; dấu ! sau println! cho biết đây là macro; ; kết thúc câu lệnh. Sửa name, chạy lại cargo run để thấy kết quả.

Phân biệt: rustc main.rs biên dịch tệp riêng lẻ; cargo thích hợp hơn cho hầu hết dự án vì quản lý cấu trúc, thư viện và tác vụ.

Biến, hằng số và kiểu dữ liệu

Mặc định một binding là không thể gán lại. Muốn thay đổi, dùng mut. Rust thường suy luận kiểu, nhưng bạn có thể viết tường minh.

RUST
fn main() {
    let age: u32 = 24;
    let mut score = 10;
    score += 5;

    const MAX_USERS: usize = 100;
    println!("age={age}, score={score}, max={MAX_USERS}");
}

Các kiểu nền tảng

Nhóm Ví dụ Ghi nhớ
Số nguyên có dấu i8, i32, i64, isize i32 là lựa chọn phổ biến
Số nguyên không dấu u8, u32, usize usize dùng cho chỉ số/kích thước
Số thực f32, f64 Mặc định thường là f64
Boolean bool true hoặc false
Ký tự char Một Unicode scalar value, dùng dấu nháy đơn
Tuple (i32, bool) Gom các giá trị khác kiểu
Array [i32; 3] Kích thước cố định
Slice &[i32] Mượn một đoạn dữ liệu
String String / &str Chuỗi sở hữu / chuỗi được mượn
RUST
fn main() {
    let pi = 3.14_f64;
    let letter = 'Đ';
    let active = true;
    let person = ("Lan", 21);
    let numbers: [i32; 3] = [10, 20, 30];

    println!("{pi} {letter} {active}");
    println!("{}: {} tuổi", person.0, person.1);
    println!("{}", numbers[1]);
}

Shadowing và chuyển kiểu

RUST
fn main() {
    let value = "42";
    let value: i32 = value.parse().expect("Phải là số");
    let doubled = value * 2;

    let n: u8 = 200;
    let larger = n as u16;
    println!("{doubled} - {larger}");
}

Shadowing (let value một lần nữa) tạo binding mới và có thể đổi kiểu; khác với mut, nơi bạn gán lại cùng một binding. Ép kiểu bằng as có thể cắt/tràn dữ liệu; khi chuyển đổi cần kiểm tra, ưu tiên TryFrom/try_into.

05 / 31

Điều khiển luồng: if, loop, while, for

if yêu cầu điều kiện có kiểu bool, không tự xem số khác 0 là đúng. Vì if là một biểu thức, các nhánh có thể trả về một giá trị cùng kiểu.

RUST
fn main() {
    let score = 78;
    let result = if score >= 50 { "Đạt" } else { "Chưa đạt" };
    println!("{result}");

    for i in 1..=3 {
        println!("Lượt {i}");
    }
}
RUST
fn main() {
    let mut remaining = 3;
    while remaining > 0 {
        println!("{remaining}");
        remaining -= 1;
    }

    let mut count = 0;
    let answer = loop {
        count += 1;
        if count == 5 {
            break count * 2;
        }
    };
    println!("Đáp án: {answer}");
}

1..5 bao gồm 1 đến 4; 1..=5 bao gồm cả 5. break <giá trị> làm loop trả về giá trị; continue nhảy sang lần lặp tiếp theo.

06 / 31

Hàm, biểu thức và phạm vi

Rust phân biệt statement (câu lệnh, thường kết thúc ;) và expression (biểu thức có giá trị). Biểu thức cuối của một khối có thể dùng làm giá trị trả về mà không cần return.

RUST
fn square(n: i32) -> i32 {
    n * n // không có dấu ;
}

fn describe(n: i32) -> &'static str {
    if n % 2 == 0 { "chẵn" } else { "lẻ" }
}

fn main() {
    let result = square(6);
    println!("{result} là số {}", describe(result));
}
RUST
fn main() {
    let outer = 10;
    let answer = {
        let inner = 5;
        outer + inner
    };
    println!("{answer}");
    // inner không tồn tại ở đây
}

Quy tắc nhớ nhanh: Để trả về T từ hàm, dùng biểu thức cuối kiểu T (không có ;) hoặc return T;. Dấu ; ở cuối biểu thức biến nó thành câu lệnh có giá trị ().

Ownership: trái tim của Rust

Trong Rust, nhiều loại dữ liệu như String và Vec<T> quản lý vùng nhớ cấp phát động. Ownership cho phép trình biên dịch xác định thời điểm giải phóng tài nguyên mà không cần GC.

Ba quy tắc cốt lõi: mỗi giá trị có một owner; tại một thời điểm một giá trị có một owner; khi owner rời scope, giá trị được giải phóng (theo cơ chế Drop).

Move, Copy và Clone

RUST
fn main() {
    let first = String::from("xin chào");
    let second = first; // ownership được chuyển (move)
    // println!("{first}"); // LỖI: first đã được move
    println!("{second}");

    let x = 7;
    let y = x; // i32 thực hiện Copy
    println!("{x} {y}");
}

String không tự sao chép vùng nhớ heap khi gán: first không còn được phép dùng sau khi move. Với kiểu triển khai Copy như số nguyên, phép gán tạo bản sao giá trị. Nếu muốn bản sao dữ liệu độc lập của String, gọi clone().

RUST
fn main() {
    let a = String::from("abc");
    let b = a.clone();
    println!("{a} và {b}");
}

Move qua hàm

RUST
fn consume(text: String) {
    println!("Đã nhận: {text}");
}

fn main() {
    let message = String::from("Hello");
    consume(message);
    // message không thể dùng nữa
}

Nếu hàm chỉ cần đọc, hãy truyền tham chiếu &str hoặc &T thay vì lấy ownership. Đây là một trong những thói quen quan trọng nhất khi thiết kế API Rust.

08 / 31

Borrowing và tham chiếu

Borrowing cho phép truy cập dữ liệu mà không nhận ownership. Có hai dạng thường dùng: &T để đọc và &mut T để thay đổi.

RUST
fn length(text: &str) -> usize {
    text.len()
}

fn append_exclamation(text: &mut String) {
    text.push('!');
}

fn main() {
    let mut greeting = String::from("Xin chào");
    println!("Độ dài byte: {}", length(&greeting));
    append_exclamation(&mut greeting);
    println!("{greeting}");
}

Quy tắc mượn

  • Có thể có nhiều tham chiếu bất biến &T cùng lúc.
  • Khi một tham chiếu &mut T đang được sử dụng, không thể đồng thời dùng tham chiếu khác đến cùng dữ liệu theo cách xung đột.
  • Mọi tham chiếu phải hợp lệ trong khoảng thời gian nó được sử dụng; Rust ngăn dangling reference.
RUST
fn main() {
    let mut value = 5;
    let read = &value;
    println!("Đọc: {read}"); // lần sử dụng cuối của read

    let write = &mut value;    // hợp lệ sau đó
    *write += 1;
    println!("Giá trị mới: {value}");
}

Trình biên dịch dùng non-lexical lifetimes (NLL) để xem thời điểm tham chiếu được dùng lần cuối, nên read không nhất thiết phải tồn tại cho tới hết khối lệnh.

Lỗi phổ biến: cố thay đổi Vec trong lúc đang giữ một tham chiếu đến phần tử của chính Vec. Việc thêm phần tử có thể khiến bộ nhớ được cấp phát lại; Rust chặn tình huống có khả năng tạo tham chiếu không hợp lệ.

09 / 31

Slice, String và Unicode

String là chuỗi UTF-8 có ownership, có thể tăng kích thước. &str là một view mượn đến dữ liệu UTF-8; literal như "hello" có kiểu &'static str.

RUST
fn first_word(s: &str) -> &str {
    s.split_whitespace().next().unwrap_or("")
}

fn main() {
    let s = String::from("Rust rất thú vị");
    println!("{}", first_word(&s));
    println!("{}", first_word("Hello world"));
}

Vì sao không dùng s[0] với String?

Một ký tự hiển thị có thể chiếm nhiều byte UTF-8. Do đó index theo số nguyên không có ý nghĩa đơn giản và Rust không cho truy cập chuỗi như s[0].

RUST
fn main() {
    let s = "Việt";
    println!("{} byte", s.len());
    println!("{} ký tự Unicode scalar", s.chars().count());

    for ch in s.chars() {
        print!("[{ch}]");
    }
    println!();
}

chars() duyệt Unicode scalar values, không nhất thiết tương ứng 1 grapheme (ký tự hiển thị). Nếu xử lý grapheme phức tạp, cân nhắc crate unicode-segmentation.

Struct và phương thức

Struct gom các trường có tên để mô tả dữ liệu. impl thêm phương thức; &self là cách mượn bất biến chính đối tượng, &mut self để thay đổi nó.

RUST
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn new(width: u32, height: u32) -> Self {
        Self { width, height }
    }

    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn scale(&mut self, factor: u32) {
        self.width *= factor;
        self.height *= factor;
    }
}

fn main() {
    let mut rect = Rectangle::new(5, 4);
    println!("{:?}; diện tích={}", rect, rect.area());
    rect.scale(2);
    println!("Diện tích mới={}", rect.area());
}

#[derive(Debug)] yêu cầu compiler sinh triển khai trait Debug; cú pháp {:?} dùng để in khi debug. Ngoài struct có tên, Rust còn có tuple struct và unit-like struct.

11 / 31

Enum, Option và Result

enum cho phép một giá trị thuộc một trong nhiều biến thể, mỗi biến thể có thể chứa dữ liệu. Hai enum xuất hiện liên tục trong Rust là Option<T> và Result<T, E>.

RUST
enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
}

fn show(msg: Message) {
    match msg {
        Message::Quit => println!("Thoát"),
        Message::Move { x, y } => println!("Di chuyển đến {x}, {y}"),
        Message::Write(text) => println!("Tin nhắn: {text}"),
    }
}

fn main() {
    show(Message::Write(String::from("Chào!")));
    show(Message::Move { x: 3, y: 4 });
}

Option: có hoặc không có

RUST
fn safe_divide(a: f64, b: f64) -> Option<f64> {
    if b == 0.0 { None } else { Some(a / b) }
}

fn main() {
    match safe_divide(10.0, 2.0) {
        Some(value) => println!("Kết quả: {value}"),
        None => println!("Không thể chia cho 0"),
    }
}

Result: thành công hoặc lỗi

RUST
fn parse_positive(text: &str) -> Result<u32, String> {
    let number: u32 = text.parse().map_err(|e| format!("{e}"))?;
    if number == 0 {
        Err(String::from("Phải lớn hơn 0"))
    } else {
        Ok(number)
    }
}

fn main() {
    println!("{:?}", parse_positive("12"));
    println!("{:?}", parse_positive("abc"));
}

Dùng Option khi sự vắng mặt là bình thường; dùng Result khi cần mang thông tin lỗi. unwrap() có thể làm chương trình panic, nên chỉ dùng khi thật sự chắc chắn hoặc trong thử nghiệm ngắn.

12 / 31

Pattern matching với match, if let và let else

match kiểm tra các pattern và phải bao phủ tất cả khả năng. Bạn có thể tách dữ liệu ra khỏi enum, tuple và struct.

RUST
fn main() {
    let point = (3, -2);
    match point {
        (0, 0) => println!("Gốc tọa độ"),
        (x, 0) => println!("Trên trục X tại {x}"),
        (x, y) if x > 0 && y < 0 => println!("Góc phần tư IV"),
        _ => println!("Vị trí khác"),
    }

    let maybe_name = Some("Hà");
    if let Some(name) = maybe_name {
        println!("Xin chào {name}");
    }
}

let ... else rất hữu ích để xử lý sớm trường hợp dữ liệu không phù hợp. Nhánh else phải chuyển luồng điều khiển ra ngoài (return, break, panic!, ...).

RUST
fn greeting(name: Option<&str>) -> String {
    let Some(name) = name else {

Generics và Traits: xây dựng API tái sử dụng

Generics cho phép một thuật toán hoạt động với nhiều kiểu mà vẫn được compiler kiểm tra. Traits mô tả các hành vi chung, tương tự interface ở một số ngôn ngữ khác nhưng có đặc điểm riêng.

RUST
fn largest<T: PartialOrd + Copy>(items: &[T]) -> Option<T> {
    let mut it = items.iter().copied();
    let mut best = it.next()?;
    for value in it {
        if value > best { best = value; }
    }
    Some(best)
}

fn main() {
    println!("{:?}", largest(&[3, 9, 2]));
    println!("{:?}", largest::<i32>(&[]));
}

Ở đây T: PartialOrd + Copy là trait bound: T phải so sánh được và có thể copy. Khi cần trả reference để tránh Copy, thiết kế hàm có thể khác.

Tự tạo trait và impl

RUST
trait Summary {
    fn summarize(&self) -> String;
}

struct Article {
    title: String,
    views: u32,
}

impl Summary for Article {
    fn summarize(&self) -> String {
        format!("{} — {} lượt xem", self.title, self.views)
    }
}

fn print_summary(item: &impl Summary) {
    println!("{}", item.summarize());
}

fn main() {
    let article = Article {
        title: String::from("Học Rust"),
        views: 120,
    };
    print_summary(&article);
}

Cú pháp Ý nghĩa điển hình

fn f<T: Trait>(x: &T) Generic rõ ràng, có thể liên hệ nhiều tham số cùng T

Lifetimes: quan hệ giữa các tham chiếu

Lifetime là cách compiler theo dõi thời gian tham chiếu có hiệu lực. Trong nhiều trường hợp, Rust tự suy luận nên bạn không phải viết annotation.

Trường hợp cần diễn tả quan hệ giữa hai tham chiếu đầu vào và một tham chiếu đầu ra:

RUST
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() >= y.len() { x } else { y }
}

fn main() {
    let a = String::from("xin chào");
    let b = String::from("Rust");
    let result = longest(&a, &b);
    println!("{result}");
}

'a không kéo dài vòng đời của biến; nó mô tả quan hệ yêu cầu giữa các tham chiếu. Giá trị trả về chỉ có thể sử dụng khi cả ràng buộc lifetime được thỏa mãn (hiểu đơn giản: không vượt quá vùng hợp lệ chung của các borrow liên quan).

Closures, Iterators và phong cách biểu thức

RUST

    let numbers = vec![1, 6, 3, 8, 10];

        .map(|&n| n * 2)

Smart pointers: Box, Rc, RefCell, Arc, Mutex

Smart pointer là các kiểu bao bọc dữ liệu và cung cấp hành vi quản lý bộ nhớ/tài nguyên bổ sung.

Kiểu Công dụng Cảnh báo
Box<T> Sở hữu dữ liệu cấp phát trên heap Không chia sẻ ownership
Rc<T> Nhiều owner trong một thread Không an toàn để chia sẻ giữa thread

Tại sao thường thấy Arc<Mutex<T>>?

Arc chia sẻ ownership giữa thread, còn Mutex tuần tự hóa quyền truy cập để thay đổi cùng dữ liệu.

RUST
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let counter = Arc::new(Mutex::new(0));
    let mut handles = Vec::new();

    for _ in 0..4 {
        let counter = Arc::clone(&counter);
        handles.push(thread::spawn(move || {
            let mut value = counter.lock().unwrap();
            *value += 1;
        }));
    }

    for handle in handles {
        handle.join().unwrap();
    }
    println!("{}", *counter.lock().unwrap());
}

Concurrency và async/await

Rust có nhiều công cụ xử lý tác vụ đồng thời. Thread hệ điều hành phù hợp với một số bài toán song song; async/await thường phù hợp với nhiều tác vụ I/O chờ đợi. Async tự nó không đồng nghĩa đa luồng và Rust không tích hợp sẵn executor đa năng trong thư viện chuẩn.

Thread và channel trong std

RUST
use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();

    thread::spawn(move || {
        for n in 1..=3 {
            tx.send(n * n).unwrap();
        }
    });

    for received in rx {
        println!("Nhận: {received}");
    }
}

move chuyển các giá trị được capture vào closure khi cần (ở đây là tx) để thread có thể sở hữu tài nguyên đó.

unsafe không có nghĩa “tắt hết kiểm tra”

unsafe cho phép một số thao tác cần kiểm chứng thủ công (ví dụ giải tham chiếu raw pointer, gọi hàm unsafe). Compiler vẫn áp dụng nhiều quy tắc kiểu và borrow cho phần còn lại. Nếu chưa cần FFI hoặc code hệ thống, có thể học sau.

RUST
fn main() {

    unsafe {
        println!("{}", *ptr);
    }
}

Mini project: Todo CLI lưu dữ liệu vào file

Bạn sẽ tự viết một chương trình dòng lệnh có ba chức năng: add, list, done. Dữ liệu được lưu trong todos.txt, không cần crate bên ngoài. Mục tiêu là tổng hợp enum kết quả, ownership, borrowing, Vec, vòng lặp, thao tác file và xử lý lỗi.

Bước 1 — Tạo dự án

Bước 2 — Thay toàn bộ src/main.rs

RUST
use std::env;
use std::error::Error;
use std::fs;
use std::path::Path;

type AppResult<T> = Result<T, Box<dyn Error>>;
const FILE: &str = "todos.txt";

#[derive(Debug)]
struct Todo {
    done: bool,
    title: String,
}

fn load() -> AppResult<Vec<Todo>> {
    if !Path::new(FILE).exists() {
        return Ok(Vec::new());
    }

    let content = fs::read_to_string(FILE)?;
    let mut todos = Vec::new();

    for line in content.lines() {
        if let Some((flag, title)) = line.split_once('|') {
            todos.push(Todo {
                done: flag == "1",
                title: title.to_owned(),
            });
        }
    }
    Ok(todos)
}

fn save(todos: &[Todo]) -> AppResult<()> {
    let text = todos
        .iter()
        .map(|todo| {
            let flag = if todo.done { "1" } else { "0" };
            format!("{flag}|{}", todo.title)
        })
        .collect::<Vec<_>>()
        .join("\n");
    fs::write(FILE, text)?;
    Ok(())
}

fn run() -> AppResult<()> {
    let args: Vec<String> = env::args().skip(1).collect();
    let mut todos = load()?;

    match args.first().map(String::as_str) {
        Some("add") => {
            let title = args[1..].join(" ");
            if title.trim().is_empty() {
                return Err("Hãy nhập nội dung công việc".into());
            }
            if title.contains('\n') || title.contains('\r') {
                return Err("Nội dung không được xuống dòng".into());
            }
            todos.push(Todo { done: false, title });
            save(&todos)?;
            println!("Đã thêm công việc.");
        }
        Some("list") => {
            if todos.is_empty() {
                println!("Chưa có công việc nào.");
            }
            for (i, todo) in todos.iter().enumerate() {
                let mark = if todo.done { "x" } else { " " };
                println!("{}. [{mark}] {}", i + 1, todo.title);
            }
        }
        Some("done") => {
            let index: usize = args
                .get(1)
                .ok_or("Thiếu số thứ tự")?
                .parse()?;
            if index == 0 || index > todos.len() {
                return Err("Số thứ tự không hợp lệ".into());
            }
            todos[index - 1].done = true;
            save(&todos)?;
            println!("Đã đánh dấu hoàn thành.");
        }
        _ => {
            println!("Cách dùng:");
            println!("  cargo run -- add Học ownership");
            println!("  cargo run -- list");
            println!("  cargo run -- done 1");
        }
    }
    Ok(())
}

fn main() {
    if let Err(error) = run() {
        eprintln!("Lỗi: {error}");
        std::process::exit(1);
    }
}

Bước 4 — Hiểu các quyết định thiết kế

  • type AppResult<T> rút gọn kiểu kết quả của các hàm có thể lỗi.
  • load() trả Vec<Todo> có ownership, còn save(&[Todo]) chỉ mượn danh sách; slice khiến hàm dùng được với nhiều nguồn dữ liệu.
  • split_once('|') tách phần trạng thái và tiêu đề; vì tách ở ký tự | đầu tiên, tiêu đề vẫn có thể chứa |.
  • args.first() tránh crash khi không truyền lệnh; args[1..] hợp lệ trong nhánh Some("add") vì chắc chắn có phần tử đầu.
  • ? giúp chuyển lỗi đọc file, ghi file và parse số cho main xử lý.

Giới hạn có chủ ý: đây là định dạng lưu file phục vụ học tập, không phải cơ sở dữ liệu. Một ứng dụng thực tế nên xử lý đồng thời ghi, ghi nguyên tử, lỗi file hỏng, mã hóa dữ liệu và có test.

Thử thách mở rộng

Bổ sung delete <n>, clear, bộ lọc list done, ghi JSON với serde_json, và unit test cho load / save bằng thư mục tạm. Đó là cách biến mini project thành portfolio có giá trị.

Debugging, linting và quy trình làm việc

Vòng lặp phát triển hiệu quả: viết mã nhỏ → cargo check → sửa lỗi kiểu và borrow → cargo fmt → cargo clippy → cargo test → chạy thử.

Cách đọc compiler error

  1. Đọc loại lỗi và dòng đầu tiên chỉ nơi phát sinh.
  2. Quan sát nhãn “value moved here”, “borrow occurs here”, “borrow later used here”.
  3. Trả lời: Ai sở hữu dữ liệu? Ai đang mượn? Borrow còn được dùng sau thao tác nào?
  4. Ưu tiên chỉnh API, phạm vi sống và kiểu tham số hơn là thêm .clone() vô tội vạ.
RUST
// Sai (không biên dịch):
// let mut items = vec![1, 2, 3];
// let first = &items[0];
// items.push(4);
// println!("{first}");

// Đúng nếu chỉ cần lưu giá trị i32:
fn main() {
    let mut items = vec![1, 2, 3];
    let first = items[0];
    items.push(4);
    println!("{first}");
}

dbg!(expression) hữu ích để in giá trị kèm vị trí mã khi debug. Với lỗi phức tạp, tạo minimal reproducible example và kiểm tra từng borrow một.

01Tính tổng số chẵnViết hàm sum_even(nums: &[i32]) -> i32 cộng các số chẵn. Không thay đổi vector đầu vào.⌄

RUST
fn sum_even(nums: &[i32]) -> i32 {
    nums.iter().copied().filter(|n| n % 2 == 0).sum()
}

fn main() {
    assert_eq!(sum_even(&[1, 2, 3, 4, 5, 6]), 12);
}
02FizzBuzz bằng matchTừ 1 đến 30: chia hết cho 3 in “Fizz”, cho 5 in “Buzz”, cho cả hai in “FizzBuzz”.⌄

Lời giải tham khảo Có nhiều cách viết đúng. Hãy so sánh với cách của bạn.

RUST
fn fizzbuzz(n: u32) -> String {
    match (n % 3 == 0, n % 5 == 0) {
        (true, true) => "FizzBuzz".into(),
        (true, false) => "Fizz".into(),
        (false, true) => "Buzz".into(),
        _ => n.to_string(),
    }
}

fn main() {
    for n in 1..=30 {
        println!("{}", fizzbuzz(n));
    }
}
03Trung bình cộng với OptionTạo hàm tính trung bình của slice số nguyên. Với slice rỗng, trả về None.⌄

Lời giải tham khảo Có nhiều cách viết đúng. Hãy so sánh với cách của bạn.

RUST
fn average(nums: &[i32]) -> Option<f64> {
    if nums.is_empty() {
        return None;
    }
    let sum: f64 = nums.iter().map(|&n| f64::from(n)).sum();
    Some(sum / nums.len() as f64)
}

fn main() {
    assert_eq!(average(&[2, 4, 6]), Some(4.0));
    assert_eq!(average(&[]), None);
}
04Ví tiền với struct và ResultTạo Wallet có balance, phương thức deposit và withdraw; không được rút quá số dư.⌄

Lời giải tham khảo Có nhiều cách viết đúng. Hãy so sánh với cách của bạn.

RUST
struct Wallet { balance: u32 }

impl Wallet {
    fn deposit(&mut self, amount: u32) {
        self.balance += amount;
    }

    fn withdraw(&mut self, amount: u32) -> Result<(), &'static str> {
        if amount > self.balance {
            return Err("Không đủ tiền");
        }
        self.balance -= amount;
        Ok(())
    }
}

fn main() {
    let mut wallet = Wallet { balance: 100 };
    wallet.deposit(50);
    assert!(wallet.withdraw(120).is_ok());
    assert!(wallet.withdraw(40).is_err());
}
05Đếm tần suất từNhận một chuỗi và đếm số lần xuất hiện từng từ bằng HashMap. Có thể đơn giản hóa bằng cách tách ở khoảng trắng.⌄

Lời giải tham khảo Có nhiều cách viết đúng. Hãy so sánh với cách của bạn.

RUST
use std::collections::HashMap;

fn frequencies(text: &str) -> HashMap<String, usize> {
    let mut counts = HashMap::new();
    for word in text.split_whitespace() {
        let key = word.to_lowercase();
        *counts.entry(key).or_insert(0) += 1;
    }
    counts
}

fn main() {
    let counts = frequencies("Rust nhanh Rust an toàn");
    assert_eq!(counts.get("rust"), Some(&2));
}
06Lọc từ với iteratorViết hàm nhận slice chứa các chuỗi &str và trả về từ dài ít nhất min ký tự Unicode scalar.⌄

Lời giải tham khảo Có nhiều cách viết đúng. Hãy so sánh với cách của bạn.

RUST
fn long_words<'a>(words: &'a [&'a str], min: usize) -> Vec<&'a str> {
    words.iter()
        .copied()
        .filter(|word| word.chars().count() >= min)
        .collect()
}

fn main() {
    let words = ["Rust", "an", "toàn"];
    assert_eq!(long_words(&words, 4), vec!["Rust", "toàn"]);
}
