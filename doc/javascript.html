Phần 1

Khởi động đúng cách

Làm quen công cụ, cú pháp, cách đọc mã và cách học hiệu quả.

Bài 00 · Định hướng

Cách sử dụng tài liệu và lộ trình học

JavaScript (JS) là ngôn ngữ được dùng để tạo tương tác trên trang web và còn có thể chạy ở máy chủ. Tài liệu này dành cho người mới, nhưng có cả nội dung trung cấp như closure, prototype, bất đồng bộ và API.

  1. Đọc theo thứ tự: nếu chưa từng lập trình, bắt đầu từ bài 01. Mỗi bài có kiến thức cốt lõi và ví dụ.
  2. Chạy và sửa ví dụ: nhấn “Chạy thử”; thử thay giá trị, dự đoán kết quả rồi chạy lại.
  3. Gõ lại mã: tự gõ ít nhất một ví dụ trong mỗi bài vào file .js của bạn.
  4. Làm bài tập: cố gắng giải trước khi mở gợi ý, cuối cùng làm quiz và ứng dụng To-do.
Ghi chú quan trọng: Các đoạn có nút “Chạy thử” được thực thi trong khung iframe cách ly với trang bài học, với kết quả console hiển thị bên dưới. Ví dụ import/export và localStorage được trình bày để bạn chạy trong dự án thực tế, không phải mọi đoạn mã đều có thể chạy trong hộp ví dụ.

Cần chuẩn bị gì?

Một trình duyệt hiện đại (Chrome, Edge, Firefox hoặc Safari), một trình soạn thảo như VS Code nếu muốn luyện code, và một thư mục chứa index.html cùng main.js. Nhấn F12 hoặc Ctrl + Shift + J trên nhiều trình duyệt để mở Developer Tools → Console (macOS thường dùng Cmd + Option + J trong Chrome).

Bài 01 · Tổng quan

JavaScript là gì và chạy ở đâu?

Trong một trang web: HTML định nghĩa cấu trúc, CSS định dạng giao diện, và JavaScript xử lý hành vi như bấm nút, kiểm tra biểu mẫu, gọi API, thay đổi nội dung.

Trình duyệt

Có DOM, window, document, fetch và các Web API.

Node.js

Chạy JS bên ngoài trình duyệt; dùng xây server, công cụ dòng lệnh và hệ thống build.

Gắn JavaScript vào trang HTML

index.html · ví dụ cấu trúc
<!doctype html>
<html lang="vi">
  <head><meta charset="utf-8"></head>
  <body>
    <h1>Xin chào JavaScript</h1>
    <script src="main.js" defer></script>
  </body>
</html>

defer giúp script ngoài tải mà không chặn quá trình phân tích HTML và thực thi sau khi tài liệu được phân tích (giữ thứ tự giữa các script defer). Nếu dùng type="module", script cũng mặc định có hành vi trì hoãn thực thi tương tự.

Bài 02 · Công cụ

Cú pháp, chú thích và console

JavaScript phân biệt chữ hoa/thường: userName và username là hai tên khác nhau. Dấu ; thường không bắt buộc vì cơ chế tự chèn dấu chấm phẩy (ASI), nhưng nên dùng nhất quán và hiểu những trường hợp dễ gây lỗi.

01 · Console và chú thích 
// Chú thích một dòng
/* Chú thích nhiều dòng */
console.log("Xin chào, JavaScript!");
console.log(2 + 3);
console.warn("Đây là một cảnh báo");

Đọc lỗi trong console là kỹ năng quan trọng. SyntaxError liên quan cú pháp, ReferenceError thường do tên chưa tồn tại, và TypeError thường do thao tác trên giá trị không phù hợp.

Phần 2

Kiến thức nền tảng

Biến, dữ liệu, logic, vòng lặp và hàm — nền móng của mọi chương trình.

Bài 03 · Nền tảng

Biến: let, const, var

Biến là tên tham chiếu đến một giá trị. Dùng const mặc định; chuyển sang let khi cần gán lại. var là cú pháp cũ có phạm vi hàm thay vì phạm vi khối và nhiều hành vi dễ gây nhầm lẫn.

02 · Khai báo và thay đổi biến 
const ten = "An";
let tuoi = 20;
tuoi = tuoi + 1;
console.log(`${ten} hiện ${tuoi} tuổi`);

const thongTin = { thanhPho: "Hà Nội" };
thongTin.thanhPho = "Đà Nẵng"; // hợp lệ
console.log(thongTin.thanhPho);
// thongTin = {}; // TypeError: không được gán lại const
Lưu ý: const không làm đối tượng trở nên bất biến; nó chỉ ngăn gán lại biến. let và const có phạm vi khối { ... } và có “temporal dead zone” trước khi được khởi tạo.
Bài 04 · Nền tảng

Kiểu dữ liệu trong JavaScript

Các giá trị nguyên thủy (primitive) gồm string, number, boolean, undefined, null, bigint, symbol. object chứa đối tượng, mảng, hàm (hàm cũng là đối tượng có thể gọi).

03 · Kiểm tra kiểu và tham chiếu 
console.log(typeof "ABC");        // string
console.log(typeof 42);           // number
console.log(typeof null);         // object (lỗi lịch sử)
console.log(Array.isArray([1, 2])); // true
console.log(Number.isNaN(NaN));   // true

const a = { diem: 10 };
const b = a; // cùng tham chiếu
b.diem = 20;
console.log(a.diem); // 20
Ghi nhớ: Các kiểu primitive được so sánh theo giá trị, còn đối tượng và mảng so sánh theo tham chiếu: {} === {} là false.
Bài 05 · Nền tảng

Toán tử, so sánh và chuyển kiểu

Các toán tử thường gặp: số học + - * / % **; so sánh > < >= <= === !==; logic && || !; gán = += -=; hợp nhất null ??.

04 · So sánh nghiêm ngặt & giá trị mặc định 
console.log(5 === "5");      // false
console.log(5 == "5");       // true (ép kiểu, nên hạn chế)
console.log(2 ** 3);         // 8
console.log(10 % 3);         // 1
console.log("5" + 2);        // "52"
console.log(Number("5") + 2); // 7

const ten = "";
console.log(ten || "Khách"); // "Khách" vì "" là falsy
console.log(ten ?? "Khách"); // "" vì không null/undefined

Truthy và falsy

Các giá trị falsy gồm false, 0, -0, 0n, "", null, undefined, NaN. Các giá trị khác thường là truthy, kể cả [] và {}. Ưu tiên === và !== để tránh lỗi do ép kiểu ngầm.

Bài 06 · Logic

Rẽ nhánh: if, else, switch, toán tử ba ngôi

Câu lệnh điều kiện quyết định đoạn mã nào được thực thi. Dùng if / else cho điều kiện tổng quát; switch thuận tiện khi so sánh một giá trị với nhiều trường hợp.

05 · Phân loại điểm 
const diem = 8.2;
let xepLoai;
if (diem >= 8) xepLoai = "Giỏi";
else if (diem >= 6.5) xepLoai = "Khá";
else if (diem >= 5) xepLoai = "Trung bình";
else xepLoai = "Cần cố gắng";
console.log(xepLoai);

const laNguoiLon = 19 >= 18 ? "Có" : "Không";
console.log("Đủ tuổi:", laNguoiLon);

switch ("thu-7") {
  case "thu-7":
  case "chu-nhat": console.log("Cuối tuần"); break;
  default: console.log("Ngày thường");
}

Mẹo: Tránh lồng quá nhiều if; tách logic thành hàm nhỏ hoặc dùng early return khi có thể.

Bài 07 · Logic

Vòng lặp: for, while, for...of, for...in

Vòng lặp giúp xử lý nhiều phần tử. for...of duyệt giá trị trong iterable như mảng, chuỗi. for...in duyệt tên thuộc tính có thể liệt kê của đối tượng (kể cả thuộc tính kế thừa) nên thường không dùng cho mảng.

06 · Các kiểu duyệt 
let tong = 0;
for (let i = 1; i <= 5; i++) tong += i;
console.log("Tổng 1..5 =", tong);

for (const mau of ["đỏ", "xanh", "vàng"]) {
  console.log("Màu:", mau);
}

const nguoi = { ten: "Lan", tuoi: 22 };
for (const key in nguoi) {
  if (Object.hasOwn(nguoi, key)) {
    console.log(key, nguoi[key]);
  }
}

break dừng vòng lặp; continue bỏ qua lần lặp hiện tại. Với while, phải đảm bảo điều kiện dừng để tránh vòng lặp vô hạn.

Bài 08 · Trọng tâm

Hàm, tham số, return và arrow function

Hàm là khối mã có thể tái sử dụng. Tham số là tên nhận dữ liệu, đối số là giá trị truyền vào. return trả kết quả và kết thúc thực thi hàm.

07 · Ba cách viết hàm 
function cong(a, b = 0) {
  return a + b;
}
const nhan = function(a, b) { return a * b; };
const binhPhuong = x => x * x;
console.log(cong(3, 4));
console.log(nhan(3, 4));
console.log(binhPhuong(5));

function tongTatCa(...so) { // rest parameter
  return so.reduce((tong, n) => tong + n, 0);
}
console.log(tongTatCa(1, 2, 3, 4));

Khác nhau giữa function và arrow

function declaration được hoist để có thể gọi trước khi định nghĩa. Arrow function không có this, arguments và super riêng; phù hợp callback nhưng thường không nên dùng làm phương thức khi cần this động. Hàm là giá trị nên có thể truyền hàm vào hàm khác (callback).

Bài 09 · Tư duy sâu

Phạm vi biến, hoisting và closure

Scope xác định nơi tên biến có thể được truy cập: global, function, block. Lexical scope nghĩa là hàm nhìn thấy các biến của môi trường nơi nó được định nghĩa. Closure là khả năng hàm giữ quyền truy cập môi trường bên ngoài ngay cả sau khi hàm bên ngoài đã trả về.

08 · Bộ đếm bằng closure 
function taoBoDem() {
  let giaTri = 0; // riêng tư nhờ closure
  return function() {
    giaTri++;
    return giaTri;
  };
}
const demA = taoBoDem();
const demB = taoBoDem();
console.log(demA(), demA(), demB()); // 1 2 1

{
  let trongKhoi = "chỉ ở đây";
  console.log(trongKhoi);
}
// console.log(trongKhoi); // ReferenceError

Hoisting: khai báo hàm dạng function ten(){} có thể được gọi trước; var được khởi tạo là undefined trước khi gán; còn truy cập let/const trước khi khởi tạo gây ReferenceError.

Phần 3

Làm việc với dữ liệu

Tổ chức và biến đổi dữ liệu bằng cấu trúc linh hoạt, hiện đại.

Bài 10 · Dữ liệu

Mảng và các phương thức quan trọng

Mảng (Array) là danh sách có thứ tự, chỉ số bắt đầu từ 0. Các phương thức thường gặp: push/pop thêm/xóa cuối mảng, map biến đổi phần tử, filter lọc, find tìm, some/every kiểm tra và reduce tích lũy.

09 · map, filter, reduce và sort 
const so = [5, 2, 8, 1, 4];
console.log(so.map(x => x * 2));
console.log(so.filter(x => x % 2 === 0));
console.log(so.find(x => x > 6));
console.log(so.reduce((tong, x) => tong + x, 0));

// sort() thay đổi mảng gốc, mặc định so sánh dạng chuỗi
const sapXep = [...so].sort((a, b) => a - b);
console.log("Tăng dần:", sapXep);
console.log("Mảng gốc:", so);
Phương thứcTrả vềThay đổi mảng gốc?
map()Mảng mớiKhông
filter()Mảng mớiKhông
find()Phần tử đầu phù hợp / undefinedKhông
reduce()Giá trị tích lũyKhông tự thay đổi
push(), splice(), sort()Tùy phương thứcCó
slice(), toSorted()Mảng mớiKhông
Mẹo: forEach dùng để thực hiện tác vụ với từng phần tử, không tạo mảng kết quả. Khi xử lý bất đồng bộ, forEach(async ...) không tự đợi tất cả Promise; hãy cân nhắc for...of hoặc Promise.all.
Bài 11 · Dữ liệu

Object, truy cập thuộc tính và phương thức

Object lưu các cặp khóa/giá trị. Truy cập bằng dấu chấm user.name hoặc ngoặc vuông user["name"]. Ngoặc vuông hữu ích khi tên khóa nằm trong một biến. Object.keys / values / entries giúp duyệt thuộc tính sở hữu và có thể liệt kê.

10 · Làm việc với đối tượng 
const hocVien = {
  ten: "Mai",
  diem: [8, 9, 10],
  diemTrungBinh() {
    return this.diem.reduce((a, b) => a + b, 0)
      / this.diem.length;
  }
};
console.log(hocVien.ten);
console.log(hocVien["diem"]);
console.log(hocVien.diemTrungBinh());
console.log(Object.keys(hocVien));

const banSaoNong = { ...hocVien, ten: "Bình" };
console.log(banSaoNong.ten);

Sao chép nông (shallow copy) bằng {...obj} hoặc [...arr] không sao chép sâu các đối tượng lồng nhau. structuredClone() có thể sao chép sâu nhiều kiểu dữ liệu phổ biến nhưng không hỗ trợ mọi giá trị, chẳng hạn function.

Bài 12 · Cú pháp mới

Destructuring, spread/rest, optional chaining

Những cú pháp này làm mã ngắn và dễ đọc: destructuring lấy dữ liệu từ mảng/đối tượng, spread mở rộng giá trị, rest gom phần còn lại, ?. tránh lỗi khi phần trước là null/undefined, ?? cung cấp giá trị mặc định khi thiếu dữ liệu.

11 · Cú pháp hiện đại trong một ví dụ 
const user = { ten: "Hà", diaChi: { thanhPho: "Huế" } };
const { ten, tuoi = 18 } = user;
const [dau, ...conLai] = [10, 20, 30];
console.log(ten, tuoi, dau, conLai);

const capNhat = { ...user, ten: "Linh" };
console.log(capNhat.ten);
console.log(user.congViec?.ten ?? "Chưa có việc làm");
console.log(user.diaChi?.thanhPho);

const tong = (...numbers) => numbers.reduce((s, n) => s + n, 0);
console.log(tong(2, 4, 6));

Phân biệt hai vai trò của dấu ...: trong fn(...array) hoặc [...arr] là spread, trong function fn(...args) hay const [x, ...rest] = arr là rest.

Bài 13 · Thư viện sẵn có

String, Number, Math và Date

JavaScript có nhiều hàm có sẵn: chuỗi dùng trim, includes, slice, replace, split; số dùng Number, parseInt, toFixed; toán dùng Math.round, floor, ceil, random; thời gian dùng Date và Intl.

12 · Xử lý chuỗi, số, thời gian 
const nhap = "  Hoc JavaScript  ";
console.log(nhap.trim().toLowerCase());
console.log("a,b,c".split(","));
console.log("JavaScript".includes("Script"));
console.log(Math.round(3.6), Math.floor(3.6));
console.log((12.345).toFixed(2)); // "12.35" là string

const ngay = new Date("2026-01-01T00:00:00Z");
console.log(new Intl.DateTimeFormat("vi-VN", {
  timeZone: "UTC", day: "2-digit", month: "2-digit",
  year: "numeric"
}).format(ngay));
Lưu ý về số và ngày: 0.1 + 0.2 !== 0.3 do biểu diễn số thực nhị phân; không nên so sánh số thực tính toán mà không xét sai số. Date phụ thuộc múi giờ khi định dạng; nên chỉ rõ múi giờ nếu kết quả phải nhất quán.
Bài 14 · Hướng đối tượng

this, prototype, class và kế thừa

JavaScript có cơ chế kế thừa dựa trên prototype. class là cú pháp tiện dụng để tạo đối tượng và tổ chức quan hệ kế thừa. Trong phương thức thường, this phụ thuộc cách gọi hàm; trong arrow function, this được lấy theo môi trường lexical.

13 · Class và tính đóng gói 
class TaiKhoan {
  #soDu = 0; // trường private
  constructor(chuTaiKhoan) {
    this.chuTaiKhoan = chuTaiKhoan;
  }
  napTien(soTien) {
    if (soTien <= 0) throw new Error("Số tiền phải dương");
    this.#soDu += soTien;
  }
  get soDu() { return this.#soDu; }
}
const taiKhoan = new TaiKhoan("Hương");
taiKhoan.napTien(150);
console.log(taiKhoan.chuTaiKhoan, taiKhoan.soDu);
console.log(taiKhoan instanceof TaiKhoan);

Dùng extends để tạo class con và super(...) gọi constructor của class cha. Trên thực tế, nhiều ứng dụng dùng hàm và thành phần (composition) thay vì lạm dụng kế thừa sâu.

Phần 4

Xây trang web tương tác

JavaScript thao tác giao diện, giao tiếp mạng và lưu dữ liệu như thế nào.

Bài 15 · Trình duyệt

DOM: chọn, tạo, sửa phần tử HTML

DOM (Document Object Model) biểu diễn tài liệu HTML dưới dạng cây đối tượng. Dùng document.querySelector() chọn một phần tử, querySelectorAll() lấy danh sách, textContent đổi văn bản, classList đổi class và createElement() để tạo phần tử.

main.js · thao tác DOM (đặt trong HTML thực tế)
const tieuDe = document.querySelector("#tieu-de");
tieuDe.textContent = "Tiêu đề mới";
tieuDe.classList.add("noi-bat");

const li = document.createElement("li");

Bài 16 · Tương tác

Event, addEventListener và form

Sự kiện là tín hiệu như click, input, change, submit. Dùng addEventListener để lắng nghe. Trong form, event.preventDefault() ngăn hành vi gửi form mặc định khi bạn muốn xử lý bằng JavaScript.

main.js · lắng nghe form
const form = document.querySelector("#loginForm");
form.addEventListener("submit", (event) => {
  event.preventDefault();
  const email = form.elements.email.value.trim();
  if (!email.includes("@")) {
    alert("Email chưa hợp lệ");
    return;
  }
  console.log("Email đã nhập:", email);
});

// Form HTML cần có input name="email".

Event bubbling & delegation

Đa số sự kiện đi từ phần tử đích lên cha (bubbling). Event delegation là gắn listener trên phần tử cha và kiểm tra event.target.closest("button") để xử lý các nút con, kể cả nút thêm về sau. Một số event không bubble như focus; có thể dùng focusin khi cần.

Accessibility: Dùng <button> thật cho hành động thay vì <div onclick="...">; kết hợp <label>, báo lỗi rõ và hỗ trợ bàn phím.
Bài 17 · Bất đồng bộ

Event loop, Promise và async/await

JavaScript thông thường chạy mã trên một luồng chính với call stack, nhưng các API có thể hoàn thành tác vụ bất đồng bộ. Promise biểu diễn một kết quả trong tương lai: pending, fulfilled hoặc rejected. async khiến hàm trả Promise; await tạm dừng trong hàm async để chờ kết quả mà không chặn toàn bộ vòng lặp sự kiện.

14 · Thứ tự thực thi 
console.log("A · đồng bộ");

Promise.resolve().then(() => console.log("C · microtask"));
console.log("B · đồng bộ");

  return "Hoàn thành";
}

Hai lệnh đồng bộ chạy trước; các callback Promise (microtask) được xử lý trước callback timer (task) sau khi ngăn xếp hiện tại rỗng. Thứ tự giữa các microtask được xếp theo hàng đợi của chúng.

15 · Promise.all và xử lý thất bại 
const cho = (ms, ketQua) =>
  new Promise(resolve => setTimeout(() => resolve(ketQua), ms));

async function main() {
  try {
    const [a, b] = await Promise.all([
      cho(100, "Dữ liệu A"),
      cho(60, "Dữ liệu B")
    ]);
    console.log(a, b);
  } catch (error) {
    console.error("Có lỗi:", error.message);

}

Phân biệt: Promise.all từ chối nếu có bất kỳ Promise nào từ chối; Promise.allSettled chờ tất cả rồi trả trạng thái từng tác vụ. await không tự biến công việc CPU nặng thành công việc chạy nền.
Bài 18 · Kết nối

Fetch API, HTTP và dữ liệu JSON

fetch(url) gửi yêu cầu HTTP và trả một Promise chứa Response. Thông thường lấy JSON qua await response.json(). Một trạng thái HTTP như 404/500 không tự làm Promise của fetch bị reject; nên kiểm tra response.ok.

main.js · tải danh sách bài viết từ API mẫu
async function taiBaiViet() {
  const controller = new AbortController();
  const timeout = setTimeout(() => controller.abort(), 5000);
  try {
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/posts?_limit=3",
      { signal: controller.signal }
    );
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    const posts = await response.json();
    console.log(posts.map(p => p.title));
  } catch (error) {
    console.error("Không tải được dữ liệu:", error.message);
  } finally {
    clearTimeout(timeout);
  }
}
taiBaiViet();

Ví dụ trên cần kết nối mạng và API cho phép gọi từ nguồn gốc của trang (CORS). Các phương thức HTTP phổ biến: GET đọc, POST tạo, PUT/PATCH cập nhật, DELETE xóa; cách sử dụng cụ thể theo hợp đồng API.

Mẫu POST (cần endpoint thực tế)

  method: "POST",

Bài 19 · Độ tin cậy

try / catch / finally và debug

Khi chương trình có thể thất bại, hãy kiểm soát luồng lỗi bằng throw và try/catch. finally chạy khi kết thúc try/catch (kể cả có return trong nhiều tình huống), phù hợp để giải phóng tài nguyên. Với Promise, dùng await trong try để bắt lỗi bất đồng bộ.

16 · Bắt và mô tả lỗi 
function chia(a, b) {
  if (b === 0) throw new RangeError("Không chia cho 0");
  return a / b;
}
try {
  console.log(chia(10, 2));
  console.log(chia(10, 0));
} catch (error) {
  console.error(`${error.name}: ${error.message}`);
} finally {
  console.log("Đã xử lý xong phép tính");
}

Để debug: tái hiện lỗi, đọc stack trace, đặt breakpoint trong tab Sources, kiểm tra biến bằng watch, rồi viết test chống tái phát. Đừng dùng catch rỗng để giấu lỗi.

Bài 21 · Lưu trữ

JSON, localStorage và sessionStorage

JSON.stringify chuyển dữ liệu phù hợp sang chuỗi JSON; JSON.parse chuyển chuỗi JSON thành giá trị. localStorage lưu các cặp key/value chuỗi giữa các phiên trình duyệt trong phạm vi origin; sessionStorage thường tồn tại trong phiên tab. Trên file://, hành vi và quyền truy cập lưu trữ có thể khác nhau giữa các trình duyệt.

Ví dụ lưu giỏ hàng trong trình duyệt
const gioHang = [{ id: 1, soLuong: 2 }];
try {

  const daLuu = JSON.parse(localStorage.getItem("cart") ?? "[]");
  console.log(daLuu[0].soLuong); // 2
} catch (error) {

}

Bảo mật: Không lưu mật khẩu, access token nhạy cảm hay bí mật API trong localStorage. Dữ liệu trong trình duyệt có thể bị đọc bởi JavaScript cùng origin và chịu rủi ro khi có XSS. localStorage không thay thế cơ sở dữ liệu máy chủ.
Bài 22 · Kỹ năng nghề

7 nguyên tắc đáng nhớ

  1. Đặt tên rõ nghĩa: totalPrice tốt hơn tp, một hàm nên làm một việc.
  2. Dùng const mặc định: tránh thay đổi trạng thái ngoài ý muốn.

17 · Hàm dễ kiểm thử 
function tinhTongGia(items) {
  if (!Array.isArray(items)) throw new TypeError("Cần một mảng");
  return items.reduce((tong, item) => {
    if (item.gia < 0 || item.soLuong < 0) {
      throw new RangeError("Giá hoặc số lượng không hợp lệ");
    }
    return tong + item.gia * item.soLuong;
  }, 0);
}
const result = tinhTongGia([
  { gia: 100, soLuong: 2 },
  { gia: 50, soLuong: 1 }
]);
console.log(result === 250 ? "PASS" : "FAIL", result);

Dự án thực tế: To-do List

Đây là ứng dụng quản lý công việc hoạt động ngay bên dưới. Bạn có thể thêm, đánh dấu hoàn thành, lọc và xóa công việc. Dữ liệu được lưu trên trình duyệt khi tính năng lưu trữ khả dụng.

    0 công việc chưa hoàn thành

    Giải thích tư duy xây dựng

    1. State: lưu danh sách dạng [{id, text, done}] và bộ lọc hiện tại.
    2. Render: dựng giao diện từ state, dùng textContent để tránh chèn HTML không an toàn.
    3. Event: khi thêm/xóa/đánh dấu, cập nhật state rồi gọi render().
    4. Persist: dùng JSON.stringify() và localStorage để lưu rồi phục hồi.
    Mã rút gọn minh họa quản lý state
    let tasks = [];
function addTask(text) {
  const title = text.trim();
  if (!title) return;
  tasks = [...tasks, { id: crypto.randomUUID(), text: title, done: false }];
  saveAndRender();
}
function toggleTask(id) {
  tasks = tasks.map(task =>
    task.id === id ? { ...task, done: !task.done } : task
  );
  saveAndRender();
}
function saveAndRender() {
  localStorage.setItem("tasks", JSON.stringify(tasks));
  render(); // tự viết hàm tạo các nút, nhãn, checkbox
}

    Bài tập từ cơ bản đến nâng cao

    Hãy tự giải trong DevTools hoặc một file main.js trước khi xem gợi ý. Mỗi bài đều có thể được giải bằng JavaScript thuần.

    01 · FizzBuzz Cơ bản

    In các số từ 1 đến 30. Bội của 3 in “Fizz”, bội của 5 in “Buzz”, bội của cả hai in “FizzBuzz”.

    Xem gợi ýTrong vòng for, kiểm tra i % 15 === 0 trước, sau đó mới đến 3 và 5.

    02 · Kiểm tra palindrome Cơ bản

    Viết laDoiXung(s) để kiểm tra chuỗi sau khi chuyển chữ thường và loại bỏ khoảng trắng có đọc xuôi/ngược giống nhau không.

    Xem gợi ýDùng toLowerCase(), replace(/\s/g, ""), split("").reverse().join(""). Với Unicode phức tạp cần xử lý cẩn thận hơn.

    03 · Thống kê giỏ hàng Trung cấp

    Cho mảng [{ten: "A", gia: 100, soLuong: 2}, ...], hãy tính tổng tiền, lọc sản phẩm trên 100 và sắp xếp theo giá tăng dần.

    Xem gợi ýKết hợp reduce, filter, và toSorted((a,b) => a.gia - b.gia) hoặc sao chép rồi sort.

    04 · Debounce tìm kiếm Trung cấp

    Viết debounce(fn, delay) để callback chỉ chạy sau khi người dùng ngừng nhập trong delay mili giây.

    Xem gợi ýTạo biến timer ở scope của hàm ngoài; mỗi lần gọi thì clearTimeout(timer), rồi gán timer = setTimeout(...).

    05 · Gọi API chịu lỗi Nâng cao

    Tạo hàm getJSON(url) dùng fetch, có timeout 5 giây, kiểm tra HTTP status, trả JSON và xử lý lỗi hiển thị thân thiện.

    Xem gợi ýDùng AbortController, response.ok, try/catch/finally và clearTimeout. Thử kiểm tra URL không hợp lệ.
