Python là gì?

Hiểu Python được dùng để làm gì và học theo lộ trình nào.

Python là ngôn ngữ lập trình bậc cao, cú pháp dễ đọc, có thể dùng trong tự động hóa, phân tích dữ liệu, trí tuệ nhân tạo, phát triển web, kiểm thử và viết công cụ nội bộ. Python phù hợp với người bắt đầu vì các ý tưởng được diễn đạt bằng những câu lệnh ngắn gọn.

🧠Học tư duyBiến, điều kiện, vòng lặp, hàm và cấu trúc dữ liệu.
🛠️Làm sản phẩmScript tự động hóa, ứng dụng CLI và xử lý file.
🚀Đi xa hơnOOP, kiểm thử, kiểu dữ liệu, bất đồng bộ.

Đọc tutorial này như thế nào?

Học theo thứ tự từ trên xuống nếu bạn mới bắt đầu. Với mỗi mục, hãy tự gõ lại ví dụ, dự đoán kết quả trước khi chạy và thử sửa một dòng để quan sát sự thay đổi. Những bài tập có lời giải mẫu để bạn tự đối chiếu sau khi làm.

  1. Cài Python và tạo chương trình đầu tiên.
  2. Nắm nền tảng: dữ liệu, điều kiện, vòng lặp, hàm.
  3. Học tổ chức chương trình: module, file, ngoại lệ, lớp.
  4. Rèn luyện với bài tập, kiểm thử và dự án nhỏ.

Cài đặt & môi trường

Python, terminal, VS Code, pip và môi trường ảo.

1. Cài trình thông dịch Python

Tải Python từ python.org/downloads. Trên Windows, nếu trình cài đặt có lựa chọn thêm Python vào PATH, hãy bật tùy chọn này. Trên macOS/Linux bạn có thể dùng bản Python 3 có sẵn hoặc trình quản lý gói tương ứng.

Mở Terminal / PowerShell và thử:

Terminal
python --version
# Nếu lệnh trên không nhận diện, thử:
python3 --version
# Trên Windows có thể dùng:
py --version

Nhận kết quả dạng Python 3.x.x tức là lệnh đang hoạt động. Để vào chế độ tương tác, gõ python (hoặc python3 / py); thoát bằng exit().

2. Tạo file và chạy chương trình

Tạo thư mục hoc-python, bên trong tạo file hello.py. Dùng một trình biên tập như VS Code, sau đó chạy:

hello.py
print("Xin chào, Python!")
▸ Kết quả dự kiến
Xin chào, Python!
Terminal
python hello.py
# hoặc python3 hello.py / py hello.py

3. Tạo môi trường ảo cho từng dự án

Môi trường ảo giúp các thư viện của mỗi dự án không xung đột nhau. Chạy trong thư mục dự án:

Terminal
# Tạo môi trường ảo
python -m venv .venv

# Kích hoạt trên Windows PowerShell:
.venv\Scripts\Activate.ps1

# Kích hoạt trên macOS / Linux:
source .venv/bin/activate

# Cài một thư viện ví dụ
python -m pip install requests

# Lưu danh sách phụ thuộc
python -m pip freeze > requirements.txt

# Khi cần cài lại
python -m pip install -r requirements.txt

# Thoát môi trường ảo
deactivate
⚠️
Đừng đưa .venv lên Git
Thường thêm .venv/, __pycache__/ và các file chứa bí mật vào .gitignore. Với dự án thực tế, nên quản lý phiên bản phụ thuộc có chủ đích thay vì chỉ phụ thuộc vào một lần pip freeze.

4. Nếu gặp lỗi phổ biến

Hiện tượngCách kiểm tra
python: command not foundThử python3, kiểm tra cài đặt và biến PATH.
Thư viện không tìm thấyĐảm bảo đang kích hoạt đúng .venv; dùng python -m pip.
VS Code chạy sai PythonChọn Python Interpreter nằm trong .venv.
Không kích hoạt được PowerShellKiểm tra chính sách thực thi của máy; có thể dùng Command Prompt và .venv\Scripts\activate.bat.

Cú pháp đầu tiên

print(), chú thích, thụt lề và lỗi thường gặp.

Python dùng thụt lề để biểu diễn một khối lệnh thay vì dấu ngoặc nhọn. Quy ước phổ biến là 4 dấu cách cho mỗi cấp.

main.py
# Đây là chú thích một dòng
name = "Lan"
print("Xin chào", name)

if name == "Lan":
    print("Đúng tên rồi!")
    print("Hai dòng này cùng một khối")
▸ Kết quả dự kiến
Xin chào Lan
Đúng tên rồi!
Hai dòng này cùng một khối

Những quy tắc nên nhớ

  • Phân biệt chữ hoa và chữ thường: name khác Name.
  • Dấu : thường mở đầu khối lệnh của if, for, while, def, class.
  • Chú thích một dòng bắt đầu bằng #; docstring thường đặt trong cặp ba dấu nháy.
  • Mỗi câu lệnh nên nằm trên một dòng để dễ đọc.
main.py
def say_hello():
    """Trả về lời chào đơn giản."""
    return "Hello"

print(say_hello())
▸ Kết quả dự kiến
Hello
⚠️
Lỗi IndentationError
Trộn tab và dấu cách hoặc thụt lề không đồng nhất thường làm chương trình báo lỗi. Bật hiển thị khoảng trắng trong editor để kiểm tra.

In ra 3 dòng: tên, sở thích và mục tiêu học Python của bạn.

Xem lời giải tham khảo
main.py

Biến & kiểu dữ liệu

int, float, str, bool, None và chuyển đổi kiểu.

Biến là tên tham chiếu đến một giá trị. Python xác định kiểu của đối tượng ở thời điểm chạy, nên bạn không cần khai báo kiểu trước khi gán.

main.py
age = 20             # int
height = 1.68        # float
name = "An"          # str
is_student = True    # bool
nickname = None      # NoneType

print(type(age))
print(type(name))
print(isinstance(age, int))
▸ Kết quả dự kiến
<class 'int'>
<class 'str'>
True

Quy tắc đặt tên

  • Dùng tên có nghĩa: total_price tốt hơn tp trong nhiều trường hợp.
  • Dùng snake_case cho biến và hàm; PascalCase cho lớp.
  • Không đặt tên trùng từ khóa như class, for, return.
  • Hạn chế ghi đè hàm có sẵn như list, str, sum.

Chuyển đổi kiểu

main.py
a = "12"
b = int(a)        # "12" -> 12
c = float("3.5") # "3.5" -> 3.5
d = str(42)       # 42 -> "42"

print(b + 8)
print(c * 2)
print(d + " tuổi")
▸ Kết quả dự kiến
20
7.0
42 tuổi
⚠️
Chú ý bool()
bool(""), bool(0) và bool([]) là False; nhưng bool("False") là True vì chuỗi không rỗng.

Chuỗi (str)

Nối chuỗi, cắt chuỗi, phương thức và f-string.

Chuỗi trong Python là dãy ký tự không thể chỉnh sửa trực tiếp (immutable). Chỉ số bắt đầu từ 0, chỉ số âm đếm từ cuối.

main.py
text = "Python"
print(text[0])       # P
print(text[-1])      # n
print(text[1:4])     # yth
print(text[:3])      # Pyt
print(text[::-1])    # nohtyP
print(len(text))     # 6
▸ Kết quả dự kiến
P
n
yth
Pyt
nohtyP
6

Phương thức thường dùng

main.py
s = "  Xin Chào Python  "
print(s.strip())
print(s.lower().strip())
print(s.replace("Python", "bạn"))
print("a,b,c".split(","))
print(" - ".join(["đỏ", "xanh", "vàng"]))
▸ Kết quả dự kiến
Xin Chào Python
xin chào python
  Xin Chào bạn  
['a', 'b', 'c']
đỏ - xanh - vàng

Định dạng bằng f-string

main.py
name = "Mai"
score = 9.256
print(f"{name} đạt {score:.2f} điểm")
print(f"Điểm gấp đôi: {score * 2:.1f}")
▸ Kết quả dự kiến
Mai đạt 9.26 điểm
Điểm gấp đôi: 18.5
✅
Unicode tiếng Việt
Python 3 hỗ trợ Unicode. Để xử lý file có tiếng Việt nhất quán, chủ động dùng encoding="utf-8" khi đọc và ghi file văn bản.

Nhập / xuất dữ liệu

input(), ép kiểu và hiển thị có định dạng.

input() đọc dữ liệu người dùng nhập từ bàn phím và luôn trả về chuỗi (str). Khi muốn tính toán, bạn cần chuyển thành số.

name = input("Tên của bạn: ")

price = 125000
quantity = 3
print("Tổng:", price * quantity, "VNĐ")
print(f"Tổng: {price * quantity:,} VNĐ")
print("A", "B", "C", sep=" | ", end="!\n")

Câu lệnh điều kiện

if / elif / else, toán tử điều kiện và match.

Điều kiện giúp chương trình lựa chọn một nhánh xử lý. Chỉ khối lệnh có điều kiện thỏa mãn mới được thực thi.

main.py
score = 8.4
if score >= 8:
    grade = "Giỏi"
elif score >= 6.5:
    grade = "Khá"
elif score >= 5:
    grade = "Trung bình"
else:
    grade = "Cần cố gắng"

print(grade)
▸ Kết quả dự kiến
Giỏi

Điều kiện lồng nhau và biểu thức ngắn

main.py
age = 16
has_parent = True
if age >= 18 or has_parent:
    print("Có thể tham gia")

status = "Đủ tuổi" if age >= 18 else "Chưa đủ tuổi"
print(status)
▸ Kết quả dự kiến
Có thể tham gia
Chưa đủ tuổi

match / case (Python 3.10+)

main.py
command = "start"
match command:
    case "start":
        print("Bắt đầu")
    case "stop":
        print("Dừng")
    case _:
        print("Không hợp lệ")
▸ Kết quả dự kiến
Bắt đầu
💡
Dùng elif đúng cách
Trong chuỗi if / elif / else, Python dừng ở nhánh đầu tiên đúng; thứ tự điều kiện vì thế rất quan trọng.

Vòng lặp

for, while, range, break, continue và enumerate.

Vòng lặp giúp lặp lại thao tác mà không cần viết lại lệnh nhiều lần. for phù hợp để duyệt một chuỗi hoặc tập hợp; while phù hợp khi lặp đến khi điều kiện thay đổi.

main.py
for number in range(1, 6):
    print(number, end=" ")
print()

count = 3
while count > 0:
    print("Còn", count)
    count -= 1
▸ Kết quả dự kiến
1 2 3 4 5
Còn 3
Còn 2
Còn 1

break, continue, enumerate, zip

main.py
for n in range(1, 8):
    if n == 3:
        continue        # bỏ qua số 3
    if n == 6:
        break           # kết thúc vòng lặp
    print(n, end=" ")
print()

names = ["An", "Bình", "Chi"]
for index, name in enumerate(names, start=1):
    print(index, name)

for name, score in zip(names, [8, 9, 7]):
    print(f"{name}: {score}")
▸ Kết quả dự kiến
1 2 4 5
1 An
2 Bình
3 Chi
An: 8
Bình: 9
Chi: 7
⚠️
Tránh vòng lặp vô hạn
Với while, cần một cách để điều kiện trở thành False hoặc có lệnh break. Khi cần lặp theo số lần biết trước, for ... in range(...) thường dễ đọc hơn.

Xem lời giải tham khảo

Danh sách & tuple

list, slicing, chỉnh sửa và tuple bất biến.

list là dãy có thứ tự, có thể thay đổi. tuple là dãy có thứ tự nhưng không thể thay đổi cấu trúc sau khi tạo. Cả hai cho phép các giá trị trùng lặp.

main.py
fruits = ["táo", "cam", "xoài"]

Lập trình bất đồng bộ

async def, await, asyncio và trường hợp sử dụng.

asyncio hữu ích cho tác vụ đợi I/O như truy vấn mạng hoặc kết nối dịch vụ bất đồng bộ. Nó không tự làm vòng lặp tính toán CPU nặng trở nên nhanh hơn.

main.py
import asyncio

async def task(name, delay):
    await asyncio.sleep(delay)
    print(f"Xong {name}")

async def main():
    await asyncio.gather(
        task("A", 0.1),
        task("B", 0.2),
    )

asyncio.run(main())
▸ Kết quả dự kiến
Xong A
Xong B

asyncio.gather() điều phối nhiều tác vụ có thể chờ cùng lúc. Đoạn ví dụ có thời gian chờ rất ngắn để dễ quan sát; thứ tự in tùy thuộc thời gian hoàn tất.

⚠️
Đừng chặn event loop
Gọi time.sleep() trong async def sẽ chặn luồng xử lý. Dùng await asyncio.sleep() cho việc chờ không chặn; với công việc tính toán nặng hoặc I/O đồng bộ, cần chiến lược khác.

Dự án 1: Máy tính CLI

calculator_cli.py
def calculate(a, b, op):
    if op == "+":
        return a + b
    if op == "-":
        return a - b
    if op == "*":
        return a * b
    if op == "/":
        if b == 0:
            raise ValueError("Không được chia cho 0")
        return a / b
    raise ValueError("Phép toán không hợp lệ")

try:
    a = float(input("Số thứ nhất: "))
    op = input("Phép toán (+ - * /): ").strip()
    b = float(input("Số thứ hai: "))
    print("Kết quả:", calculate(a, b, op))
except ValueError as error:
    print("Lỗi:", error)

Dự án 3: To-do list lưu JSON

Yêu cầu: thêm việc, xem danh sách, đánh dấu hoàn thành và lưu xuống JSON. Mẫu rút gọn dưới đây xây nền dữ liệu; bạn có thể xây thêm menu while và xử lý input.

todo.py
import json
from pathlib import Path

DB = Path("tasks.json")

def load_tasks():
    if not DB.exists():
        return []
    return json.loads(DB.read_text(encoding="utf-8"))

def save_tasks(tasks):
    DB.write_text(json.dumps(tasks, ensure_ascii=False, indent=2), encoding="utf-8")

def add_task(title):
    tasks = load_tasks()
    tasks.append({"title": title, "done": False})
    save_tasks(tasks)

add_task("Ôn tập hàm Python")
print(load_tasks())

[{'title': 'Ôn tập hàm Python', 'done': False}]
