Bắt đầu học C++

C++ là gì, học như thế nào và bạn sẽ xây dựng được gì?

C++ là ngôn ngữ lập trình biên dịch, đa mô hình: lập trình thủ tục, hướng đối tượng và generic. Nó thường được dùng cho phần mềm hệ thống, game, ứng dụng hiệu năng cao, thiết bị nhúng và các bài toán thuật toán.

⚡ Hiệu năngKiểm soát tài nguyên và chi phí thực thi.
🧩 Linh hoạtTừ chương trình nhỏ đến hệ thống lớn.
📚 Thư viện chuẩnvector, string, thuật toán, I/O và nhiều hơn.

Chuẩn và cách học

Hướng dẫn ưu tiên cú pháp C++17, giới thiệu thêm một số tính năng C++20. Mỗi chương gồm giải thích, ví dụ, lưu ý và bài thực hành. Bạn không cần biết C trước khi học C++.

  1. Đọc khái niệm và đoán đầu ra của chương trình.
  2. Gõ lại ví dụ trong trình soạn thảo, tự thay đổi dữ liệu.
  3. Làm bài tập trước khi mở lời giải.
  4. Ôn lại chương đã học sau 1–2 ngày.

Hiểu include, main, câu lệnh, comment và namespace.

Nhập / xuất dữ liệu

Sử dụng cin, cout, getline và định dạng đầu ra.

main.cpp
#include <iostream>
#include <string>
#include <limits>

int main() {
    int age{};
    std::string fullName;

    std::cout << "Nhap tuoi: ";
    if (!(std::cin >> age)) {
        std::cerr << "Tuoi khong hop le!\n";
        return 1;
    }
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
    std::cout << "Nhap ho ten: ";
    std::getline(std::cin, fullName);
    std::cout << "Xin chao " << fullName << " (" << age << ")\n";
}

Vòng lặp for, while, do-while

Lặp có điều kiện và duyệt tập dữ liệu.

main.cpp
#include <iostream>
#include <vector>
int main() {
    for (int i = 1; i <= 5; ++i) {
        std::cout << i << ' ';
    }
    std::cout << '\n';

    int n{3};
    while (n > 0) {
        std::cout << n-- << ' ';
    }
    std::cout << '\n';

    int x{0};
    do {
        ++x;
    } while (x < 1); // chạy ít nhất một lần

    std::vector<int> values{3, 5, 8};
    for (int value : values) {
        std::cout << value << ' ';
    }
}
  • for: biết rõ cách khởi tạo/cập nhật biến đếm.
  • while: lặp khi điều kiện còn đúng.
  • do...while: kiểm tra điều kiện sau mỗi lượt.
  • for (auto x : container): duyệt phần tử ngắn gọn.

break kết thúc vòng lặp gần nhất; continue bỏ qua phần còn lại của lượt hiện tại.

!
Chú ý vòng lặp vô hạn
Bảo đảm biến điều khiển được cập nhật đúng, đặc biệt trong while. Khi duyệt size(), cân nhắc kiểu chỉ số không dấu std::size_t.

Truyền theo giá trị và tham chiếu

main.cpp
#include <iostream>
#include <string>

void changeCopy(int x) { x = 99; }
void changeOriginal(int& x) { x = 99; }
void printName(const std::string& name) {
    std::cout << name << '\n'; // không sao chép chuỗi
}

int main() {
    int value{10};
    changeCopy(value);     // value vẫn là 10
    changeOriginal(value); // value thành 99
    printName("Nguyen Van An");
}

Constructor, destructor và RAII

Quản lý vòng đời và tài nguyên an toàn.

main.cpp
#include <iostream>
#include <string>

class Tracer {
    std::string name_;
public:
    explicit Tracer(std::string name) : name_(name) {
        std::cout << "Tao " << name_ << '\n';
    }
    ~Tracer() {
        std::cout << "Huy " << name_ << '\n';
    }
};

int main() {
    Tracer outer{"A"};
    {
        Tracer inner{"B"};
    } // B bị hủy tại đây
} // Sau đó A bị hủy

Constructor khởi tạo đối tượng; destructor (~TênLớp()) chạy khi đối tượng bị hủy. Biến cục bộ thông thường có vòng đời tự động theo phạm vi.

RAII: Resource Acquisition Is Initialization

Gắn tài nguyên (file, khóa mutex, bộ nhớ, socket…) với một đối tượng. Khi đối tượng ra khỏi phạm vi, destructor dọn dẹp tài nguyên — kể cả lúc có ngoại lệ.

main.cpp
#include <fstream>
#include <string>

int main() {
    std::ofstream file{"notes.txt"};
    if (!file) return 1;
    file << "Du lieu duoc ghi bang RAII\n";
} // ofstream tự đóng file

Rule of Zero / Five

Nếu một lớp chỉ chứa những thành viên biết tự quản lý tài nguyên (như std::string, std::vector), thường không cần tự viết destructor, copy/move constructor hay phép gán: đó là Rule of Zero. Nếu tự quản lý tài nguyên cấp thấp, cần cân nhắc nhất quán 5 thao tác đặc biệt (Rule of Five).

✓

Đừng viết destructor hay tự gọi new/delete nếu một kiểu thư viện chuẩn có thể sở hữu tài nguyên giúp bạn.

Kế thừa và đa hình

Sử dụng virtual, override và lớp cơ sở đúng cách.

main.cpp
#include <iostream>
#include <memory>
#include <vector>

class Shape {
public:
    virtual ~Shape() = default;
    virtual double area() const = 0; // Hàm thuần ảo
};

class Rectangle final : public Shape {
    double width_, height_;
public:
    Rectangle(double w, double h) : width_(w), height_(h) {}
    double area() const override { return width_ * height_; }
};

int main() {
    std::vector<std::unique_ptr<Shape>> shapes;
    shapes.push_back(std::make_unique<Rectangle>(3.0, 4.0));
    for (const auto& s : shapes) {
        std::cout << s->area() << '\n'; // 12
    }
}

virtual cho phép gọi đúng phiên bản hàm theo kiểu đối tượng thực tế. override yêu cầu phương thức ghi đè hợp lệ; = 0 tạo hàm thuần ảo khiến lớp cơ sở trở thành trừu tượng. final ngăn lớp bị kế thừa tiếp.

!
Destructor ảo
Khi dự định hủy đối tượng dẫn xuất qua con trỏ lớp cơ sở, destructor của lớp cơ sở phải là virtual. Dùng kế thừa cho quan hệ “là một”; ưu tiên composition (“có một”) khi hợp lý.

Algorithm, lambda và sort

main.cpp

#include <numeric>
#include <vector>

int main() {
    std::vector<int> a{5, 2, 8, 1, 4};
    std::sort(a.begin(), a.end());

    auto even = std::count_if(a.begin(), a.end(),

Đa luồng cơ bản

Biết thread, mutex và vì sao data race nguy hiểm.

main.cpp
#include <iostream>
#include <mutex>
#include <thread>

std::mutex outputMutex;

void worker(int id) {
    std::lock_guard<std::mutex> lock(outputMutex);
    std::cout << "Worker " << id << " dang chay\n";
}

int main() {
    std::thread a(worker, 1);
    std::thread b(worker, 2);
    a.join();
    b.join();
}

std::thread tạo luồng. join() chờ luồng kết thúc; một std::thread vẫn joinable khi bị hủy sẽ khiến chương trình std::terminate. std::mutex bảo vệ dữ liệu dùng chung; std::lock_guard tự mở khóa theo RAII.

Data race xảy ra khi các luồng truy cập cùng vị trí bộ nhớ đồng thời, ít nhất một truy cập là ghi và không có đồng bộ phù hợp. Trong C++, data race dẫn đến hành vi không xác định.

#include <fstream>
#include <iostream>
#include <limits>
#include <string>
#include <vector>

struct Task {
    std::string title;
    bool done{false};
};

void show(const std::vector<Task>& tasks) {
    if (tasks.empty()) {
        std::cout << "Danh sach trong.\n";
        return;
    }
    for (std::size_t i = 0; i < tasks.size(); ++i) {
        std::cout << i + 1 << ". [" << (tasks[i].done ? 'x' : ' ')
                  << "] " << tasks[i].title << '\n';
    }
}

void save(const std::vector<Task>& tasks) {
    std::ofstream file{"tasks.txt"};
    if (!file) {
        std::cerr << "Khong the luu file.\n";
        return;
    }
    for (const auto& t : tasks) {
        file << (t.done ? "1" : "0") << ' ' << t.title << '\n';
    }
    if (!file) std::cerr << "Ghi file that bai.\n";
    else std::cout << "Da luu vao tasks.txt\n";
}

int main() {
    std::vector<Task> tasks;
    int choice{};
    while (true) {
        std::cout << "\n1. Them  2. Xem  3. Hoan thanh  4. Luu  0. Thoat\n> ";
        if (!(std::cin >> choice)) {
            std::cout << "Nhap mot so hop le.\n";
            return 1;
        }
        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

        if (choice == 0) break;
        if (choice == 1) {
            std::string title;
            std::cout << "Ten cong viec: ";
            std::getline(std::cin, title);
            if (!title.empty()) tasks.push_back({title, false});
        } else if (choice == 2) {
            show(tasks);
        } else if (choice == 3) {
            show(tasks);
            std::size_t index{};
            std::cout << "So thu tu: ";
            if (!(std::cin >> index)) {
                std::cin.clear();
                std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
                std::cout << "So thu tu khong hop le.\n";
                continue;
            }
            if (index >= 1 && index <= tasks.size()) {
                tasks[index - 1].done = true;
            } else {
                std::cout << "Khong tim thay cong viec.\n";
            }
        } else if (choice == 4) {
            save(tasks);
        } else {
            std::cout << "Lua chon khong hop le.\n";
        }
    }
}

Undefined behavior (UB) là gì?

Chuẩn C++ không yêu cầu chương trình có hành vi cụ thể khi xảy ra UB. Ví dụ: truy cập chỉ số ngoài mảng, tràn số nguyên có dấu, giải tham chiếu con trỏ không hợp lệ. UB không chỉ có nghĩa “bị crash”; chương trình có thể cho kết quả bất ngờ hoặc trông vẫn chạy.
