0101 · Tổng quan

Go là gì?

Hiểu lý do Go phù hợp để xây dựng CLI, backend và hệ thống xử lý đồng thời.

Go (Golang) dành cho ai?

Go là ngôn ngữ biên dịch, định kiểu tĩnh, có bộ thu gom rác (garbage collector), cú pháp gọn và hỗ trợ concurrency ngay từ ngôn ngữ. Go đặc biệt hữu ích cho dịch vụ web, API, công cụ dòng lệnh, hạ tầng và xử lý nhiều tác vụ I/O.

⚡Biên dịch nhanhTạo chương trình thực thi độc lập cho nhiều hệ điều hành.
🧩Cú pháp rõ ràngÍt cơ chế phức tạp, dễ review và bảo trì.
↗ConcurrencyGoroutine và channel là công cụ nền tảng.
🧰Thư viện chuẩnHTTP, JSON, crypto, test và công cụ định dạng.

Go khác gì với các ngôn ngữ quen thuộc?

0202 · Môi trường

Cài đặt & thiết lập

Cài Go, kiểm tra phiên bản và tạo dự án đầu tiên.

Bước 1. Tải Go

Truy cập go.dev/dl, chọn bản ổn định phù hợp hệ điều hành rồi cài theo hướng dẫn. Dùng trình biên tập có hỗ trợ Go (ví dụ VS Code + Go extension) để nhận gợi ý mã và debug.

Bước 2. Kiểm tra đường dẫn lệnh

Terminal BASH
go version
go env GOPATH GOROOT GOOS GOARCH

go version in phiên bản được cài. GOPATH dùng cho bộ nhớ cache/module và công cụ, còn GOROOT trỏ đến bản cài Go. Với Go hiện đại, bạn không cần đặt mã nguồn dự án vào GOPATH.

Bước 3. Tạo module

Terminal BASH
mkdir hoc-go
cd hoc-go
go mod init example.com/hoc-go

Lệnh go mod init tạo go.mod để xác định tên module và quản lý phụ thuộc. Với dự án thực, hãy dùng đường dẫn module phù hợp repository (ví dụ github.com/tenban/tenrepo).

✦
Windows / PowerShell

Các lệnh go ... giống nhau. Tạo thư mục bằng mkdir hoc-go và chuyển bằng cd hoc-go.

0404 · Variables & types

Biến, hằng & kiểu dữ liệu

Phân biệt var, const, suy luận kiểu và giá trị zero.

main.go GO
package main

import "fmt"

func main() {
    var age int = 24
    name := "Minh"       // Khai báo ngắn chỉ bên trong hàm
    var active bool      // zero value: false
    const pi = 3.14159

    fmt.Printf("%s - %d - %t - %.2f\n", name, age, active, pi)
}

0505 · Operators

Toán tử & định dạng

Làm việc với phép toán, so sánh, logic và hàm fmt.Printf.

Đặt trong main() GO
x, y := 10, 3
fmt.Println(x+y, x-y, x*y) // 13 7 30
fmt.Println(x/y, x%y)     // 3 1 (chia nguyên)
fmt.Println(x > y, x == y) // true false
fmt.Println(x > 5 && y < 5) // true
fmt.Println(!(x == y))     // true

price := 19.995
fmt.Printf("Gia: %.2f | Kieu: %T\n", price, price)

Các toán tử logic && và || có short-circuit. Không có ++x như C/C++; bạn có thể dùng x++ như một statement, nhưng không nhúng nó vào biểu thức.

0606 · Control flow

Điều kiện & vòng lặp

Go dùng if, switch và duy nhất một cấu trúc lặp: for.

main.go GO
package main

import "fmt"

func main() {
    score := 82
    if score >= 90 {
        fmt.Println("Xuất sắc")
    } else if score >= 70 {
        fmt.Println("Tốt")
    } else {
        fmt.Println("Cần luyện tập")
    }

    switch day := "mon"; day {
    case "mon", "tue":
        fmt.Println("Đầu tuần")
    default:
        fmt.Println("Ngày khác")
    }

    for i := 0; i < 3; i++ {
        fmt.Println(i)
    }
}

Không cần ngoặc tròn quanh điều kiện; dấu ngoặc nhọn { bắt buộc. switch tự kết thúc sau case phù hợp (không cần break); dùng fallthrough khi thật sự cần.

Đặt trong main() GO
sum := 0
for sum < 10 { // tương tự while
    sum += 3
}

for i, v := range []string{"Go", "Rust"} {
    fmt.Println(i, v)
}

// Vòng lặp vô hạn: for { ... }
// break: thoát vòng; continue: lượt tiếp theo
✍FizzBuzz

In các số từ 1 đến 30; bội 3 in Fizz, bội 5 in Buzz, bội cả hai in FizzBuzz.

Xem lời giải gợi ý
Đặt trong main() GO
for i := 1; i <= 30; i++ {
    switch {
    case i%15 == 0:
        fmt.Println("FizzBuzz")
    case i%3 == 0:
        fmt.Println("Fizz")
    case i%5 == 0:
        fmt.Println("Buzz")
    default:
        fmt.Println(i)
    }
}

0707 · Functions

Hàm, scope & closure

Tách chương trình thành các khối có thể tái sử dụng và trả nhiều giá trị.

main.go GO
package main

import "fmt"

func add(a, b int) int { return a + b }

func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("không thể chia cho 0")
    }
    return a / b, nil
}

func total(nums ...int) int {
    sum := 0
    for _, n := range nums { sum += n }
    return sum
}

func main() {
    value, err := divide(10, 2)
    if err != nil { fmt.Println(err); return }
    fmt.Println(add(2, 5), value, total(1, 2, 3))
}

Giá trị trả về và phạm vi

Hàm có thể trả về nhiều giá trị, thường là (result, error). Biến khai báo trong block chỉ tồn tại trong scope đó. ... cho phép nhận số lượng đối số tùy ý (variadic).

Closure GO
func counter() func() int {
    n := 0
    return func() int {
        n++
        return n
    }
}

// Đặt trong main():
// next := counter()
// fmt.Println(next(), next()) // 1 2

Closure là hàm có thể ghi nhớ các biến thuộc môi trường nơi nó được tạo.

0808 · Collections

Array & slice

Phân biệt mảng có độ dài cố định và slice linh hoạt.

main.go GO
package main

import "fmt"

func main() {
    fixed := [3]int{2, 4, 6} // array: độ dài thuộc kiểu
    nums := []int{10, 20, 30} // slice
    nums = append(nums, 40)
    part := nums[1:3] // [20 30], dùng chung backing array

    fmt.Println(fixed, nums, part)
    fmt.Println(len(nums), cap(nums))

    copied := append([]int(nil), nums...) // clone độc lập
    copied[0] = 999
    fmt.Println(nums[0], copied[0]) // 10 999
}

Slice gồm con trỏ tới backing array, len và cap. Hai slice có thể cùng nhìn thấy thay đổi của phần tử khi chúng chia sẻ backing array. append có thể làm cấp phát mảng mới, nên luôn dùng giá trị slice trả về.

Đặt trong main() GO
nums := make([]int, 3, 8) // len=3, cap=8
nums[0] = 7
nums = append(nums, 9)
for i, value := range nums {
    fmt.Println(i, value)
}
!
Tránh lỗi phổ biến

len và cap khác nhau; chỉ truy cập phần tử có chỉ số từ 0 đến len(slice)-1. Vượt giới hạn sẽ gây panic.

0909 · Key–value

Map & tra cứu

Lưu dữ liệu dạng cặp khóa–giá trị và kiểm tra khóa có tồn tại.

main.go GO
package main

import "fmt"

func main() {
    grades := map[string]int{"Lan": 9, "Bình": 8}
    grades["Minh"] = 10

    score, ok := grades["An"]
    if !ok {
        fmt.Println("Không tìm thấy An", score)
    }
    delete(grades, "Bình")

    for name, value := range grades {
        fmt.Println(name, value)
    }
}

Map có kiểu map[Key]Value; khóa phải thuộc kiểu có thể so sánh. Đọc khóa không tồn tại trả về zero value; dùng value, ok := m[key] để phân biệt. Thứ tự duyệt map không được đảm bảo.

!
Lưu ý nil map và concurrency

Bạn có thể đọc từ nil map nhưng không thể gán phần tử mới. Map thông thường không an toàn khi nhiều goroutine đồng thời đọc/ghi mà không đồng bộ.

1010 · Text processing

String, byte & Unicode

Xử lý UTF-8 đúng cách thay vì giả định một ký tự bằng một byte.

main.go GO
package main

import (
    "fmt"
    "strings"
    "unicode/utf8"
)

func main() {
    s := "Xin chào 🌏"
    fmt.Println(len(s))                  // số byte UTF-8
    fmt.Println(utf8.RuneCountInString(s)) // số rune

    for index, r := range s {
        fmt.Printf("byte=%d rune=%c\n", index, r)
    }
    fmt.Println(strings.ToUpper("go lang"))
    fmt.Println(strings.Contains(s, "chào"))
}

string là chuỗi byte bất biến; range trên string giải mã thành các rune và trả byte offset, không phải chỉ số ký tự. Một rune vẫn chưa chắc bằng một ký tự người dùng nhìn thấy (grapheme cluster).

Chuyển đổi byte/string GO
raw := []byte("hello")
raw[0] = 'H'
text := string(raw)
fmt.Println(text) // Hello

1111 · Data modeling

Struct & method

Mô hình hóa thực thể bằng struct và gắn hành vi qua method.

main.go GO
package main

import "fmt"

type User struct {
    Name string
    Age  int
}

func (u User) Label() string {
    return fmt.Sprintf("%s (%d)", u.Name, u.Age)
}

func (u *User) Birthday() {
    u.Age++
}

func main() {
    user := User{Name: "Hà", Age: 20}
    user.Birthday()
    fmt.Println(user.Label()) // Hà (21)
}

Method có receiver: (u User) nhận bản sao; (u *User) cho phép cập nhật đối tượng và tránh copy struct lớn. Tên bắt đầu bằng chữ hoa có thể được xuất ra khỏi package (exported).

Embedding GO
type Address struct { City string }
type Customer struct {
    User            // embedding: nhúng User
    Address Address // field có tên
}

// c := Customer{User: User{Name: "Nam"}}
// fmt.Println(c.Name) // promoted field

1212 · Abstraction

Interface & đa hình

Hiểu interface được triển khai ngầm và cách viết code dễ test.

main.go GO
package main

import (
    "fmt"
    "math"
)

type Shape interface {
    Area() float64
}

type Circle struct { Radius float64 }
func (c Circle) Area() float64 { return math.Pi * c.Radius * c.Radius }

func printArea(s Shape) { fmt.Printf("%.2f\n", s.Area()) }

func main() {
    printArea(Circle{Radius: 2})
}

Không cần viết implements: kiểu nào cung cấp đủ method là thỏa interface. Interface nên nhỏ, tập trung vào hành vi mà nơi sử dụng thực sự cần.

Type switch GO
func describe(value any) string {
    switch v := value.(type) {
    case int:
        return fmt.Sprintf("số nguyên %d", v)
    case string:
        return "chuỗi: " + v
    default:
        return "kiểu khác"
    }
}
!
Bẫy typed nil

Một biến kiểu error có thể khác nil dù giá trị động bên trong là con trỏ nil. Khi muốn biểu thị không có lỗi, hãy return nil trực tiếp.

1313 · Memory basics

Con trỏ & truyền tham số

Biết khi nào nên truyền giá trị và khi nào nên truyền con trỏ.

main.go GO
package main

import "fmt"

func setTo100(p *int) { *p = 100 }

func main() {
    n := 12
    p := &n
    fmt.Println(*p) // 12
    setTo100(&n)
    fmt.Println(n) // 100
}

&x lấy địa chỉ của biến; *p đọc/ghi giá trị mà con trỏ trỏ tới. Go truyền tham số theo giá trị, kể cả khi giá trị đó là một con trỏ. Slice, map và channel cũng có cơ chế chia sẻ dữ liệu bên dưới, không cần dùng con trỏ tới chúng trong phần lớn trường hợp.

✓
Không dùng con trỏ theo thói quen

Chọn receiver con trỏ khi cần sửa trạng thái, tránh copy struct lớn, hoặc để nhất quán với method set. Với giá trị nhỏ, bất biến, receiver giá trị thường rõ ràng hơn.

1414 · Reliability

Xử lý lỗi, defer & panic

Go coi lỗi dự kiến là giá trị cần xử lý, không phải ngoại lệ.

main.go GO
package main

import (
    "errors"
    "fmt"
    "strconv"
)

func parseAge(s string) (int, error) {
    age, err := strconv.Atoi(s)
    if err != nil {
        return 0, fmt.Errorf("tuổi không hợp lệ %q: %w", s, err)
    }
    if age < 0 { return 0, errors.New("tuổi phải không âm") }
    return age, nil
}

func main() {
    age, err := parseAge("abc")
    if err != nil {
        fmt.Println("Lỗi:", err)
        return
    }
    fmt.Println(age)
}

Kiểm tra err != nil gần lệnh có thể sinh lỗi. Dùng fmt.Errorf("...: %w", err) để giữ chuỗi nguyên nhân lỗi; errors.Is và errors.As để kiểm tra.

Bên trong hàm trả error GO
file, err := os.Open("input.txt")
if err != nil { return err }
defer file.Close()

// Các defer chạy LIFO khi hàm bao ngoài trả về.
// Dùng panic cho tình huống thật sự bất thường,
// không dùng thay cho lỗi đầu vào thông thường.
!
Đừng bỏ qua lỗi

Không viết value, _ := operation() trừ khi bạn chắc chắn lý do bỏ qua lỗi. Với thao tác ghi file, đôi khi cần kiểm tra cả lỗi từ Close.

1515 · Reusability

Generics & type parameters

Viết hàm và cấu trúc dữ liệu tái sử dụng cho nhiều kiểu dữ liệu.

main.go GO
package main

import "fmt"

type Number interface {
    ~int | ~int64 | ~float64
}

func Sum[T Number](values []T) T {
    var total T
    for _, v := range values { total += v }
    return total
}

type Pair[A, B any] struct {
    First A
    Second B
}

func main() {
    fmt.Println(Sum([]int{2, 3, 5}))
    fmt.Println(Sum([]float64{1.5, 2.5}))
    fmt.Println(Pair[string, int]{"Go", 27})
}

[T Number] khai báo tham số kiểu; any chấp nhận mọi kiểu; ~int bao gồm các kiểu tự định nghĩa có underlying type là int. Type inference thường cho phép bỏ tham số kiểu khi gọi hàm.

✓
Dùng generics khi nào?

Dùng khi cùng một thuật toán thực sự áp dụng cho nhiều kiểu (container, xử lý slice, thuật toán tổng quát). Nếu chỉ cần đa hình về hành vi, interface thông thường dễ đọc hơn.

1616 · Concurrent Go

Goroutine & channel

Cho nhiều tác vụ cùng tiến triển và trao đổi dữ liệu an toàn.

main.go GO
package main

import (
    "fmt"
    "sync"
)

func main() {
    jobs := make(chan int)
    var wg sync.WaitGroup

    for worker := 1; worker <= 2; worker++ {
        wg.Add(1)
        go func(id int) {
            defer wg.Done()
            for job := range jobs {
                fmt.Printf("worker %d xử lý %d\n", id, job)
            }
        }(worker)
    }

    for job := 1; job <= 5; job++ { jobs <- job }
    close(jobs) // người gửi đóng sau khi gửi xong
    wg.Wait()
}

1717 · Shared state

Mutex, WaitGroup & race

Bảo vệ dữ liệu dùng chung và phát hiện lỗi tranh chấp dữ liệu.

main.go GO
package main

import (
    "fmt"
    "sync"
)

type Counter struct {
    mu sync.Mutex
    value int
}

func (c *Counter) Inc() {
    c.mu.Lock()
    defer c.mu.Unlock()
    c.value++
}

func main() {
    var c Counter
    var wg sync.WaitGroup
    for i := 0; i < 100; i++ {
        wg.Add(1)
        go func() { defer wg.Done(); c.Inc() }()
    }
    wg.Wait()
    fmt.Println(c.value) // 100
}

sync.Mutex chỉ cho một goroutine giữ khóa tại một thời điểm; sync.RWMutex hỗ trợ nhiều reader; sync.WaitGroup dùng để đợi nhóm goroutine hoàn tất. Không sao chép một mutex sau khi đã sử dụng.

1818 · Lifecycle

Context, timeout & cancellation

Hủy công việc lâu, đặt deadline và tránh rò rỉ goroutine.

main.go GO
package main

import (
    "context"
    "fmt"
    "time"
)

func wait(ctx context.Context) error {
    select {
    case <-time.After(2 * time.Second):
        return nil
    case <-ctx.Done():
        return ctx.Err()
    }
}

func main() {
    ctx, cancel := context.WithTimeout(context.Background(), 100*time.Millisecond)
    defer cancel()
    fmt.Println(wait(ctx)) // context deadline exceeded
}

context.Context mang cancellation, deadline và giá trị gắn với phạm vi request. Khi gọi API/database, truyền ctx từ caller đến callee. Thường truyền context làm tham số đầu tiên: func Fetch(ctx context.Context, ...).

✓
Không lạm dụng context.WithValue

Chỉ đặt dữ liệu gắn với request, không dùng context thay cho tham số hàm thông thường hay container phụ thuộc. Luôn gọi cancel() khi tạo context có cancel, kể cả timeout.

        ReadHeaderTimeout: 5 * time.Second,
    }
    log.Println("Serving at http://localhost:8080")
    log.Fatal(server.ListenAndServe())
}

func TestAdd(t *testing.T) {

main.go GO
package main

import (
    "encoding/json"
    "errors"
    "io"
    "log"
    "net/http"
    "sync"
    "time"
)

type Task struct {
    ID   int    `json:"id"`
    Text string `json:"text"`
    Done bool   `json:"done"`
}

type Store struct {
    mu    sync.Mutex
    next  int
    tasks []Task
}

func main() {
    store := &Store{next: 1}
    mux := http.NewServeMux()

    mux.HandleFunc("GET /tasks", func(w http.ResponseWriter, r *http.Request) {
        store.mu.Lock()
        items := make([]Task, len(store.tasks))
        copy(items, store.tasks)
        store.mu.Unlock()

        w.Header().Set("Content-Type", "application/json")
        if err := json.NewEncoder(w).Encode(items); err != nil {
            log.Printf("encode tasks: %v", err)
        }
    })

    mux.HandleFunc("POST /tasks", func(w http.ResponseWriter, r *http.Request) {
        r.Body = http.MaxBytesReader(w, r.Body, 1<<20) // tối đa 1 MiB
        defer r.Body.Close()

        var input struct { Text string `json:"text"` }
        decoder := json.NewDecoder(r.Body)
        decoder.DisallowUnknownFields()
        if err := decoder.Decode(&input); err != nil {
            http.Error(w, "JSON không hợp lệ", http.StatusBadRequest)
            return
        }
        var extra any
        if err := decoder.Decode(&extra); !errors.Is(err, io.EOF) {
            http.Error(w, "Body chỉ được chứa một JSON object", http.StatusBadRequest)
            return
        }
        if input.Text == "" {
            http.Error(w, "text không được rỗng", http.StatusBadRequest)
            return
        }

        store.mu.Lock()
        item := Task{ID: store.next, Text: input.Text}
        store.next++
        store.tasks = append(store.tasks, item)
        store.mu.Unlock()

        w.Header().Set("Content-Type", "application/json")
        w.WriteHeader(http.StatusCreated)
        if err := json.NewEncoder(w).Encode(item); err != nil {
            log.Printf("encode created task: %v", err)
        }
    })

    server := &http.Server{
        Addr: ":8080",
        Handler: mux,
        ReadHeaderTimeout: 5 * time.Second,
    }
    log.Println("Todo API: http://localhost:8080/tasks")
    log.Fatal(server.ListenAndServe())
}

func unique(nums []int) []int {
    seen := make(map[int]struct{})
    result := make([]int, 0, len(nums))
    for _, n := range nums {
        if _, ok := seen[n]; ok { continue }
        seen[n] = struct{}{}
        result = append(result, n)
    }
    return result
}
