1. PyTorch là gì?

Khái niệm, hệ sinh thái và quy trình học sâu.

PyTorch là framework mã nguồn mở hỗ trợ tensor, tăng tốc phần cứng và automatic differentiation. Nó phổ biến trong nghiên cứu lẫn production nhờ cách lập trình Python tự nhiên.

Các thành phần quan trọng

Thư viện / module Vai trò
torch Tensor, toán tử, quản lý thiết bị
torch.autograd Tự động tính đạo hàm
torch.nn Lớp mạng và loss function
torch.optim SGD, Adam, AdamW, scheduler
torch.utils.data Dataset, DataLoader, batching
torchvision Dữ liệu, transforms, mô hình thị giác
torchaudio Công cụ cho bài toán âm thanh
torch.distributed Huấn luyện nhiều tiến trình / GPU

Một pipeline Deep Learning điển hình

  1. Chuẩn bị dữ liệu và chia train/validation/test.
  2. Định nghĩa mô hình kế thừa nn.Module.
  3. Chọn loss, optimizer và siêu tham số.
  4. Lặp: forward → loss → backward → optimizer.step().
  5. Đánh giá trên validation, lưu checkpoint tốt nhất.
  6. Đánh giá cuối cùng trên test và triển khai suy luận.

Tại sao dùng PyTorch thay vì NumPy? Cả hai đều thao tác trên mảng, nhưng PyTorch có tính toán gradient tự động, hỗ trợ GPU/accelerator và các module huấn luyện neural network.

2.3 Kiểm tra cài đặt và device

PYTHON
import torch
print('PyTorch:', torch.__version__)
print('CUDA:', torch.cuda.is_available())
print('MPS:', torch.backends.mps.is_available())

def choose_device():
    if torch.cuda.is_available():
        return torch.device('cuda')
    if torch.backends.mps.is_available():
        return torch.device('mps')
    return torch.device('cpu')

device = choose_device()
print('Device:', device)
x = torch.ones(2, 3, device=device)
print(x)

Lưu ý: CUDA dành cho GPU NVIDIA được hỗ trợ; MPS cho GPU Apple Silicon / macOS hỗ trợ. torch.cuda.is_available() trả về False không nhất thiết có nghĩa là cài lỗi: máy có thể không có GPU NVIDIA, thiếu driver tương thích hoặc cài bản CPU.

3. Tensor: cấu trúc dữ liệu cốt lõi

Khởi tạo, shape, dtype, device, index và chuyển đổi.

Tensor là mảng nhiều chiều, tương tự numpy.ndarray, có thể nằm trên CPU hoặc thiết bị tăng tốc.

3.1 Khởi tạo tensor

PYTHON
import torch

x = torch.tensor([[1, 2], [3, 4]], dtype=torch.float32)
a = torch.zeros((2, 3))
b = torch.ones((2, 3))
c = torch.rand((2, 3))       # Uniform [0, 1)
d = torch.randn((2, 3))      # Normal N(0, 1)
e = torch.arange(0, 10, 2)
f = torch.linspace(0, 1, 5)
like = torch.zeros_like(x)

print(x.shape)   # torch.Size([2, 2])
print(x.ndim)    # 2
print(x.dtype)   # torch.float32
print(x.device)  # cpu (nếu chưa .to(...))

3.2 Truy cập và biến đổi shape

PYTHON
x = torch.arange(12).reshape(3, 4)
print(x[0, :])       # Hàng đầu tiên
print(x[:, 1])       # Cột thứ hai
print(x[-1, -1])     # Phần tử cuối

print(x.reshape(2, 6).shape)
print(x.unsqueeze(0).shape)  # (1, 3, 4)
print(x.flatten().shape)     # (12,)
print(x.T.shape)             # (4, 3)

view() thường yêu cầu tensor có memory layout phù hợp; reshape() có thể trả về view hoặc tạo bản sao nếu cần. permute() thay đổi thứ tự các chiều; transpose() hoán đổi hai chiều.

PYTHON
images = torch.randn(8, 3, 64, 64)     # NCHW
images_nhwc = images.permute(0, 2, 3, 1)
print(images_nhwc.shape)               # (8, 64, 64, 3)

3.3 dtype, scalar, NumPy

PYTHON
x = torch.tensor([1, 2, 3])
print(x.float())                  # int -> float32
print(x.to(torch.float64))        # double
print(x.sum().item())            # tensor scalar -> Python number

import numpy as np
arr = np.array([1.0, 2.0], dtype=np.float32)
t = torch.from_numpy(arr)       # Chia sẻ bộ nhớ CPU
arr_copy = t.clone().numpy()    # Bản sao tách biệt

Cẩn thận: .numpy() trực tiếp trên tensor có gradient hoặc đang ở GPU thường không hợp lệ. Dùng tensor.detach().cpu().numpy(). Các thao tác chia sẻ bộ nhớ NumPy ↔ Tensor có thể làm thay đổi dữ liệu ở cả hai phía.

4. Các phép toán Tensor & Broadcasting

Toán tử, ma trận, giảm chiều và quy tắc broadcasting.

4.1 Phép toán phần tử và ma trận

PYTHON
import torch
x = torch.tensor([[1., 2.], [3., 4.]])
y = torch.tensor([[5., 6.], [7., 8.]])

print(x + y)                   # Cộng theo phần tử
print(x * y)                   # Nhân theo phần tử
print(x @ y)                   # Nhân ma trận
print(torch.matmul(x, y))
print(x.mean(), x.sum(), x.max())
print(x.sum(dim=0))            # Tổng mỗi cột
print(x.mean(dim=1))           # Trung bình mỗi hàng
print(torch.softmax(x, dim=1))

4.2 Broadcasting

Khi hai tensor có số chiều khác nhau, PyTorch có thể tự mở rộng các chiều kích thước 1 hoặc chiều còn thiếu, từ phải sang trái.

PYTHON
x = torch.ones(4, 3)             # (4, 3)
bias = torch.tensor([1., 2., 3.]) # (3,)
y = x + bias                    # (4, 3)

batch = torch.randn(8, 3, 32, 32)
mean = torch.tensor([.5, .4, .3]).view(1, 3, 1, 1)
normalized = batch - mean       # (8, 3, 32, 32)

Ví dụ sai: (4, 3) + (4,) gây RuntimeError vì các kích thước cuối 3 và 4 không tương thích.

4.3 Các thao tác cần nhớ

Mục đích API thường dùng
Ghép tensor torch.cat, torch.stack
Thay shape reshape, flatten, squeeze, unsqueeze
Giảm chiều sum, mean, amax, argmax
Chỉ mục logic x[x > 0], torch.where
Sắp xếp sort, argsort, topk
Tính khoảng cách torch.linalg.norm, torch.cdist
PYTHON
a = torch.ones(2, 3)
b = torch.zeros(2, 3)
print(torch.cat([a, b], dim=0).shape)   # (4, 3)
print(torch.stack([a, b], dim=0).shape) # (2, 2, 3)

5. Autograd & Backpropagation

Computational graph, chain rule và gradient.

Autograd tự dựng computation graph cho các phép toán trên tensor có requires_grad=True. Khi gọi backward(), PyTorch tính gradient bằng quy tắc dây chuyền.

5.1 Ví dụ đạo hàm đơn giản

Giả sử (y = x^2 + 3x), tại (x=2) ta có (dy/dx = 2x+3 = 7).

PYTHON
import torch
x = torch.tensor(2.0, requires_grad=True)
y = x**2 + 3*x
y.backward()
print(x.grad)     # tensor(7.)

5.2 Gradient vector

PYTHON
x = torch.tensor([1., 2., 3.], requires_grad=True)
y = (x ** 2).sum()          # Scalar loss
y.backward()
print(x.grad)              # tensor([2., 4., 6.])

5.3 Vì sao phải zero gradient?

PyTorch cộng dồn gradient vào .grad (không tự reset), vì vậy trong train loop phải gọi optimizer.zero_grad() mỗi bước cập nhật, trừ khi cố ý gradient accumulation.

PYTHON
w = torch.tensor(2.0, requires_grad=True)
(w ** 2).backward()
print(w.grad.item())        # 4.0
(w ** 2).backward()
print(w.grad.item())        # 8.0: đã cộng dồn
w.grad = None              # Reset thủ công

5.4 no_grad, inference_mode và detach

PYTHON
with torch.no_grad():
    y = x * 5

with torch.inference_mode():
    pred = x * 5

x_detached = x.detach()
  • no_grad() tắt ghi nhận gradient tạm thời, tiện khi đánh giá/cập nhật ngoài autograd.
  • inference_mode() có thể nhanh hơn cho suy luận, nhưng tensor tạo bên trong có hạn chế khi dùng lại trong autograd.
  • detach() trả tensor không tiếp tục theo dõi computation graph trước đó.

Phân biệt: model.eval() đổi hành vi Dropout/BatchNorm, không tự tắt autograd. Thường dùng cả hai khi inference.

6. Xây dựng mạng với torch.nn

nn.Module, parameters, forward và nn.Sequential.

Mỗi mô hình PyTorch thông thường là một lớp kế thừa torch.nn.Module, định nghĩa các layer trong __init__ và luồng dữ liệu trong forward.

6.1 Mạng MLP nhị phân

PYTHON
import torch
from torch import nn

class MLP(nn.Module):
    def __init__(self, input_dim=20, hidden_dim=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Dropout(p=0.2),
            nn.Linear(hidden_dim, 1)
        )

    def forward(self, x):
        return self.net(x)  # Logit; chưa sigmoid

model = MLP()
x = torch.randn(8, 20)
logits = model(x)
print(logits.shape)              # (8, 1)
print(sum(p.numel() for p in model.parameters()))

6.2 nn.Sequential hay class riêng?

nn.Sequential phù hợp cho pipeline tuyến tính. Dùng class nn.Module khi có kết nối nhánh, skip connection, nhiều đầu ra hoặc logic riêng.

PYTHON
class ResidualBlock(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.fc1 = nn.Linear(dim, dim)
        self.fc2 = nn.Linear(dim, dim)

    def forward(self, x):
        return torch.relu(self.fc2(torch.relu(self.fc1(x))) + x)

6.3 Những layer thường gặp

Layer Công dụng Input ví dụ
nn.Linear(in, out) Fully connected (B, in)
nn.Conv2d(c_in, c_out, k) Trích đặc trưng ảnh (B, C, H, W)
nn.BatchNorm2d(c) Chuẩn hóa feature map (B, C, H, W)
nn.LayerNorm(d) Chuẩn hóa chiều đặc trưng (..., d)
nn.Dropout(p) Regularization khi train Bất kỳ
nn.Embedding(vocab, d) Token → vector (B, L)
nn.MultiheadAttention(d, n_heads) Attention (B, L, d) nếu batch_first=True

Ghi nhớ: gọi model(x) thay vì model.forward(x) để framework thực thi hooks và hành vi liên quan đầy đủ.

7. Dataset, DataLoader & batching

Biến dữ liệu thô thành mini-batch một cách chuẩn hóa.

Dataset định nghĩa cách lấy một mẫu; DataLoader gom mẫu thành batch, xáo trộn, và có thể đọc song song.

7.1 Dataset tự định nghĩa

PYTHON
import torch
from torch.utils.data import Dataset, DataLoader

class TabularDataset(Dataset):
    def __init__(self, n=1000, features=10):
        self.X = torch.randn(n, features)
        self.y = (self.X.sum(dim=1) > 0).long()

    def __len__(self):
        return len(self.X)

    def __getitem__(self, index):
        return self.X[index], self.y[index]

dataset = TabularDataset()
loader = DataLoader(dataset, batch_size=32, shuffle=True)
for X_batch, y_batch in loader:
    print(X_batch.shape, y_batch.shape)   # (32, 10), (32,)
    break

7.2 DataLoader parameters

Tham số Ý nghĩa
batch_size=32 Số mẫu trong 1 mini-batch
shuffle=True Xáo trộn thứ tự mỗi epoch (train)
num_workers=4 Số tiến trình tải dữ liệu; bắt đầu với 0 để debug
pin_memory=True Có thể tăng tốc copy CPU → CUDA
drop_last=True Bỏ batch cuối nếu thiếu mẫu
collate_fn=... Tùy chỉnh cách gom batch, ví dụ độ dài biến thiên

7.3 Dataset ảnh từ thư mục

Sắp xếp dữ liệu dạng data/train/cat/*.jpg, data/train/dog/*.jpg rồi sử dụng torchvision.datasets.ImageFolder.

PYTHON
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
])
train_ds = datasets.ImageFolder('data/train', transform=transform)
train_dl = DataLoader(train_ds, batch_size=32, shuffle=True)
print(train_ds.class_to_idx)

Kinh nghiệm: không augment tập validation/test bằng phép biến đổi ngẫu nhiên làm thay đổi nội dung. Chia dữ liệu theo đối tượng, video hoặc phiên ghi nếu các khung hình gần nhau có thể gây data leakage.

8. Preprocessing & Data Augmentation

Chuẩn hóa, ảnh RGB, transforms và biến đổi train/test.

8.1 Tại sao tiền xử lý quan trọng?

Mô hình nhạy với thang pixel, kích thước ảnh, tỷ lệ khung hình và phân phối ảnh đầu vào. Nếu dùng model pretrained, cần preprocessing phù hợp với weights của model.

PYTHON
from torchvision import transforms

train_tfms = transforms.Compose([
    transforms.Resize((256, 256)),
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.RandomRotation(degrees=10),
    transforms.ToTensor(),            # PIL RGB → float tensor [0, 1]
    transforms.Normalize(
        mean=(0.485, 0.456, 0.406),
        std=(0.229, 0.224, 0.225)
    ),
])

val_tfms = transforms.Compose([
    transforms.Resize((256, 256)),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=(0.485, 0.456, 0.406),
        std=(0.229, 0.224, 0.225)
    ),
])

Các giá trị mean/std trên thường được dùng cho nhiều model pretrained trên ImageNet; với bài toán khác, hãy tính thống kê tập train hoặc dùng transform đi kèm weights.

8.2 Lưu ý với object detection

Khi xoay, crop, flip ảnh có bounding box, phải biến đổi box và mask tương ứng. Không nên áp dụng transform ảnh độc lập lên input nếu label không được cập nhật. Với ảnh y sinh/thuỷ sản, hãy cân nhắc phép augment nào giữ nguyên ý nghĩa nhãn.

8.3 Kiểm tra thống kê ảnh

PYTHON
# images: (B, C, H, W), được chuẩn hóa [0, 1]
mean = images.mean(dim=(0, 2, 3))
std = images.std(dim=(0, 2, 3))
print(mean, std)

Trong đoạn cuối, images là batch bạn đã đọc từ DataLoader; đoạn này là minh họa, không phải script độc lập.

9. Loss Functions & Activation

Chọn hàm mất mát phù hợp với đầu ra mô hình.

9.1 Chọn loss theo loại bài toán

Bài toán Output của model Loss nên dùng Target
Regression (B, 1) nn.MSELoss, nn.L1Loss float cùng shape
Multi-class, 1 nhãn (B, K) logits nn.CrossEntropyLoss long, (B,) class index
Binary classification (B, 1) logits nn.BCEWithLogitsLoss float, (B, 1)
Multi-label (B, K) logits nn.BCEWithLogitsLoss float, (B, K)
Segmentation (multi-class) (B, K, H, W) nn.CrossEntropyLoss long, (B, H, W)

9.2 Ví dụ CrossEntropyLoss

PYTHON
import torch
from torch import nn
logits = torch.tensor([[2.1, 0.4, -0.2], [0.2, 0.1, 2.0]])
y = torch.tensor([0, 2], dtype=torch.long)
loss = nn.CrossEntropyLoss()(logits, y)
prob = logits.softmax(dim=1)
pred = logits.argmax(dim=1)
print(loss.item(), prob, pred)

CrossEntropyLoss nhận raw logits, tự kết hợp log-softmax và negative log-likelihood. Không gọi softmax trước khi đưa vào loss này.

9.3 BCEWithLogitsLoss

PYTHON
logits = torch.tensor([[0.5], [-1.0]])

11. Training loop hoàn chỉnh

Huấn luyện, validation, train/eval mode và thống kê theo batch.

Đây là bộ khung có thể tái sử dụng cho phân loại nhiều lớp với nn.CrossEntropyLoss. Phần này định nghĩa train/evaluate độc lập với kiến trúc model.

PYTHON
import torch
from torch import nn

def train_one_epoch(model, loader, optimizer, criterion, device):
    model.train()
    total_loss, total_correct, total_items = 0.0, 0, 0

    for x, y in loader:
        x, y = x.to(device), y.to(device)
        optimizer.zero_grad(set_to_none=True)
        logits = model(x)
        loss = criterion(logits, y)
        loss.backward()
        optimizer.step()

        bs = y.size(0)
        total_loss += loss.item() * bs
        total_correct += (logits.argmax(dim=1) == y).sum().item()
        total_items += bs

    return total_loss / total_items, total_correct / total_items

@torch.inference_mode()
def evaluate(model, loader, criterion, device):
    model.eval()
    total_loss, total_correct, total_items = 0.0, 0, 0
    for x, y in loader:
        x, y = x.to(device), y.to(device)
        logits = model(x)
        loss = criterion(logits, y)
        bs = y.size(0)
        total_loss += loss.item() * bs
        total_correct += (logits.argmax(dim=1) == y).sum().item()
        total_items += bs
    return total_loss / total_items, total_correct / total_items

Gọi train loop

PYTHON
# Giả sử đã có model, train_loader, val_loader, device
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)

best_val_acc = -1.0
for epoch in range(10):
    tr_loss, tr_acc = train_one_epoch(
        model, train_loader, optimizer, criterion, device
    )
    va_loss, va_acc = evaluate(model, val_loader, criterion, device)
    print(f'{epoch+1:02d}: train={tr_acc:.3f}, val={va_acc:.3f}')
    if va_acc > best_val_acc:
        best_val_acc = va_acc
        torch.save(model.state_dict(), 'best_model.pth')

Điểm quan trọng: tính loss.item() * batch_size trước khi lấy trung bình theo tổng mẫu (vì batch cuối có thể nhỏ hơn). Cần model.to(device) trước khi train và tạo data loaders với đúng đặc trưng input.

Gradient accumulation

Nếu bộ nhớ GPU không đủ, có thể tích lũy gradient qua nhiều mini-batch rồi mới gọi optimizer.step(). Phải xử lý đúng tỷ lệ loss, batch cuối và trường hợp dùng AMP/DDP. Tích lũy gradient không luôn hoàn toàn tương đương với batch lớn (ví dụ BatchNorm).

class SmallCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1), nn.ReLU(),
            nn.MaxPool2d(2),              # 32 -> 16
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(),
            nn.MaxPool2d(2),              # 16 -> 8
            nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(),
            nn.AdaptiveAvgPool2d((1, 1))
        )
        self.classifier = nn.Linear(128, num_classes)

    def forward(self, x):
        x = self.features(x)               # (B, 128, 1, 1)
        x = x.flatten(1)                   # (B, 128)
        return self.classifier(x)          # logits (B, 10)

model = SmallCNN()
print(model(torch.randn(5, 3, 32, 32)).shape)  # (5, 10)

18. AMP, torch.compile & Profiling

18.1 Automatic Mixed Precision (AMP) trên CUDA

AMP có thể cải thiện tốc độ và giảm bộ nhớ khi phần cứng hỗ trợ. Với CUDA float16, sử dụng autocast + GradScaler:

PYTHON
import torch
use_amp = torch.cuda.is_available()
scaler = torch.amp.GradScaler('cuda', enabled=use_amp)

# Trong vòng lặp train; model, x, y, optimizer, criterion đã có
optimizer.zero_grad(set_to_none=True)
with torch.autocast(device_type='cuda', dtype=torch.float16,
                    enabled=use_amp):
    logits = model(x)
    loss = criterion(logits, y)

scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()

Code trên là mẫu CUDA/CPU (CPU bỏ qua autocast vì enabled=False). Trên MPS, cần kiểm tra hỗ trợ AMP theo phiên bản và dtype; không mặc định chuyển nguyên mẫu CUDA sang MPS. bfloat16 thường không cần GradScaler theo cách dùng float16, nhưng mức hỗ trợ phụ thuộc thiết bị.

19. Distributed Training & DDP

DataParallel so với DDP và cấu trúc torchrun.

DistributedDataParallel (DDP) thường là lựa chọn chuẩn để train trên nhiều GPU bằng nhiều tiến trình. Mỗi tiến trình có bản sao model, nhận phần dữ liệu riêng và đồng bộ gradient.

19.1 Ví dụ khung DDP (một node nhiều GPU CUDA)

PYTHON
# train_ddp.py — skeleton; chạy trong môi trường CUDA đa GPU
import os
import torch
import torch.distributed as dist
from torch import nn
from torch.nn.parallel import DistributedDataParallel as DDP
from torch.utils.data import DataLoader, DistributedSampler


def main():
    dist.init_process_group(backend='nccl')
    local_rank = int(os.environ['LOCAL_RANK'])
    torch.cuda.set_device(local_rank)
    device = torch.device(f'cuda:{local_rank}')

    dataset = MyDataset()  # Tự định nghĩa
    sampler = DistributedSampler(dataset, shuffle=True)
    loader = DataLoader(dataset, batch_size=32, sampler=sampler)

    model = MyModel().to(device)
    model = DDP(model, device_ids=[local_rank])
    optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)
    criterion = nn.CrossEntropyLoss()
    try:
        for epoch in range(5):
            sampler.set_epoch(epoch)
            for x, y in loader:
                x, y = x.to(device), y.to(device)
                optimizer.zero_grad(set_to_none=True)
                loss = criterion(model(x), y)
                loss.backward()
                optimizer.step()
    finally:
        dist.destroy_process_group()

if __name__ == '__main__':
    main()
BASH
torchrun --standalone --nproc-per-node=2 train_ddp.py

Giới hạn: Đây là skeleton, chưa độc lập vì bạn phải định nghĩa MyDataset, MyModel và có ≥2 GPU CUDA. DistributedSampler có thể cần xử lý trùng mẫu khi số mẫu không chia hết cho số worker nếu muốn tính metric tuyệt đối chính xác. Tham khảo DDP chính thức cho checkpoint, validation và lỗi đồng bộ.

19.2 DDP so với batch size

Nếu mỗi GPU có batch size 32 và dùng 4 GPU, global batch size thường là 128 (chưa tính accumulation). Khi tăng global batch size, cần xem lại learning rate, scheduler và số optimizer steps.

20. Dự án A–Z: FashionMNIST

Mã Python chạy được: tải dữ liệu → train → test → lưu model.

Dự án minh họa phân loại 10 loại trang phục từ ảnh grayscale 28×28. Dataset FashionMNIST được tải qua TorchVision, không cần chuẩn bị ảnh thủ công. Cần cài torch và torchvision tương thích, internet cho lần tải dataset đầu tiên.

🎯 Sau dự án này bạn sẽ làm được

Chọn thiết bị, load dataset, tách validation, xây CNN, train nhiều epoch, lưu mô hình tốt nhất và tính accuracy trên test.

20.1 Script hoàn chỉnh: fashion_mnist.py

PYTHON
import random
import numpy as np
import torch
from torch import nn
from torch.utils.data import DataLoader, random_split
from torchvision import datasets, transforms

SEED = 42
random.seed(SEED)
np.random.seed(SEED)
torch.manual_seed(SEED)

device = torch.device(
    'cuda' if torch.cuda.is_available() else
    'mps' if torch.backends.mps.is_available() else 'cpu'
)
print('Running on', device)

# 1) Download & split datasets
transform = transforms.ToTensor()
full_train = datasets.FashionMNIST(
    root='data', train=True, download=True, transform=transform
)
test_ds = datasets.FashionMNIST(
    root='data', train=False, download=True, transform=transform
)
train_ds, val_ds = random_split(
    full_train, [50000, 10000],
    generator=torch.Generator().manual_seed(SEED)
)
train_loader = DataLoader(train_ds, batch_size=128, shuffle=True)
val_loader = DataLoader(val_ds, batch_size=256)
test_loader = DataLoader(test_ds, batch_size=256)

# 2) Model
class FashionCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1), nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Flatten(),
            nn.Linear(64 * 7 * 7, 128), nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        return self.net(x)

model = FashionCNN().to(device)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)

# 3) Training
best_val_acc = 0.0
for epoch in range(5):
    model.train()
    running_loss, count = 0.0, 0
    for images, labels in train_loader:
        images = images.to(device)
        labels = labels.to(device)

        optimizer.zero_grad(set_to_none=True)
        logits = model(images)
        loss = criterion(logits, labels)
        loss.backward()
        optimizer.step()

        running_loss += loss.item() * labels.size(0)
        count += labels.size(0)

    # Validation
    model.eval()
    val_correct, val_total = 0, 0
    with torch.inference_mode():
        for images, labels in val_loader:
            logits = model(images.to(device))
            pred = logits.argmax(dim=1).cpu()
            val_correct += (pred == labels).sum().item()
            val_total += labels.size(0)

    val_acc = val_correct / val_total
    print(f'Epoch {epoch+1}: loss={running_loss/count:.4f}, '
          f'val_acc={val_acc:.4f}')

    if val_acc > best_val_acc:
        best_val_acc = val_acc
        torch.save(model.state_dict(), 'fashion_best.pth')

# 4) Load best and test ONCE
state = torch.load('fashion_best.pth', map_location='cpu',
                   weights_only=True)
model.load_state_dict(state)
model.to(device).eval()

test_correct, test_total = 0, 0
with torch.inference_mode():
    for images, labels in test_loader:
        pred = model(images.to(device)).argmax(dim=1).cpu()
        test_correct += (pred == labels).sum().item()
        test_total += labels.size(0)

print(f'Best val accuracy: {best_val_acc:.4f}')
print(f'Test accuracy: {test_correct/test_total:.4f}')

21. Computer Vision: Object Detection

Bounding box, custom Dataset và Faster R-CNN trong PyTorch.

Trong bài toán phát hiện tôm/cá, model thường nhận ảnh và xuất bounding boxes, class labels, scores. Dataset detection khác classification vì mỗi ảnh có số lượng đối tượng thay đổi.

21.1 Định dạng annotation

Với mỗi ảnh RGB images[i] có shape (3, H, W), target có thể chứa:

  • boxes: tensor float32, shape (N, 4), định dạng (xmin, ymin, xmax, ymax).
  • labels: tensor int64, shape (N,), ID lớp, với class 0 thường dành cho background trong Faster R-CNN.
  • Có thể có image_id, area, iscrowd cho evaluation COCO.

21.2 Dataset đơn giản đọc annotation từ bộ nhớ

PYTHON
import torch
from PIL import Image
from torchvision.transforms.functional import to_tensor
from torch.utils.data import Dataset, DataLoader

class DetectionDataset(Dataset):
    def __init__(self, records):
        # records: [{'image': 'a.jpg', 'boxes': [[x1,y1,x2,y2]], ...}]
        self.records = records

    def __len__(self):
        return len(self.records)

    def __getitem__(self, idx):
        rec = self.records[idx]
        image = to_tensor(Image.open(rec['image']).convert('RGB'))
        boxes = torch.as_tensor(rec['boxes'], dtype=torch.float32).reshape(-1, 4)
        labels = torch.ones((len(boxes),), dtype=torch.int64)  # 1 = prawn
        return image, {'boxes': boxes, 'labels': labels}


def detection_collate(batch):
    return tuple(zip(*batch))

22. Debugging & lỗi thường gặp

Checklist xử lý tensor shape, CUDA OOM và loss không giảm.

Vấn đề Nguyên nhân phổ biến Cách xử lý
Expected all tensors ... same device Model và input khác device .to(device) cho model và từng batch
mat1 and mat2 shapes cannot be multiplied Sai feature dimension In x.shape trước nn.Linear
expected scalar type Long Label cho CrossEntropy sai dtype y.long() cho class indices
CUDA out of memory Batch/ảnh/model quá lớn Giảm batch/resize, AMP, accumulation
Loss ra NaN Learning rate cao, overflow, dữ liệu NaN Kiểm tra dữ liệu, giảm LR, clipping
Trying to backward ... second time Backward 2 lần qua graph đã giải phóng Tính forward lại / quản lý graph đúng
Validation dao động Quên eval(), split nhỏ, seed eval(), kiểm tra augmentation, split
Accuracy không tăng Label lệch, loss không hợp, LR Test overfit trên 1 batch
DataLoader treo multiprocessing / worker lỗi Dùng num_workers=0, kiểm tra __main__

24. Bài tập theo cấp độ

Tự kiểm tra kiến thức và hướng giải.

Bài 1 — Tensor (dễ)

Tạo tensor kích thước (5, 3), tính trung bình theo cột, chuẩn hóa về mean 0 và std 1 theo cột.

Xem gợi ý / lời giải
PYTHON
import torch
x = torch.randn(5, 3)
mean = x.mean(dim=0, keepdim=True)
std = x.std(dim=0, keepdim=True).clamp_min(1e-8)
x_norm = (x - mean) / std
print(x_norm.mean(dim=0))

Bài 2 — Autograd (dễ)

Với w = 3, tính đạo hàm của L = (w − 5)² và xác nhận gradient bằng tính tay.

Xem gợi ý / lời giải
PYTHON
w = torch.tensor(3.0, requires_grad=True)
L = (w - 5)**2
L.backward()
print(w.grad.item())   # -4.0

Bài 3 — MLP (trung bình)

Dùng dữ liệu tổng hợp X: (1000, 10), y nhị phân. Xây MLP với BCEWithLogitsLoss, chia train/validation, so sánh accuracy và F1.

Hướng dẫn triển khai

Dùng `TensorDataset`, output shape `(B,1)`, chuyển nhãn sang float32 và unsqueeze(1). Khi dự đoán, dùng sigmoid(logits) >= 0.5. Không thêm sigmoid vào model khi dùng BCEWithLogitsLoss.

Bài 4 — CNN (trung bình)

Thay FashionCNN bằng kiến trúc có BatchNorm và Dropout; ghi log train/validation 10 epoch, báo cáo confusion matrix trên test.

Bài 5 — Nghiên cứu Computer Vision (nâng cao)

Xây pipeline phát hiện tôm/cá từ tập ảnh có nhãn: convert annotations → custom Dataset → train detector → evaluate mAP → phân tích vật thể nhỏ và vùng mật độ cao.

Checklist khi nộp kết quả: mã nguồn và requirements, cách chia dataset, seed, các chỉ số, phần cứng, cấu hình huấn luyện, đồ thị học và ví dụ dự đoán.
